## 构型演进主线（对照 [CHANGELOG](../../CHANGELOG.md)）

```
v0.1  螺旋弹 / 纯自旋长杆，无主翼                      → 废弃（无主翼不可行）
v0.2  带翼迫降 / 折叠翼自旋垂起                        → 废弃（4×24" 桨需 ~1.3 m 尾架，不成立）
v0.3  倒拖垂直起飞 + 无动力改平（**单翼 b 2.00 m**）   → 废弃（半展 1000 mm 进不了 ⌀380×850 桶）
v0.3.1c 单翼反复调整                                   → 废弃（同上，分断则需在翼内过信号线）
v0.4  **上下双翼**（上 b1.50 / 下 b1.40，各 0.315 m²）+ 钻石背两段折收拢     ← 当前版
v0.4a 菱形主翼备选                                     → 未采用
```

> **v0.4 的三个关键取舍**（详见 [docs/03](../../docs/03-总体方案与气动布局.md) 与 CHANGELOG）：
> 1. 整机返航、整机迫降（**不要伞**）——省 1.6 kg 与 380 mm 舱段；
> 2. 头部 = 一次性吸能区（空舱），数据舱移到前段快拆舱；
> 3. 上下双翼换"能进桶"——代价是等效展长 2.00 → 1.60 m，巡航 +25 % / 盘旋 +32 % / 航程 −20 %。

## 打开方式

所有 `.html` 均为**单文件离线页面**：双击即可用浏览器打开，
**不需要服务器、不联网**（灾区无网络的硬约束下这一点很重要）。

`.obj` 可用任意 3D 查看器（Blender / MeshLab / Windows 3D 查看器）打开。
