## 坐标系与单位（重要）

```
X = STA（机头尖 0 → 十字尾翼后缘 1580），Y = 上，Z = 侧向；单位 mm
```

| 部件 | X（STA） | Y | Z |
|:---|:---|:---|:---|
| 机头泡沫（可拆，螺纹口 @300） | 0 ~ 318 | — | — |
| 主体（电池 / 航电 / 翼盒） | 318 ~ 1118 | r = 70 | — |
| 尾杆（插接，粗锥 → 细杆） | 1118 ~ 1580 | r 70 → 30 | — |
| **上翼**（2 片，半展 750） | LE 818 ~ TE 1048 | **+175** | ±750 |
| **下翼**（2 片，半展 700） | LE 860 ~ TE 1100 | **−175** | ±700 |
| 桨盘面（4 × 13″，X 型 90°） | 1460 | 桨心 R 245 | — |
| 十字尾翼（水平片 + 垂直片） | 1500 ~ 1580 | — | — |

**双翼合 AC = STA 895**（上翼 AC 870 / 下翼 AC 920）；gap = 350 mm；合计 S = 0.63 m²。

## 动画：9 阶段时间轴（总 72 s）

| 段 | 时间 | 内容 |
|:---|:---|:---|
| P0 | 0 ~ 2 s | 待发：机头插软地、双翼收拢 |
| P1 | 2 ~ 25 s | **倒拖爬升** 0 → 150 m（翼收拢贴体，不吃桨下洗流） |
| P2 | 25 ~ 26 s | 关机 + 顺桨（0.5 s 内停转） |
| P3 | 26 ~ 34 s | 无动力俯冲增速至 ~24 m/s |
| P4 | 34 ~ 36 s | ☂ **双翼雨伞撑开 + 棘爪自锁** |
| P5 | 36 ~ 42 s | **2.0 g 拉平**（掉高 56 m，净高 60 m） |
| P6 | 42 ~ 44 s | 变距切巡航档 · 重启推进 |
| P7 | 44 ~ 63 s | 巡航侦察 |
| P8 | 63 ~ 72 s | 末端迫降（吸能机头先触地，机头上仰 −12°） |

**交互键**：空格播放/暂停、←/→ 单帧、H 隐藏 UI、循环开关、跟随/全景/环绕三视角。
**URL 参数**：`?ui=0` 隐藏界面（便于直接录屏）、`?t=30` 从 30 s 开始。

## 生成方式（可复现）

1. 参数化建模脚本按 `docs/03` 的站位表生成 OBJ；
2. 用模板 HTML 内联（three.js + OBJ 文本），打包成**单文件离线 HTML**；
3. 收拢/展开变换链用 Python 复算并做干涉检查；
4. 时间轴关键帧从打包后的 HTML 反解采样，逐条比对硬判据。
