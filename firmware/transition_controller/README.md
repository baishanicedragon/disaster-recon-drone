# transition_controller · 段 I + 段 II 自定义控制器

> **这是全项目技术风险最高的一项（B 级：工程极难但合理可实现，见 [docs/07 7.2.2](../../docs/07-电子系统与PCB设计.md)）。**
> 本目录的 C 代码是**参考实现骨架**：未编译、未单测跑通、未 SITL、未实飞。
> 目的：让使用者清楚"状态怎么切、门控怎么判、与硬件互锁怎么配合"。

---

## 1. 为什么必须自定义

ArduPilot **没有**「机头朝下倒拖爬升 + 关机俯冲 + 双翼撑开 + 2.0 g 拉平」这套剖面，
且它**不是**尾坐（tailsitter）——所以 `Q_ENABLE=0`，**不用 Q_TAILSIT**。

| 段 | 内容 | 谁负责 |
|:--:|:---|:---|
| **段 I** | 倒拖爬升 0 → 150 m（~45 s）：机头朝下、4 桨对转推力竖直向上；**被动摆式稳定**为主，差动推力只做阻尼 | **自定义**（`dragclimb_ctrl.c`） |
| **段 II** | 关机 → 俯冲增速 → 门控撑开 → 2.0 g 拉平 → 棘轮切巡航档 → 重启推进 | **自定义**（`deploy_ctrl.c`） |
| 段 III/IV | 巡航、盘旋、返航 | **ArduPilot 原生**（AUTO + 地形跟随） |

> 平飞段不要自己写：地形跟随、RTL、自动降落都是**已大量实飞验证**的能力。
> 从零重写 = 项目失败率翻倍（[firmware README](../../README.md)）。

## 4. 门控真值表（`deploy_ctrl.c` / `tests/test_deploy_gate.c`）

| 空速 ≥ 20.9 | 高度 ≥ 90 | `IL_DEPLOY_OK`（硬件） | 结果 |
|:---:|:---:|:---:|:---|
| ✓ | ✓ | ✓ | **GATE_OPEN** → 撑开 |
| ✗ | ✓ | ✗ | `GATE_WAIT` → 继续俯冲增速 |
| ✓ | ✗ | ✗ | **高度已不足 → `GATE_ABORT_PROFILE`**（机头朝下迫降） |
| ✓ | ✓ | ✗ | `GATE_WAIT` —— **硬件互锁优先**，即使软件认为够也不撑开 |
| ✗ | ✗ | ✗ | `GATE_ABORT_PROFILE` |

> ⚠ **`IL_DEPLOY_OK` 是硬线信号**（动压开关 ∧ 高度比较，与门后**物理解锁**棘爪、弹簧驱动无舵机）。
> 软件判据**只用于状态机进度与日志**，**不能**作为解锁依据（[hardware/interface/pinmap.md](../../hardware/interface/pinmap.md)）。

## 5. 与硬件互锁的配合

| 信号 | 本目录代码如何使用 |
|:---|:---|
| `IL_DEPLOY_OK` | 门控的**必要条件**；断线 → 永不 `GATE_OPEN` |
| `IL_WING_LOCK_L/R` | 撑开后确认锁定；未锁 → 不进 `FLARE` |
| `IL_RATCHET_CRUISE` | `RESTART` 前确认棘轮已切巡航小距档；未锁 → **拒绝重启电机** |
| `IL_NOSE_1..4` | 串联在电机供电通路；未到位 → 物理断电（**不由本代码决定**） |

## 6. 分步验证（**强烈建议，别直接合全剖面**）

1. **系留测倒拖爬升** —— 只验证「推力 + 阻尼」，不追求全姿态闭环（垂直上升 + 摆式稳定下，开环大概率成立）；
2. **滑翔机投放测无动力改平** —— 不装电机，只验证关机→俯冲→撑开→拉平的气动时序；
3. **全剖面合练** —— 前三步都过再合。

SITL 中至少跑通（[firmware README](../../README.md)）：

- [ ] 倒拖爬升段（注入无空速姿态扰动）
- [ ] 关机 → 俯冲 → **门控（20.9 m/s ∧ 90 m）** → 2.0 g 拉平 → 平飞
- [ ] 地形跟随（加载本地 DEM）
- [ ] 盘旋（LOITER_TURNS / LOITER_TIME）
- [ ] GNSS 关断 120 s 的航位推算
- [ ] 能量管理规则触发返航
- [ ] **每个状态机转移至少触发一次（含 `GATE_ABORT_PROFILE` 备用剖面）**

## 7. 已知简化（落地时必须补）

| 简化 | 说明 |
|:---|:---|
| 段 I 不做全姿态闭环 | 设计如此（摆式稳定 + 阻尼），但**横向 CG < 3 mm** 是前提，必须实测 |
| 关机前未减速 | 若爬升速率 > 1 m/s，应先减速再关机，减少上飘过冲 |
| 拉平未建模气动非线性 | 2.0 g 上限靠限幅，未做增益调度 |
| 未含失效保护细节 | 交给 ArduPilot + [docs/12](../../docs/12-测试与验证流程.md) |
