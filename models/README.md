# models/ · 检测模型训练说明

> **本目录不存放任何模型权重。**
> 权重涉及第三方许可（YOLOv5/YOLOv8 为 **AGPL-3.0**），且体积大，不入库。
> 这里只放**训练与量化流程**。

---

## 诚实的定位

> **YOLO 在这个任务里不是"判定"，是"打点提示"。**
> **12 MP 影像的人工判读才是主手段。**

原因很简单：

```
在 250 m 高度、GSD 6.5 cm 下：
  一个 1.7 m 的人体 ≈ 1.7 / 0.065 ≈ 26 像素
  → 这属于 YOLOv8n 的**小目标困难区**
  → 召回率能有 50~70 % 就算不错
```

**不要指望它。** 用它把 279 张影像筛成 30 张"疑似有人"的，交给人工看。
这才是它的价值。

## 类别定义

| ID | 类别 | 说明 | 优先级 |
|:--|:---|:---|:---|
| 0 | `person` | 人体（站立/俯卧/部分掩埋） | **最高** |
| 1 | `vehicle` | 车辆、工程机械 | 高 |
| 2 | `structure` | 建筑残骸、屋顶 | 中 |
| 3 | `cross_red` | 回收场红布十字标 | 高（迫降用） |
| 4 | `debris` | 大型堆积物 | 低 |

## 数据集策略

### ⚠ 伦理红线

**本仓库不使用、不收集、不分发任何真实灾区影像，尤其涉及遇难者的影像。**

### 可用数据

| 来源 | 内容 | 备注 |
|:---|:---|:---|
| COCO | `person`、`car`、`truck` | 通用，域差大 |
| **VisDrone** | 航拍小目标（人/车） | **最贴近本场景的公开数据** |
| DOTA | 航拍旋转框 | 大目标为主 |
| 自建 | 本地相似环境自行采集 | **必需**（见下） |

### 域适应是最大的问题

公开数据集里没有"淤泥覆盖的残骸""部分掩埋的人体""灰褐色单调地表"。
**直接拿 COCO 训出来的模型，在灾区影像上大概率很差。**

**缓解（按有效性排序）：**

1. **自建数据**：在本地河滩、工地、山地道路采集，**人工标注**；
2. **合成增强**：
   - 颜色变换到泥灰色系（HSV 扰动 + 色偏）；
   - 随机遮挡（模拟掩埋：从下方裁剪）；
   - 低对比度、雾霾、阴影；
   - 随机旋转（盘旋时目标方向任意）；
3. **小目标专项**：
   - 训练时用 **tile / mosaic** 增强；
   - 输入分辨率**不要低于 640**（若算力允许）；
   - 考虑 **SAHI**（切片推理）在后处理阶段提升小目标召回。

## 训练流程

```bash
# 1. 环境
pip install ultralytics

# 2. 准备数据（YOLO 格式）
#    dataset/
#      images/{train,val}/*.jpg
#      labels/{train,val}/*.txt
#      data.yaml

# 3. 训练（示例）
yolo detect train \
  model=yolov8n.pt \
  data=dataset/data.yaml \
  imgsz=640 \
  epochs=200 \
  batch=16 \
  mosaic=1.0 \
  device=0

# 4. 验证（**重点看小目标召回**）
yolo detect val model=runs/detect/train/weights/best.pt data=dataset/data.yaml

# 5. 导出 ONNX
yolo export model=best.pt format=onnx imgsz=256
```

**关键指标**（按优先级）：

1. `person` 类的 **recall @ conf=0.25**（宁可误报，不要漏）
2. `person` 类的 **PR 曲线下面积**
3. **误报数/帧**（太高会让人工判读失去意义）

## 量化与部署

```
best.pt
   ↓  yolo export format=onnx imgsz=256
best.onnx
   ↓  量化（INT8，**必须**——NPU 只跑整数）
   │   · X-CUBE-AI（STM32N6）
   │   · NNCASE（K210）
   │   · TFLite Micro + 全整数量化
   ↓
model_int8.bin   →  烧进视觉 MCU 的 Flash
```

**量化要点：**

| 项 | 说明 |
|:---|:---|
| 校准集 | **必须用代表性数据**（至少 100 张，含泥灰色调、小目标） |
| 精度损失 | INT8 通常 mAP 掉 2~4 个点，可接受 |
| 输入尺寸 | 256×256（STM32N6 目标 ≥ 15 fps）；若算力允许可上 320 |
| 逐层检查 | 用工具看哪些层量化误差大（通常是检测头） |

## 评估协议（**必须做，否则不知道模型能不能用**）

| 步骤 | 做法 |
|:---|:---|
| 1 | 在本地相似环境布设 **1.7 m 人体靶 ×5、车辆靶 ×3**（不同姿态、部分遮挡） |
| 2 | 按任务剖面（250 m AGL、盘旋）实飞采集 |
| 3 | 跑模型，统计：真检 / 漏检 / 误报 |
| 4 | 与**人工判读**结果比对（人工判读作为"真值上限"） |
| 5 | 记录：召回率、精确率、平均置信度 |

**验收判据**：`person` 召回 ≥ 50 %（目标 70 %），误报 ≤ 5 / 帧。
