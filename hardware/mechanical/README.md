## 2. 材料

| 部位 | 材料 | 理由 |
|:---|:---|:---|
| 主承力杆 | 碳纤维圆管（缠绕） | 轴向承载为主，比刚度高 |
| 隔框 FR-1~FR-4 | 碳板 / 玻纤板（2~3 mm） | 传力 + 设备安装基准 |
| 半翼 | 碳管梁 + 翼肋 + 蒙皮（轻木/泡沫夹心） | 半翼 ≤ 750 mm，整段进桶不分断 |
| **机头吸能段** | **EPP 泡沫**（可更换分层） | 让耗材去变形，贵重件待在不变形区（[docs/04](../docs/04-结构设计与材料.md)） |
| 撑开/锁销机构 | 金属（铝/钢）+ 弹簧 | **弹簧驱动无舵机**（[docs/11 阶段 9](../docs/11-施工顺序与装配工艺.md)） |

## 4. 出图规范

| 项 | 规则 |
|:---|:---|
| 2D 切割件 | 导出 **DXF**（R12 兼容），单位 mm，**1:1**，图层分"外轮廓/内孔/刻线" |
| 3D 装配 | 导出 **STEP**（AP214），用于干涉检查与运动仿真 |
| 图纸 | **PDF**，含：三视图、关键尺寸与公差、材料、表面处理、版本号 + 日期 |
| 关键公差 | 翼锁销孔 **±0.1 mm**；主承力杆同轴度 ≤ 0.2 mm；撑开机构配合间隙 0.1~0.2 mm |
| 版本 | 每份图纸右下角标注 `件号 / 版本 / 日期 / 材料 / 数量` |
| 命名 | `FR-1_v1.2_2026-09-10.dxf`、`WING-UPPER-L_v1.0.step` |

## 5. 各子件要点

### 5.1 隔框 FR-1~FR-4

- FR 是**设备安装基准**：飞控载板、配电板、数据舱、电池舱各自有框位；
- 框上预置**减振安装点**（软胶 30~50 Shore A）用于 IMU；
- 框的开孔避让主线束与 ESC 走线，**大电流路径不与信号线共孔**。

### 5.2 双翼与钻石背机构

- 4 片半翼（上 L/R、下 L/R），**主翼免装**（快拆挂体）；
- 钻石背**两段折**收拢：地面收拢 → 升空后**雨伞式被动撑开**（一次性，弹簧驱动）；
- 撑开门控是**硬件互锁** `IL_DEPLOY_OK`（动压 ≥ 1.1 Vs **且** 高度 ≥ 90 m，硬线与门后物理解锁）；
- 下翼按设计**可剪断脱落**耗能（v0.4 已删腹滑橇）。

### 5.3 吸能机头

- EPP **分层**溃缩，按 15 m/s + 3 m/s 工况设计；
- **可更换**：1 次任务 1 个；
- `IL_NOSE_1..4` 到位检测**串联在电机供电通路**（断线即切断电机供电，**不允许只做软件判断**）。

### 5.4 装配型架 jigs

- 型架保证：翼面**安装角**、上反角、双翼 gap 350 mm、前后缘对齐；
- 型架同时充当**互锁装配工装**——销孔位置由型架定位，避免手工配钻造成锁销虚位。

## 6. 检查清单

- [ ] 半翼 ≤ 750 mm，收拢后 ⌀480 mm 能进桶（**实物试装**）
- [ ] 双翼 gap 350 mm、AC 落 STA 895（与气动核算一致）
- [ ] 撑开机构**地面反复收放 ≥ 50 次**无卡滞、无塑性变形
- [ ] 锁销孔 ±0.1 mm，锁销到位信号可靠（常闭微动，断线判未锁）
- [ ] 机头 EPP 按工况做**落锤/跌落**验证，与 [docs/06](../docs/06-末端迫降与泡沫机头吸能.md) 目标一致
