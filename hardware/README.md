## 全局接口定义（`interface/pinmap.md` 摘要）

### 电源

| 网络 | 电压 | 最大电流 | 备注 |
|:---|---:|---:|:---|
| `VBAT` | 33.6 ~ 50.4 V（12S） | 90 A 峰值 | 主母线 |
| `VCC_12V` | 12 V | 15 A | 伺服 |
| `VCC_5V_FC` | 5 V | 8 A | 飞控 + 传感器 |
| `VCC_5V_VIS` | 5 V | 3 A | 视觉 MCU |
| `VCC_19V_CAM` | 19 V | 2 A | 12 MP 相机 |
| `VBACKUP` | 7.4 V（2S） | 1 A | 后备，保证断电后完成写入 |

### 信号总线

| 总线 | 设备 | 速率 |
|:---|:---|:---|
| CAN | 电调遥测、BMS、配电板 | 1 Mbps |
| I2C | 气压计 ×2、INA226 ×2、磁罗盘 | 400 kHz |
| SPI | IMU 主/备（**独立片选**） | 10 MHz |
| UART1 | GNSS | 115200 |
| UART2 | 视觉 MCU ↔ 飞控（MAVLink 隧道） | 921600 |
| UART3 | LoRa 遥测 | 57600 |
| UART4 | LoRa 信标 | 9600 |
| DShot1200 | 4 × 电调 | — |
| MIPI CSI-2 | 12 MP 相机 → Linux 小板 | — |

### 互锁信号（**硬件层，见 docs/11 阶段 9**）

| 信号 | 类型 | 失效安全方向 |
|:---|:---|:---|
| `IL_DEPLOY_OK` | 数字量（动压开关 + 高度比较，硬线） | 断线 → 禁止展翼 |
| `IL_WING_LOCK_L/R` | 数字量（常闭微动） | 断线 → 未锁定 |
| `IL_NOSE_1..4` | 数字量 | 断线 → 未到位 → **切断电机供电** |
| `IL_PAYLOAD_OK` | 数字量 | 断线 → 禁止 ARM |
| `IL_RATCHET_CRUISE` | 数字量（棘轮巡航档微动） | 断线 → 禁止电机重启（平飞） |

> **互锁实现**：
> - **IL-3（吸能头到位）必须通过继电器/固态开关串联在电机供电通路里，不允许只做软件判断。**
> - **IL-1（展翼门控）**：动压 ≥ 1.1 Vs **且** 高度 ≥ 90 m，两个硬线信号与门后**物理解锁**展翼舵机，
>   不依赖飞控软件值（见 [docs/11 阶段 9](../docs/11-施工顺序与装配工艺.md)）。
> - **IL-5（巡航档确认）**：棘轮未锁巡航小距档 → 电机重启指令被硬件拒绝。

## 设计规范

| 项 | 要求 |
|:---|:---|
| 最小线宽/间距 | ≥ 0.2 mm（常规）；主回路按载流计算 |
| 主回路铜厚 | **2 oz 起**，大电流路径开窗镀锡 |
| 载流宽度 | 2 oz 外层 60 A → ≥ 25 mm（或双面并联 + 过孔阵列） |
| 过孔 | 主回路 ⌀0.5 mm × ≥ 12 个阵列 |
| **爬电距离** | 按**海拔 5000 m** 修正（间距 ×1.4）；满充 50.4 V 端子 ≥ 1.5 mm，必要时开槽 |
| 三防 | 全部 PCBA 涂三防漆（高原低气压 + 湿热） |
| 接地 | 单点接地；屏蔽层单端接地 |
| 丝印 | 每个接插件标注信号名与方向 |
| 版本 | 每块板丝印版本号 + 日期 |

## KiCad 约定

- 版本：**KiCad 8+**；
- 库：自建库放 `hardware/pcb/lib/`（符号 + 封装 + 3D 模型）；
- 每个工程根目录放 `README.md`，说明：功能、接口、BOM、测试点；
- 提交前跑 ERC / DRC，**零 Error**（Warning 需在 README 中说明理由）；
- 生成 Gerber 放 `gerbers/`（已被 .gitignore 排除，按需本地生成）。
