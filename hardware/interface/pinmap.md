# interface/pinmap.md · 全局接口与引脚定义（**唯一真源**）

> **本文件是硬件与固件之间唯一的信号真源。**
> [docs/07](../docs/07-电子系统与PCB设计.md) 定"用哪些芯片"，本文件定"每个信号落哪个脚、走什么规则"。
> [docs/18 示例代码](../docs/18-软件实现示例代码-机载固件.md) 里所有句柄（`WING_LOCK_GPIO[4]`、`SMOKE_GPIO` …）都必须能在本表查到物理落点。
>
> ⚠ **引脚号为示例分配**，按 **STM32H743VI（LQFP100）** 示例封装给出。
> 换封装、换飞控板、换视觉 MCU 时**必须重新核对官方数据手册**并重算复用功能（AF）映射。
> ⚠ 凡标注 **`HW-IL`** 的信号为**硬件互锁**：断线/失效方向已定死，**不允许只做软件判断**（[docs/11 阶段 9](../docs/11-施工顺序与装配工艺.md)）。

---

## 1. 电源网络

| 网络 | 电压 | 最大电流 | 来源 | 去向 |
|:---|---:|---:|:---|:---|
| `VBAT` | 33.6 ~ 50.4 V（12S） | 90 A 峰值 | XT90 输入 | 主配电板 → 4× ESC |
| `VCC_12V` | 12 V | 15 A | BEC 12V/15A | 6× 舵机 |
| `VCC_5V_FC` | 5 V | 8 A | BEC 5V/8A | 飞控 + IMU + GNSS + 空速 + 气压 |
| `VCC_5V_VIS` | 5 V | 3 A | BEC 5V/3A | 视觉 MCU（STM32N6） |
| `VCC_19V_CAM` | 19 V | 2 A | BEC 19V/2A | 12 MP 相机 + Linux 小板 |
| `VCC_3V3` | 3.3 V | 2 A | 板上 LDO | 逻辑、CAN 收发、LoRa |
| `VBACKUP` | 7.4 V（2S 200 mAh） | 1 A | 后备锂电 | **断电后完成写盘**（[docs/07 7.5.3](../docs/07-电子系统与PCB设计.md)） |

> `VBACKUP` 是**写入可靠性三保险之一**：主电断开后仍要完成当前帧写入 + 关闭文件系统，然后才全断。

## 2. 总线分配

| 总线 | 设备 | 速率 | 走线要点 |
|:---|:---|---:|:---|
| CAN | 电调遥测、BMS、配电板 | 1 Mbps | 差分，总线两端各 1× 120 Ω 终端，支线 ≤ 0.3 m |
| I²C1 | 气压计 ×2（DPS310）、INA226 ×2、磁罗盘 | 400 kHz | 上拉 2.2 kΩ@3V3，总线电容 < 400 pF |
| SPI1 | IMU 主 / 备（**独立片选**） | 10 MHz | 长度 ≤ 150 mm，串 22~33 Ω |
| USART1 | GNSS（u-blox M10 / F9P） | 115200 | 走顶层，远离 DShot |
| USART2 | 视觉 MCU ↔ 飞控（MAVLink 隧道） | **921600** | 走线 ≤ 100 mm，**禁止**与 DShot 平行 |
| USART3 | LoRa 遥测 | 57600 | — |
| UART4 | LoRa 信标 | 9600 | — |
| DShot1200 | 4 × 电调 | — | 单线，每路串 100 Ω，短走线 |
| SDIO | microSD ×2（镜像） | — | 等长，参考层完整 |
| MIPI CSI-2 | 12 MP 相机 → Linux 小板 | — | 100 Ω 差分，对内等长 ±0.15 mm |

## 3. 飞控 MCU 引脚分配（示例 · STM32H743 LQFP100）

| 引脚 | 信号 | 方向 | 对端 | 备注 |
|:---|:---|:---:|:---|:---|
| PA9 / PA10 | `USART1_TX/RX` | ↔ | GNSS | 115200 |
| PD5 / PD6 | `USART2_TX/RX` | ↔ | 视觉 MCU | **921600**，MAVLink 隧道 |
| PD8 / PD9 | `USART3_TX/RX` | → | LoRa 遥测 | 57600，单向下行 |
| PC10 / PC11 | `UART4_TX/RX` | → | LoRa 信标 | 9600，10 s 一帧 |
| PB8 / PB9 | `I2C1_SCL/SDA` | ↔ | 气压 ×2 / INA226 ×2 / 罗盘 | 400 kHz |
| PA5 / PA6 / PA7 | `SPI1_SCK/MISO/MOSI` | ↔ | IMU | 10 MHz |
| PE3 | `SPI1_CS_IMU_MAIN` | → | IMU 主（BMI088 级） | 独立片选 + 独立中断 |
| PE4 | `SPI1_CS_IMU_BKUP` | → | IMU 备（**不同型号**） | 防共模失效 |
| PD0 / PD1 | `CAN1_RX/TX` | ↔ | CAN 收发器 | 1 Mbps |
| PE9 / PE11 / PE13 / PE14 | `DShot1..4`（TIM1 CH1-4） | → | ESC 1~4 | DShot1200 |
| PA0 | `ADC1_IN0` `WIRE_SENSE` | ← | 导线导通分压 | 对应 18 章 `WIRE_ADC_CH` |
| PA1 | `ADC1_IN1` `IBAT_SENSE` | ← | 分流器 100 A/75 mV | — |
| PC0 ~ PC3 | `WING_LOCK_0..3` | ← | **翼锁销微动 ×4** | 对应 18 章 `WING_LOCK_GPIO[4]` |
| PC4 ~ PC7 | `PROP_FEATHER_0..3` | ← | **桨顺桨开关 ×4** | 对应 18 章 `PROP_FEATHER_GPIO[4]` |
| PC8 | `SMOKE_FIRE` | → | 烟雾 MOSFET | 对应 18 章 `SMOKE_GPIO` |
| PC9 | `MAIN_CONTACTOR` | → | 主接触器 / 理想二极管 | 对应 18 章 `power_cut()` |
| PD2 | **`IL_DEPLOY_OK`** | ← | 动压开关 ∧ 高度比较（**硬件与门**） | `HW-IL` 断线 → 禁止撑开 |
| PD3 | **`IL_WING_LOCK_L`** | ← | 左翼锁（常闭微动） | `HW-IL` 断线 → 未锁定 |
| PD4 | **`IL_WING_LOCK_R`** | ← | 右翼锁 | `HW-IL` |
| PD5~PD7, PB3 | **`IL_NOSE_1..4`** | ← | 吸能机头到位 | `HW-IL` 断线 → **切断电机供电** |
| PE0 | **`IL_PAYLOAD_OK`** | ← | 数据舱到位 | `HW-IL` 断线 → 禁止 ARM |
| PE1 | **`IL_RATCHET_CRUISE`** | ← | 棘轮巡航档微动 | `HW-IL` 断线 → 禁止电机重启 |
| PB4 / PB5 / PB0 | `LED_R/G/B`（TIM3 CH1-3） | → | RGB 状态灯 | 15.5.1 灯语义 |
| PE15 | `CAM_TRIG` | → | 相机等距触发 | 09 章 9.2 |
| PC12 | `SDIO_D0`（+ 其余 SDIO 脚） | ↔ | microSD ×2 | 镜像写 |
| PA13 / PA14 | `SWDIO / SWCLK` | ↔ | 调试口 | 留出 4-pin SWD |

> 复用功能（AF）编号、DMA 通道、定时器通道**必须**用 STM32CubeMX 生成后逐一核对，本表只定"信号名 ↔ 物理脚"的映射意图。

## 5. 互锁信号（**硬件层，`HW-IL`**）

| 信号 | 类型 | 失效安全方向 | 实现要求 |
|:---|:---|:---|:---|
| `IL_DEPLOY_OK` | 数字量（动压开关 ∧ 高度比较，硬线） | 断线 → **禁止撑开** | 动压 ≥ 1.1 Vs（20.9 m/s）**且** 高度 ≥ 90 m；与门后**物理解锁**棘爪（弹簧驱动，无舵机） |
| `IL_WING_LOCK_L/R` | 数字量（常闭微动） | 断线 → 未锁定 | — |
| `IL_NOSE_1..4` | 数字量 | 断线 → 未到位 → **切断电机供电** | **必须串联在电机供电通路**（继电器/固态开关），**不允许只做软件判断** |
| `IL_PAYLOAD_OK` | 数字量 | 断线 → 禁止 ARM | — |
| `IL_RATCHET_CRUISE` | 数字量（棘轮巡航档微动） | 断线 → 禁止电机重启 | 未锁巡航小距档 → 电机重启指令被**硬件拒绝** |

## 6. 接插件定义

| 编号 | 型号 | 信号 | 备注 |
|:---|:---|:---|:---|
| J1 | XT90 | `VBAT` / GND | 主电输入，反接保护（理想二极管） |
| J2 | 4× 子弹座 / MR30 | `DShot1..4` + ESC 供电 | 每路并 470 µF |
| J3 | DF13 / JST-GH 8p | 飞控载板 ↔ 主配电 | CAN + 12V + 5V + GND |
| J4 | JST-GH 10p | 数据舱 ↔ 飞控 | USART2 + 5V_VIS + 触发 + GND |
| J5 | MIPI 40p | 相机 → Linux 小板 | 屏蔽，扣具固定 |
| J6 | JST-GH 4p | LoRa 遥测 | USART3 |
| J7 | JST-GH 4p | LoRa 信标 | UART4 |
| J8 | SWD 4p | 调试 | 丝印标注 1 脚方向 |
| J9 | JST-GH 6p | 舵机总线 | 12V + 6× PWM |

> 每个接插件**丝印标注信号名与方向**（[hardware README 规范](../README.md)）；所有大功率接插件做**防呆**（不同 pin 数/键位）。

## 7. 走线基本规则（芯片组级）

| 类别 | 规则 |
|:---|:---|
| **CAN** | 特性阻抗 120 Ω；总线两端各 1 只 120 Ω 终端（**中间节点不接**）；支线 ≤ 0.3 m；远离功率回路 ≥ 10 mm |
| **I²C** | 400 kHz；上拉 2.2 kΩ@3V3；总线电容 < 400 pF；SDA/SCL 并行走、等长；**远离 DShot 与电机线** |
| **SPI** | 10 MHz；长度 ≤ 150 mm；源端串 22~33 Ω；IMU 主/备**独立片选 + 独立中断**；下方参考层完整，禁止跨分割 |
| **UART（921600）** | 视觉隧道走线 ≤ 100 mm；**禁止**与 DShot 平行走线；必要时用地线隔离（guard trace） |
| **DShot1200** | 每路串 100 Ω；尽量短；**远离**气压计/模拟前端；不与模拟信号长距离平行 |
| **MIPI CSI-2** | 100 Ω 差分；对内等长 ±0.15 mm；差分对间 ≥ 3W；参考层**完整不分割**；禁止在差分对下打过孔换层（若必须换层，就近加回流地过孔） |
| **SDIO** | 数据/时钟等长 ±0.5 mm；参考层完整 |
| **电源（主回路）** | 2 oz 起；60 A 外层需 ≥ 25 mm（或双面并联 + 过孔阵列）；过孔 ⌀0.5 mm × ≥ 12 阵列；大电流路径**开窗镀锡或加铜条** |
| **爬电** | 按**海拔 5000 m** 修正（间距 ×1.4）；满充 50.4 V 端子 ≥ 1.5 mm；必要时**开槽**；全部 PCBA **涂三防漆** |
| **地** | 功率地与信号地**单点连接**；4 层板保留完整地平面；屏蔽层**单端接地** |
| **丝印/版本** | 每块板丝印版本号 + 日期 + 信号名与方向 |
