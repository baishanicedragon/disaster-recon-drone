# pcb/payload-board · 数据舱主板

> **状态：设计规则，非可用工程。**
> 本板是**写入可靠性的核心**：撞击后主电断开，仍要完成当前帧写入并关闭文件系统（[docs/07 7.5.3](../docs/07-电子系统与PCB设计.md)）。

---

## 1. 规格

| 项 | 值 |
|:---|:---|
| 层数 / 铜厚 | **4 层，1 oz**；STM32N6 为 BGA，**建议 1 阶 HDI（1+N+1）或 via-in-pad + 电镀填平** |
| 尺寸 | 90 × 50 mm |
| 主控 | STM32N6（Cortex-M55 @800 MHz + Neural-ART NPU） |
| 存储 | 8/16 MB OctoSPI Flash（模型 + 固件）+ 32 MB HyperRAM（推理工作区）+ microSD ×1（主） |
| 成像 | CSI-2 → 全局快门 CMOS（OV9282 / AR0234 级，1~2 MP）；12 MP 相机独立走 MIPI → Linux 小板 |
| 后备电 | 2S 200 mAh + 充电管理（**关键**） |
| 对外 | UART → 飞控（MAVLink 隧道 921600）、USB-C（地面取数/调试） |

---

## 2. 关键器件（含封装）

| 器件 | 建议型号 | 封装 | 备注 |
|:---|:---|:---|:---|
| 视觉 MCU | STM32N6 | **BGA**（0.65/0.8 mm pitch，按具体型号定） | 需 HDI 扇出 |
| OctoSPI Flash | 8/16 MB | SOP-16 / WSON | 模型 + 固件 |
| HyperRAM | 32 MB | BGA-24 / WLCSP | 推理工作区 |
| 全局快门 CMOS | OV9282 / AR0234 级 | 模组 + FPC | 识别通道（低延迟） |
| IMU（帧间去抖） | BMI270 | LGA-14 | 与主 IMU 用途不同 |
| microSD 座 | 推挽式 | 贴片 | U3/V30 ≥ 256 GB |
| 后备锂电 | 2S 200 mAh | 带线 | + 充电管理 IC |
| PMIC / 电源树 | 多路 DC-DC + LDO | QFN | 3V3 / 1V8 / core |
| USB-C | 16p | 贴片 | 取数 + 调试 |

---

## 3. 走线规则（芯片组级）

| 类别 | 规则 |
|:---|:---|
| **MIPI CSI-2** | **100 Ω 差分**；对内等长 **±0.15 mm**；差分对间 **≥ 3W**；参考层**完整不分割**；**禁止**在差分对下打过孔换层（必须换层时，就近加**回流地过孔**） |
| **OctoSPI** | 阻抗 **50 Ω**；组内等长 **±0.25 mm**；长度 ≤ 80 mm；时钟与数据同层同参考面；远离 CSI-2 与射频 |
| **HyperRAM** | 同 OctoSPI：50 Ω、等长 ±0.25 mm；地址/控制/时钟组间等长 |
| **SDIO** | 数据/时钟等长 **±0.5 mm**；参考层完整；卡座外壳接地 |
| **BGA 扇出** | 建议 **via-in-pad + 电镀填平** 或 1 阶 HDI；0.1 mm 线宽/线距起步；**先确认板厂工艺能力**再定 pitch |
| **去耦** | BGA 背面密布 **0402 100 nF**（每个电源/地平对就近放置）+ 每电源域 1× 10 µF + 1× 1 µF；去耦过孔紧邻焊盘 |
| **电源树** | MCU core / IO / HyperRAM / Flash 分域供电；上电时序按 STM32N6 手册；每域留测试点 |
| **后备电切换** | 用理想二极管 / PMIC 无缝切换；主电掉落后 **VBACKUP 立即接管**，保证 ≥ 200 ms 写盘窗口 + 关文件系统 |
| **分区** | 模拟（CSI 电源）/ 数字 / 射频分区；磁珠或 0 Ω 隔离，单点连接 |
| **三防 / 爬电** | 全部涂三防漆；本板无高压，爬电要求低于配电板 |

---

## 4. 测试点

| 测试点 | 信号 | 用途 |
|:---|:---|:---|
| TP1 | `VCC_5V_VIS` | 输入供电 |
| TP2 | MCU core 电压 | 上电时序验证 |
| TP3 | `VBACKUP` | **后备电切换验证**（掉电不断写） |
| TP4 | CSI-2 时钟 | 差分波形/眼图 |
| TP5 | SDIO 时钟 | 写盘时序 |
| TP6 | `USART2_TX` | MAVLink 隧道 |

---

## 5. 检查清单（**写入可靠性是重点**）

- [ ] ERC / DRC 零 Error；BGA 扇出 100 % 完成，无遗漏电源/地焊盘
- [ ] CSI-2 差分阻抗实测 100 Ω ±10 %，对内等长达标
- [ ] OctoSPI / HyperRAM 读写压力测试无 ECC 错误
- [ ] **掉电测试**：满速写盘时拔主电 → microSD 文件**不损坏**、最后帧完整、文件系统已关闭
- [ ] 后备电容量实测可覆盖 ≥ 200 ms 写盘 + 关 FS
- [ ] 循环落盘每 5 s `fsync`（[docs/18 18.10](../docs/18-软件实现示例代码-机载固件.md)）
- [ ] 双卡镜像：两张 microSD 同时写，任一可读即可
