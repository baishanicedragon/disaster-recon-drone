# pcb/power-distribution · 主配电板

> **状态：设计规则，非可用工程。** 本文件给出"照着能画出来"的规则与器件清单，不含 Gerber/原理图文件。
> 引脚与网络名以 [../../interface/pinmap.md](../../interface/pinmap.md) 为唯一真源。

---

## 1. 规格

| 项 | 值 |
|:---|:---|
| 层数 / 铜厚 | **2 层，2 oz**（大电流路径开窗镀锡或加铜条） |
| 尺寸 | 100 × 60 mm |
| 输入 | XT90，12S（33.6 ~ 50.4 V），**峰值 90 A / 持续 60 A** |
| 输出 | 4 × ESC（DShot1200 + 供电）、BEC 12V/15A、5V/8A、5V/3A、19V/2A |
| 遥测 | INA226 ×2（母线电流/电压 → I²C） |
| 保护 | 主保险 200 A、反接保护（**理想二极管**，非肖特基）、预充 |

## 3. 走线规则

| 项 | 规则 |
|:---|:---|
| 主回路铜厚 | **2 oz 起**；大电流路径**开窗镀锡**或加铜条（载流 60 A 峰值 90 A） |
| 载流宽度 | 2 oz 外层 60 A → **≥ 25 mm**（或双面并联 + 过孔阵列） |
| 过孔 | 主回路 ⌀0.5 mm × **≥ 12 个阵列** |
| 电容布置 | ESC 输入电容**紧贴**接插件；母线电容靠近接触器输出 |
| 爬电距离 | 50.4 V 满充属 SELV，但**高原低气压**（2750 m ≈ 72 kPa，绝缘强度 −25 %）→ 按**海拔 5000 m 修正（间距 ×1.4）**，端子 ≥ 1.5 mm，必要时**开槽** |
| 三防 | 全部 PCBA **涂三防漆** |
| 地 | 功率地与信号地**单点连接**；2 层板功率地铺铜，避免环路包围敏感信号 |
| 分流器采样 | **开尔文四线**走差分，远离大电流铜皮与开关节点 |
| I²C | 上拉 2.2 kΩ@3V3，**远离** DShot 与电机线 |

## 4. 测试点（必须留出）

| 测试点 | 信号 | 用途 |
|:---|:---|:---|
| TP1 / TP2 | `VBAT` / GND | 输入电压 |
| TP3 / TP4 | 分流器差分 | 母线电流（INA226 校验） |
| TP5 | `VCC_12V` | 伺服供电 |
| TP6 | `VCC_5V_FC` | 飞控供电 |
| TP7 | `VCC_5V_VIS` | 视觉供电 |
| TP8 | `VCC_19V_CAM` | 相机供电 |
| TP9 | NTC | 板温（1 Hz 记入配电日志，[docs/09 9.6](../../../docs/09-软件架构与识别算法.md)） |

## 5. 检查清单（提交前）

- [ ] ERC / DRC **零 Error**（Warning 需在 README 说明理由）
- [ ] 载流宽度按 2 oz / 60 A 复核，温升估算 < 30 K
- [ ] 爬电按海拔 5000 m 修正，高压端子 ≥ 1.5 mm
- [ ] 预充回路时序验证（上电浪涌不误触发保险）
- [ ] 反接保护实测（反接不上电、不损器件）
- [ ] INA226 读数与台表对比，误差 < 2 %
- [ ] 满负载 30 min 热成像，热点 < 85 ℃
