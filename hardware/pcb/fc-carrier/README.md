# pcb/fc-carrier · 飞控载板

> **状态：设计规则，非可用工程。** 本板**不实现飞控**——飞控用现成 STM32H7 模块（ArduPilot）。
> 载板负责：模块插座、冗余 IMU、接口引出、屏蔽与减振。

---

## 1. 规格

| 项 | 值 |
|:---|:---|
| 层数 / 铜厚 | **4 层，1 oz**（L1 信号 / L2 完整地 / L3 电源 / L4 信号） |
| 尺寸 | 60 × 60 mm |
| 承载 | 飞控模块插座 + **冗余 IMU**（与主 IMU **不同型号**）+ 接口引出 |
| 总线引出 | CAN、SPI（调试）、I²C1、USART1/2/3、UART4、DShot ×4、ADC、GPIO、SWD |

---

## 2. 关键器件（含封装）

| 器件 | 建议型号/等级 | 封装 | 备注 |
|:---|:---|:---|:---|
| 飞控模块 | STM32H7 级开源飞控模块（ArduPilot 兼容） | 模块插座（按模块 datasheet 定） | **不自己画飞控** |
| IMU 主 | BMI088 或 ICM-42688-P 级 | LGA-16 / QFN-24 | 陀螺量程 ≥ ±2000 °/s，噪声 ≤ 0.05 °/s/√Hz |
| IMU 备 | **与主机不同型号** | 同上 | **避免共模失效**（[docs/07 7.3](../../../docs/07-电子系统与PCB设计.md)） |
| 气压计 ×2 | DPS310 / BMP390 | LGA-8 | 相对精度 ±0.03 m |
| 空速 | MS4525DO | SOP-8 / 模块 | ±1 % FS，需引气管 |
| 磁罗盘 | IST8310 / RM3100 | LGA / QFN | ⚠ **峡谷内磁异常严重**，权重调低，仅静态初始化 |
| CAN 收发器 | SN65HVD230 级 | SOIC-8 | 1 Mbps |
| 接插件 | JST-GH 系列 | 贴片 | 按 [pinmap](../../interface/pinmap.md) J3~J9 |

---

## 3. 走线规则（芯片组级）

| 项 | 规则 |
|:---|:---|
| 层叠 | L2 **完整不间断地平面**；信号层禁止在地平面走线 |
| IMU（SPI 10 MHz） | 长度 ≤ 150 mm；源端串 22~33 Ω；**主/备独立片选 + 独立中断** |
| IMU 布局 | **远离**大电流路径与 ESC 线 ≥ 20 mm；IMU **正下方禁止打过孔**、禁止电源/信号分割；下方铺地并多点接地过孔 |
| IMU 减振 | 整板用**软胶减振**（30~50 Shore A）安装到机身；电机座刚性安装（[docs/07 7.8](../../../docs/07-电子系统与PCB设计.md)） |
| 气压计 | 开**透气孔**通大气，避免螺旋桨气流直吹；需**遮光**（阳光直射致温漂）；远离发热器件 |
| I²C | 上拉 2.2 kΩ@3V3；SDA/SCL 并行走；**远离 DShot** |
| CAN | 差分 120 Ω；支线 ≤ 0.3 m；若本板为总线端点则加 120 Ω 跳线终端 |
| DShot1200 | 每路串 100 Ω；短走线；**远离**气压计与模拟前端，禁止长距离平行 |
| 去耦 | 每个 IC 电源脚就近 100 nF（0402）+ 每芯片 1× 10 µF；去耦电容**紧贴**电源脚，回路过孔紧邻 |
| 屏蔽 | 飞控区可加**屏蔽罩**（选配）；屏蔽层**单端接地** |
| 爬电 / 三防 | 无高压，但仍按高原环境**全部涂三防漆** |

## 4. 测试点

| 测试点 | 信号 |
|:---|:---|
| TP1 | `VCC_5V_FC` |
| TP2 | `VCC_3V3` |
| TP3 / TP4 | `CAN_H` / `CAN_L` |
| TP5 / TP6 | IMU 主 / 备中断 |
| TP7 | `USART2_TX`（视觉隧道 921600，便于抓波形） |
| TP8 | `DShot1` |

---

## 5. 检查清单

- [ ] ERC / DRC 零 Error
- [ ] IMU 主/备为**不同型号**且独立 CS/中断
- [ ] IMU 下方无过孔、无地平面分割
- [ ] 气压计有透气孔 + 遮光，远离热源
- [ ] SPI / I²C / CAN 实际波形眼图/边沿合格（无过冲 > 20 %）
- [ ] 静态零偏与噪声达标（[docs/12](../../../docs/12-测试与验证流程.md)）
