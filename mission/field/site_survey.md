## 六项判据（逐项现场判定）

| # | 判据 | 现场简易判据 | 实测 | 合格 |
|:--:|:---|:---|:---|:---:|
| **L-01** | 承载力 **30 ~ 60 kPa** | **鞋跟能踩进 3~5 cm，拔出不粘鞋** | 陷入 ____ cm | ☐ |
| **L-02** | 坡度 **≤ 8°** | 目视基本水平（手机水平仪复核） | ____ ° | ☐ |
| **L-03** | 无 **> 10 cm** 石块 | 目视；可疑处尺量 | 最大石块 ____ cm | ☐ |
| **L-04** | 长 **≥ 120 m** × 宽 **≥ 30 m** | 步测 / 激光测距 | ____ × ____ m | ☐ |
| **L-05** | 进近 **300 m** 无障碍 | 目视（电线、树、陡坎） | ☐ 无 / ☐ 有：____ | ☐ |
| **L-06** | 无积水 / 流沙 | 目视 + 踩踏 | ☐ 无 / ☐ 有 | ☐ |

> **L-01 是唯一需要身体参与的判据**：太硬（踩不进去）→ 冲击过载超标；
> 太软（陷到脚踝、拔鞋费劲）→ 会陷进去取不出来。

## 🚫 绝对禁止（**任一条即否决，不用再往下填**）

| 否决项 | 原因 |
|:---|:---|
| ☐ 泥石流淤积区 | 承载力 < 15 kPa，**会陷** |
| ☐ 水泥 / 沥青 | 零吸能，等同硬地撞击 |
| ☐ 冻土 | 表面硬、下层空，且季节性变化 |
| ☐ 碎石滩 | 石块划穿机头泡沫，且滚动不可控 |
| ☐ 水面 | 数据舱进水，回收即失败 |
| ☐ 坡度 > 15° | 触地后翻滚，结构解体 |
| ☐ 密林 | 无法进近，且挂树取不回 |
