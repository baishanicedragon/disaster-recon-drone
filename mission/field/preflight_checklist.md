# 起飞前检查表（Pre-flight Checklist）

> **在飞之前就把 90 % 的决策做完**（[mission README](../README.md) 核心原则）。
> 本表是**地面表**，与 APP 上的三步检查单（[docs/16 16.7](../../docs/16-安卓APP架构与素材库.md)）**不是一回事**：
> APP 只管「电压 / 限动器 / 导线」这三项硬互锁的**最终确认**，本表管从装配到法规的全流程。
>
> 每格必须有人签字。**任何一格红 → 不起飞。**

## B. 硬件互锁（[hardware/interface/pinmap.md](../../hardware/interface/pinmap.md)）

| # | 信号 | 失效安全方向 | 结果 |
|:--:|:---|:---|:---:|
| B-1 | `IL_NOSE_1..4` | 断线 → 未到位 → **切断电机供电** | ☐ |
| B-2 | `IL_WING_LOCK_L/R` | 断线 → 判未锁定 | ☐ |
| B-3 | `IL_PAYLOAD_OK` | 断线 → 禁止 ARM | ☐ |
| B-4 | `IL_RATCHET_CRUISE` | 断线 → 禁止电机重启 | ☐ |
| B-5 | `IL_DEPLOY_OK` | 断线 → **禁止撑开**（动压 ∧ 高度，硬线与门） | ☐ |

> ⚠ B-1~B-5 是**硬件互锁**，**不允许只做软件判断**。断线必须落在"禁止"侧。

|:--:|:---|:---:|
