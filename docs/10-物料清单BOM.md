## 10.2 成本汇总

> **v0.4 口径（2026-09-09）：随飞件合计 12.54 kg** —— 结构 4.44 + 动力 6.12 + 航电 1.10 + 载荷 0.72 + **双翼撑开机构 0.35**（下详）。
> 结构已**不含尾坐起落架**（v0.3 删除 −0.42 kg）与**腹滑橇**（v0.4 删除 −0.18 kg）；
> 工具/插地环/备用吸能头为地面物资，不计入随飞质量。
>
> **v0.3 → v0.4 质量迁移**：单翼 1.30 → 双翼 4 片 1.50（**+0.20**）；腹滑橇删除（**−0.18**）；
> **双翼撑开机构新增（+0.35）**：弹簧 ×8、连杆 ×8、棘爪锁 ×4、锁销 ×4、微动开关 ×4。
> 12.19 + 0.20 − 0.18 + 0.35 = **12.54 kg**。

| 配置 | 成本 ¥ | 质量 kg |
|:---|---:|---:|
| 结构 + 动力 + 航电 + 载荷（随飞件，不含 F9P 升级） | **16 615** | **12.54** |
| + GNSS 升级 F9P | +950 | +0.08 |
| + 工具与耗材 / 插地环 / 备用吸能头 / 行军桶 ×2 | +2 980 | — |
| **合计（推荐配置，含 F9P）** | **≈ 20 545** | **12.62 kg** ⚠ |

> ⚠ **质量口径**：随飞件基准 **12.54 kg**（低于 02/03/05 章计算用设计点 **12.93 kg**，余量 0.39 kg）；
> 加 F9P 后 **12.62 kg**。**计算章节统一按 12.93 kg 设计点取数（保守），BOM 按实累加取数。**
> T/W 核对（160 N 静推力需求）：12.54 kg → **1.30**；12.62 kg（含 F9P）→ **1.29**；12.93 kg（设计点）→ **1.26**。
> ⚠ **v0.4 的 T/W 已从 v0.3 的 1.34 压到 1.30——正好卡在红线上，没有余量了。**
> 若实测再超重，优先拆（按顺序）：① 前向毫米波（可选，−0.15 kg）；② 双卡镜像 microSD（−0.02 kg）；
> ③ 12S4P → 12S3P（−0.9 kg，航程降到 ~30 km）。**禁止再加装任何非必需载荷。**

## 10.4 关键件替代方案

| 原件 | 替代 | 代价 |
|:---|:---|:---|
| STM32N6 | K210（MaixPy/NNCASE） | 算力下降，帧率 ~10 fps；但生态成熟、资料多 |
| STM32N6 | i.MX RT1170 + TinyMaix | 无 NPU，纯 CPU 跑小模型 |
| u-blox M10 | F9P（双频） | +690 元，峡谷抗多路径显著更好 |
| 12 MP IMX477 | Arducam 5 MP 全局快门 | 分辨率降一半，但无果冻效应 |
| 21700 P45B | Samsung 50S / 国产同级 | 需核对**持续放电 ≥ 45 A** |
| 77 GHz 雷达 | 不做实时避障 | 依赖第 1 层预规划，风险上升 |
| 碳纤缠绕管 | 玻纤管 | +0.3 kg，刚度下降 |
| EPP | **不可用 EPS 替代** | EPS 脆性、吸能差、易碎裂 |

## 10.5 采购风险与提示

| 风险 | 说明 | 应对 |
|:---|:---|:---|
| **21700 电池** | 高倍率型号（≥ 45 A 持续）供货波动；**假货多** | 只在可信渠道买；**逐颗测内阻**，偏差 ≤ 5 mΩ 才配组 |
| **电机推力虚标** | 厂家曲线多为海平面理想值 | **必须实测**（12 章 T-04）；按实测重选桨 |
| **碳纤管质量** | 缠绕角度/含胶量差异大 | 抽样做三点弯曲，比较破坏弯矩 |
| **STM32N6 供货** | 新型号产能爬坡 | 先备 K210 方案做软件验证 |
| **EPP 密度** | 采购到手的实际密度常与标称差 ±15 % | 称重 + 量体积核对；**做压缩试样实测平台应力** |
| **microSD 假卡** | 容量虚标，写入到一半丢数据 | 用 `h2testw` / `F3` 全盘验证 |
| **高原运输** | 电池空运受限 | 陆运；或到当地采购电池（**更推荐**） |
