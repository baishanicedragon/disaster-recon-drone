# 06 · 末端迫降与泡沫机头吸能（替代伞降）

> 状态：**待验证**。全部为简化能量法与压溃模型估算，**没有任何一次实测落震**。
> 这是本设计**最危险的一环**——按 [12 章](./12-测试与验证流程.md) 的分级，它必须在**无动力滑翔验证之后**才允许实机尝试。

---

## 6.1 为什么取消降落伞

| 伞降的代价 | 说明 |
|:---|:---|
| **占空间** | 伞衣 + 伞包 + 抛离机构 ≈ 380 mm 舱段 + 1.6 kg |
| **落点不可控** | 灾区/峡谷内有风场，伞降落点散布可达数百米；在 4 m 深淤泥区根本无法取回 |
| **开伞需要火工品/高压气体** | 与本仓库**红线 2**（无火工品）冲突 |
| **伞挂在树上/悬崖上** | 吉隆沟两侧是陡坡与森林，挂树概率高 |
| **数据舱仍要单独回收** | 整机迫降 = 人到一处，一次取完 |

**取消伞降省下的 1.6 kg + 380 mm 全部还给电池**（正好是 12S3P → 12S4P 的 0.9 kg）。

## 6.2 一个反直觉的关键认识：**软地的价值是"行程"，不是"垫子"**

很多人以为软地是"缓冲垫"。**错**。

坠落吸收的能量等于 **力 × 行程**：

```
E = ∫ F dx
```

在硬地上，泡沫能提供的行程只有 **0.2~0.3 m**，因此：

```
吸收 1.66 kJ 需要平均力 F = 1660 / 0.25 = 6.6 kN
对 12.93 kg 的机体 → 过载 = 6640 / (12.93 × 9.81) = 52 g   ← 电子设备必死
```

**关键结论：过载只由「力」决定，而力 = 压溃应力 × 接触面积，与行程无关。**
要降过载，只能 **降应力（用更软的泡沫）** 或 **减小面积**——但这两者都会**减少吸能量**。
于是陷入死循环：**吸够能量就必然高过载。**

**打破循环的唯一办法是延长行程 ×。** 而**软地正好免费提供 0.3~0.8 m 的额外行程**：

```
机头犁入软土：F = 承载力 × 接触投影面积
             = 40 kPa × 0.045 m² = 1.8 kN  →  过载仅 14.6 g
行程 0.5 m  →  吸收 900 J
```

> ### ⚠ 因此：**硬地上这套迫降方案不成立。**
> **软地不是加分项，是本方案成立的前提条件。**
> 在水泥、沥青、冻土、碎石滩、水面上，本设计的迫降过载会超过 40 g，
> 数据舱存活率不可接受。

## 6.3 能量预算

### 6.3.1 撞击能量

```
设计触地状态：
 空速 V = 15 m/s    （拉平后衰减速度，= 0.80 × Vs）
 下沉率 w = 3.0 m/s
 合速度 V_tot = √(15² + 3²) = 15.3 m/s
 质量 m = 12.93 kg

平动动能 E_t = ½ × 12.93 × 15.3² = 1513 J
转动动能（机头触地后机体绕触地点俯冲旋转）经验取平动的 15 %：
 E_r = 0.15 × 1469 = 220 J

总需吸收 E_total = 1.69 kJ
```

### 6.3.2 三段吸收分配

| 段 | 机构 | 行程 | 平均力 | 吸能 | 说明 |
|:---|:---|---:|---:|---:|:---|
| ① **泡沫机头压溃** | 三层变密度 EPP | 0.25 m | 1.7 kN | **420 J** | 定姿态、防反弹、削第一峰 |
| ② **软地犁入** | 机头 ⌀240 犁入土中 | 0.50 m | 1.8 kN | **900 J** | **主力** |
| ③ **下翼牺牲 + 摩擦 + 结构变形** | 下翼可剪断铝销 + 机身 | 0.08 m + 滑行 | 2.5 kN | **370 J** | v0.4 删除腹滑橇，改由**下翼整体脱落**耗能（吸收剩余 + 消耗水平动能） |
| | | | | **合计 1690 J** ✅ | |

### 6.3.3 峰值过载校核

```
峰值出现在 ① 的末段（机头压溃到最大截面处）：
F_peak = σ_plateau × A_max
       = 0.20 MPa（EPP 45 kg/m³ 平台应力 × 应变率系数 1.2）× 0.030 m²
       = 6.0 kN  →  49 g   ← 太高！
```

**必须整改。** 三条并行措施：

| 措施 | 做法 | 效果 |
|:---|:---|:---|
| **① 限制机头最大压溃深度** | 在 STA 250 处设**刚性止挡环**（铝环 ⌀180），压溃到此处后泡沫"到底"，力急剧上升前由②接管 | A_max 从 0.030 → 0.0254 m²，F_peak 5.1 kN → 41 g |
| **② 降低外层密度** | 前 130 mm 用 **EPP 20 kg/m³**（σ ≈ 0.10 MPa），撞击先由最软层吃下第一峰 | 前段峰值降到 2.5 kN |
| **③ 用锥形的渐进特性** | 压溃从尖端 ⌀60 开始，面积随深度线性增大 → **力随行程线性上升**（近似），峰值出现在末期且被①止挡 | 峰值被钳制在止挡环触发点 |

**整改后重算：**

```
阶段 1（压溃 0→130 mm，EPP 20，A 0.003→0.013 m²）：
 F = 0.10 MPa × A_avg(0.008) = 0.8 kN → 6.5 g；E₁ = 0.8 × 0.13 × 0.65 = 68 J
阶段 2（130→250 mm，EPP 45，A 0.013→0.025 m²，止挡）：
 F = 0.20 MPa × A_avg(0.019) = 3.8 kN → 31 g；E₂ = 3.8 × 0.12 × 0.65 = 296 J
   ⚠ 31 g 仍偏高 → 把中间层降到 EPP 35（σ=0.15 MPa）→ F = 2.85 kN → 23 g；E₂ = 222 J
阶段 3（软地犁入 0.5 m）：F = 1.8 kN → 14.6 g；E₃ = 900 J
阶段 4（下翼牺牲 + 摩擦）：E₄ ≈ 500 J（v0.4 删除腹滑橇后，改由下翼可剪断铝销脱开耗能 80 mm 行程；容量 1950 J，实际只用到 500 J）

合计可吸收 = 68 + 222 + 900 + 500 = 1690 J ✅
峰值过载 = 31 g（若中间层 EPP 35）→ 优化后 ≈ 23 g ✅ 落在 ≤ 25 g 目标内
```

### 6.3.4 最终参数

| 项目 | 参数 |
|:---|:---|
| 机头吸能段长度 | **400 mm**（有效压溃 250 mm，止挡在 STA 250） |

## 6.4 末端飞行剖面

```
                    回收场（软地，承载力 30~60 kPa）
                              ▲
    P7-1  进近  ────────────────┘  高度 120 m AGL，速度 21 m/s（1.12 Vs）
                              │     沿预设进近航向（顺风或侧风 ≤ 3 m/s）
    P7-2  下滑  ───────────────┘   高度 120 → 15 m，下滑角 −10°
                              │     速度维持 20~21 m/s，油门 20 %
    P7-3  拉平  ───────────────┘   高度 15 → 4 m，拉杆至 +6° 迎角
                              │     速度衰减 21 → 15 m/s，**严禁失速**
    P7-4  触地  ───────────────┘   高度 4 → 0 m，下沉率 3 m/s，俯角 −8°
                              │     机头先触地 → 压溃 → 犁入 → 下翼脱落刮地 → 停
    P7-5  停后  ───────────────┘   断电（延时 30 s 保证写入完成）
                                    → 蜂鸣 + LED + LoRa 信标
                                    → 人员到达 → 无工具取出数据舱
```

### 6.4.1 各段参数

| 段 | 高度 | 速度 | 姿态 | 关键约束 |
|:---|---:|---:|:---|:---|
| P7-1 进近 | 120 m AGL | 21 m/s | 水平，坡度 0 | 航向与场地长轴对齐；**禁止带坡度接地** |
| P7-2 下滑 | 120→15 m | 20~21 m/s | 俯角 −10° | 下沉率 ≤ 4 m/s；激光/毫米波测高修正 |
| P7-3 拉平 | 15→4 m | 21→15 m/s | 迎角 +6° | **速度不得低于 1.05 Vs = 19.6 m/s @ 拉平起点**；拉平不足 → 重飞 |
| P7-4 触地 | 4→0 m | 15 m/s | 俯角 −8° | 下沉 3 m/s；**机头先触地** |
| P7-5 停后 | 0 | 0 | 机腹贴地 | 30 s 延时断电；燃料/电池无关 |

### 6.4.2 重飞（Go-around）条件

| 触发 | 处置 |
|:---|:---|
| 高度 8 m 时速度 < 19 m/s | **立即复飞**，绕回重新进近 |
| 高度 8 m 时偏离航向 > 15° | 复飞 |
| 测高无效/丢失 | 复飞 |
| 场地上出现人/车/牲畜 | 复飞 |
| 复飞次数 ≥ 3 | 进入 **备用垂直迫降剖面**（竖立缓降，机腹触地） |

## 6.5 回收场地判据（**硬约束**）

> **选错场地 = 前面的计算全部作废。** 这一节的优先级高于任何结构设计。

### 6.5.1 必须满足（全部满足才可迫降）

| # | 判据 | 现场简易判据 | 量化 |
|:--|:---|:---|:---|
| L-01 | 承载力 | **用鞋跟能踩进去 3~5 cm，拔出来不粘鞋** | 30~60 kPa |
| L-02 | 坡度 | 目视基本水平 | ≤ 8° |
| L-03 | 表面 | 无大于拳头的石块 | 无 > 10 cm 硬物 |
| L-04 | 面积 | 长 ≥ 120 m × 宽 ≥ 30 m | 含滑跑/犁入区 |
| L-05 | 无障碍 | 进近航向 300 m 内无电线/树/建筑 | — |
| L-06 | 无积水/流沙 | 表面无明水、无流动泥浆 | — |

### 6.5.2 绝对禁止

| 场地 | 理由 |
|:---|:---|
| ❌ **泥石流淤积区** | 通报中核心区淤泥平均 4 m、最深 16 m。**承载力 < 15 kPa，会陷进去**；且流动性泥浆拍击载荷极大 |
| ❌ 水泥 / 沥青 / 压实路面 | 无犁入行程 → 过载 > 40 g |
| ❌ 冻土 / 板结砾石滩 | 同上 |
| ❌ 水面 | 无行程 + 浸水 + 不可回收 |
| ❌ 陡坡 > 15° | 触地后翻滚 |
| ❌ 有 > 20 cm 块石的河滩 | 撞击集中载荷戳穿泡沫直达结构 |
| ❌ 灌木/密林 | 戳穿 + 挂住 |

> **吉隆场景的具体结论**：
> **核心区（0.7 km²，淤泥 4~16 m）绝不能作为落点。**
> 推荐回收场：**吉隆镇外围的河滩沙洲、草甸、或缓坡台地**（海拔 ~2750 m），
> 与起飞场同址。这既满足软地要求，也在道路抢通后人员可达范围内。

## 6.6 与"十字标"的关系

原需求中的"地面红布十字标"在本版**保留并改用途**：

| v0.1 | v0.2 |
|:---|:---|
| 用于**投放点**的视觉精定位 | 用于**回收场**的视觉精定位 |
| 一次性投放 | 可重复使用（布标，每次任务铺一次） |

**布标规格：**

| 项目 | 参数 |
|:---|:---|
| 颜色 | **正红**（对绿色/灰褐色地表对比度最高；避开当地常见经幡色系） |
| 形状 | 十字，臂长 **6 m**，臂宽 **1.2 m** |
| 材质 | 牛津布 / 无纺布，配 8 个地钉 |
| 数量 | **2 组**：主标（落点中心）+ 辅标（进近方向 100 m 处，指示航向） |
| 铺法 | 十字一臂指向**进近航向**（同时作风向参考） |
| 识别 | 飞控在 60 m AGL 用视觉 MCU 检测，修正横向偏差；检测到才允许进入 P7-2 |

> ⚠ **红布在高原强日照下会褪色/被风吹走**；建议同时备 **橙色烟雾/荧光板**作为备份标识，
> 且**不依赖视觉作为唯一手段**（GNSS + LoRa 测向为主，视觉为辅）。

## 6.7 迫降后流程

```
T+0     触地
T+0~3 s 滑行/犁入停止
T+3 s   主继电器断开电机供电（保留航电）
T+3 s   蜂鸣器启动（≥ 95 dB @ 1 m），LED 频闪
T+30 s  完成所有写入（相机 RAW/JPEG + 飞控日志 + YOLO 结果），切断非必要负载
T+30 s  LoRa 信标进入"低频求救"模式：每 10 s 发一次（GPS 坐标 + 姿态 + 电池电压）
        续航目标 ≥ 6 h（用独立 2S 200 mAh 后备电池）
T+?     人员按 LoRa 测向（≥ 2 km）到达
T+?     无工具打开快拆数据舱（≤ 10 s）→ 取出 microSD
T+?     现场初步检查：主杆有无折断、电池有无鼓包/异味
        ⚠ 电池异常 → 勿移动，隔离 30 min，用灭火毯/沙土覆盖
T+?     更换机头吸能段（3 min）→ 装新电池 → 可再次出动
```

## 6.8 失效模式

| 失效 | 后果 | 缓解 |
|:---|:---|:---|
| 拉平过早 → 失速掉高 | 大下沉率砸地 | 拉平点高度锁定 15 m；迎角限制；空速低于阈值自动补推力 |
| 拉平过晚 → 俯冲触地 | 过载超限 | 触地前 4 m 强制俯角限制 −8° |
| 带坡度接地 → 翼尖先撞 | 翻滚、机翼折断 | 进近段坡度限幅 ±5°；翼尖 EPP 滑块 |
| 场地误判（实际是硬地） | 过载 40 g+，数据舱损毁 | 进近前 60 m 视觉 + 测高复核；**有人到场时先人工确认场地** |
| 机头吸能段未装/未锁紧 | 无吸能，直接结构撞击 | 卡扣到位检测（4 × 微动开关）→ 未确认**禁止起飞** |
| 触地后起火 | 锂电热失控 | 钢壳 21700 + 铝内衬；**首次任务必带灭火毯** |
| 数据舱卡扣在撞击中脱开 | 数据舱飞出丢失 | 卡扣 + 防脱销 + 3M 应力带三重 |
| 写入未完成就断电 | 影像损坏 | 30 s 延时断电 + 后备电池 + 循环写入（每 5 s 落盘） |

## 6.9 验证分级（**必须逐级通过**）

| 级 | 试验 | 判据 |
|:--|:---|:---|
| **L0** | 泡沫试样压缩试验（万能试验机，100 mm/min） | 实测平台应力与理论值偏差 ≤ 25 % |
| **L1** | 整机**落震试验**（吊挂释放，垂直速度 3 m/s + 水平 15 m/s，软土靶） | 峰值过载 ≤ 25 g；主杆不断；数据舱可读 |
| **L2** | 遥控**滑橇滑跑迫降**（无人区，软土，人工遥控拉平） | 3 次全部成功停住 |
| **L3** | **无动力滑翔迫降**（从 100 m 切断动力，自动拉平触地） | 3 次，数据 3 次可读 |
| **L4** | 全剖面自主迫降 | 5 次，成功率 ≥ 80 % |

> **禁止跳级。** L1 未过不得进入 L2。
