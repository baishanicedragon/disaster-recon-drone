# 11 · 施工顺序与装配工艺

> **这是全项目最关键的一章。**
> 前面所有计算都是纸面的；这一章决定**做出来的东西会不会在空中散架**。
>
> 设计原则：**每一道工序后面都有一个"Gate"（闸门）**——
> Gate 不过，绝不进入下一道。**Gate 的作用是让错误在地面暴露，而不是在 150 米高空暴露。**

---

## 11.0 施工总原则

| 原则 | 说明 |
|:---|:---|
| **① 先飞起来，再加功能** | 批 1 先做**构型 T**（固定翼 + 无折叠 + 无倒拖垂起，手抛/滑跑起飞），把巡航—盘旋—迫降跑稳；再加**倒拖爬升**与**无动力改平**（[03 章 Q2](./03-总体方案与气动布局.md)） |
| **② 先地面后空中** | 任何一个新功能，先台架 → 再绳系 → 再低空 → 再全剖面 |
| **③ 结构件不做"看起来差不多"** | 每个承力件都要有**检查判据**（力矩、间隙、目视） |
| **④ 装配可逆** | 所有关键连接必须能拆（返工是常态），**禁止"胶死了一劳永逸"** |
| **⑤ 每一次改动都称重 + 记 CG** | 重量与重心是安全的地基，改一次记一次 |
| **⑥  Gates 强制** | 13 个 Gate，逐条签字，不许跳 |

## 阶段 0 · 起飞触地环（地面设备，不随飞）

> 倒拖起飞**不需要起落架**——机头朝下静置在触地环里，A 区 EPP 吸能机头本身就是"支架"。
> 触地环是**地面设备**，任务是保证起飞瞬间（1）机头不打滑、（2）桨盘离地最远、（3）推力线竖直。

**内容**

1. 环形软垫：EPP / 发泡 PE 圆环，内径与 A 区机头根部（⌀240 锥段）贴合，**包裹高度 ≥ 150 mm**
2. 底座：硬板 + 4 个地钉 / 沙袋（高原阵风 > 6 m/s 时加防风绳）
3. 环口对中标记：与机体轴线对齐线，**起飞前用水平仪核对环口平面水平度**
4. 备件：吸能机头每次起飞都被压一次，**触地环软垫按 10 次起飞检查、磨损即换**

**要点**

| 项 | 要求 |
|:---|:---|
| 环口水平 | ≤ 1°（倒拖起转瞬间若歪斜 → 整机沿斜面滑出） |
| 软垫密度 | 50~80 kg/m³ 发泡材料；太软机头陷太深，太硬伤 EPP |
| 对中 | 机体轴线与环口中心偏差 ≤ 5 mm |
| 防风 | 场地阵风 > 6 m/s **不起飞**（倒拖段无空速，见 [03 章 3.5.3](./03-总体方案与气动布局.md)） |

## 阶段 1 · 准备与工装

**内容**

1. 建立工作台：水平平台（≥ 1.8 × 0.8 m）、台虎钳、切割台（**碳纤切割必须湿式 + 口罩**）
2. 制作**机身装配型架**：两块 V 型块 + 直线导轨，保证主杆与隔框**同轴度 ≤ 0.5 mm**
3. 准备量具：数显游标卡尺、千分尺、水平仪、角尺、**电子秤（精度 1 g）**、扭矩螺丝刀
4. 打印/制作所有 3D 件（PA-CF，**打印后 80 ℃ 烘干 4 h 除湿**）

**工艺要点**

| 项 | 要求 |
|:---|:---|
| 碳纤切割 | 湿切 + N95 口罩 + 护目镜；切口用环氧封边 |
| 3D 打印件 | PA-CF 必须烘干；层纹方向**垂直于主受力方向** |
| 金属件 | 去毛刺、倒角；螺纹孔攻丝后吹净 |

### 🚪 Gate-1：工装与量具

| # | 检查 | 判据 |
|:--|:---|:---|
| 1 | 装配型架同轴度 | ≤ 0.5 mm（用长直尺/激光检查） |
| 2 | 水平平台 | ≤ 0.2 mm/m |
| 3 | 电子秤校准 | 用标准砝码核对，误差 ≤ 2 g |
| 4 | 所有 3D 件已烘干 | 有记录 |
| 5 | 全部物料到齐并逐项称重 | BOM 表上**每项都有实测质量** |

> ❌ 不过 Gate-1 的后果：后面所有同轴度/配平数据都不可信。

## 阶段 2 · 主承力杆与隔框

**内容**

1. 主杆 ⌀55×2.5 × 1000 mm 下料，两端**环氧封边**
2. 在 STA 400/520/900/1250 划线定位隔框
3. 隔框（FR-1~FR-4）加工：碳纤板 + 铝嵌件（**嵌件用环氧 + 滚花压入**）
4. 隔框与主杆连接：**环氧 + 4 × M3 不锈钢销**（不是只靠胶）

**工艺要点（防断裂核心）**

| 项 | 做法 |
|:---|:---|
| 隔框不能只靠胶粘 | 胶承受剪切差，**必须加径向销钉** |
| 胶接面处理 | 碳纤表面 400# 砂纸打磨 → 丙酮脱脂 → 底涂 → 环氧（24 h 固化） |
| 环氧选型 | 结构胶（如 Araldite 2014 级或同级），**不是 502/AB 哥俩好** |
| 固化 | 室温 24 h 或 60 ℃ 4 h；**固化期间不得移动** |
| 孔位 | 隔框上的所有过线孔**必须倒角 + 加橡胶护圈**（线束被割破 = 短路） |

### 🚪 Gate-2：主承力结构

| # | 检查 | 判据 |
|:--|:---|:---|
| 1 | 主杆直线度 | ≤ 1 mm / 1000 mm |
| 2 | 隔框与主杆垂直度 | ≤ 0.3 mm / 100 mm |
| 3 | 隔框轴向位置 | ± 1 mm |
| 4 | **静力试验**：主杆简支，FR-2 与 FR-3 之间施加 600 N·m 弯矩 | 无裂纹、无异常响声、残余变形 ≤ 1 mm |
| 5 | 销钉全部到位 | 目视 + 手拉 |

## 阶段 3 · 二级吸能筒 + 前段

**内容**

1. 制作二级吸能筒：铝蜂窝 ⌀6（5052）卷成锥形，外层 0.4 mm 玻纤布 + 环氧包覆
2. 筒位于 STA 380~520，与 FR-1/FR-2 连接
3. 在 STA 400~520 主杆上加工**屈曲诱导槽**（环向浅槽，深 0.3 mm，宽 2 mm，间距 40 mm × 3）
4. 前设备舱（STA 400~520）：毫米波雷达、空速管座、着陆灯

**工艺要点**

| 项 | 说明 |
|:---|:---|
| 诱导槽 | **只能浅、不能深**；深了飞行中就会屈曲。深度 = 壁厚 × 12 % |
| 铝蜂窝防潮 | 两端用环氧封边（吸潮后吸能性能下降） |
| 空速管 | 必须在**机身外、远离桨滑流与机身边界层**；加防水堵（地面堵，起飞前拔） |

> ⚠ v0.3 空速管是**段 II 展翼门控的输入**（动压 ≥ 1.1 Vs），它的安装质量直接决定能否在俯冲段正确展开机翼——见 [07 章](./07-电子系统与PCB设计.md) 与 Gate-9 IL-1。

### 🚪 Gate-3：前段

| # | 检查 | 判据 |
|:--|:---|:---|
| 1 | 吸能筒与主杆同轴 | ≤ 1 mm |
| 2 | 诱导槽深度 | 0.30 ± 0.05 mm（用深度尺逐槽量） |
| 3 | **压溃试验**：样品筒轴向压缩，记录力-位移曲线 | 平台力 2.5~4.0 kN，吸能 ≥ 250 J |
| 4 | 空速管气密 | 加压 5 kPa，1 min 压降 ≤ 0.2 kPa |
| 5 | 前段称重 | 与设计值偏差 ≤ 8 % |

## 阶段 4 · 电池舱与滑轨

**内容**

1. 制作电池舱：铝内衬（0.8 mm 5052）+ 3 mm EVA 内衬
2. 安装**纵向滑轨**（STA 520~760），用于电池前后配平
3. 压紧块 + M4 螺栓，配平后用扭矩（2.5 N·m）+ 螺纹胶固定
4. 电池组制作：**48 颗 21700，12S4P**

**电池组制作要点（高风险工序）**

| 项 | 要求 |
|:---|:---|
| **配组** | 逐颗测内阻（≤ 25 mΩ）与容量，**同串内偏差 ≤ 5 mΩ / 3 %** |
| 镍片点焊 | **点焊，绝不能烙铁焊**（烙铁高温损伤电芯）；每点拉拔测试 ≥ 40 N |
| 绝缘 | 每层加青稞纸/环氧板；极耳方向用**不同颜色热缩管**区分 |
| 采样线 | 逐串引出，**必须加保险丝（每串 1 A）**，线径 ≥ 24 AWG |
| BMS | 先接 BMS 再接输出；**首次上电用限流电源** |
| 外观 | 无毛刺、无挤压、包 PVC + 玻纤胶带 |
| **首次充电** | 在**防爆袋内、有人值守、远离可燃物**进行 |

### 🚪 Gate-4：电池

| # | 检查 | 判据 |
|:--|:---|:---|
| 1 | 每颗电芯内阻记录 | 有表，偏差 ≤ 5 mΩ（同串） |
| 2 | 点焊拉拔抽检（3 点） | ≥ 40 N |
| 3 | 绝缘 | 正负极与外壳 ≥ 20 MΩ |
| 4 | 满充后每串电压 | 偏差 ≤ 0.03 V |
| 5 | **放电能力**：1 C 放电 10 min，最低串 ≥ 3.5 V，温升 ≤ 20 ℃ | 通过 |
| 6 | 电池滑轨前后移动 | 全程顺畅，锁定后不晃动 |
| 7 | 电池挤压保护 | 铝内衬到位，手用力压电池表面无位移 |

## 阶段 5 · 尾部动力段（电机 + 变距棘轮 + 桨）

**内容**

1. 制作 FR-4 电机座：PA-CF 打印 + **4 mm 铝背板**（不是纯打印件）
2. 安装 4 × 电机，**X 型 45°/135°/225°/315°**（相邻反向对转：对角同向 2 CW + 2 CCW）
3. **桨心距核查**：桨心半径 **0.245 m**，**相邻桨心距 ≥ 0.347 m**（1.05 D 无盘面互穿），**轴向错位 ≥ 30 mm**
4. 安装 4 × **13" 折叠桨 + 变距棘轮毂**（单向两档：爬升大距 / 巡航小距）
5. 安装 4 × 电调（固定在铝背板上，散热面朝外）

**工艺要点**

| 项 | 要求 |
|:---|:---|
| 电机座强度 | 电机座是悬臂 + 振动源，**用铝背板传力到 FR-4**，不要让打印件单独吃力 |
| 螺栓 | M3 不锈钢，力矩 1.2 N·m，**全部涂中等强度螺纹胶（如 243）** |
| 桨 | 静平衡（平衡器，允许 ≤ 0.05 g·m）；**上桨后必须复查** |
| 转向 | 相邻反向对转（对角同向 2 CW + 2 CCW），**用贴纸标明**，上电前用低油门确认 |
| 变距棘轮 | 电磁销锁两个桨距位；**必须在断电状态下确认棘轮单向**（巡航档后不能再回爬升档） |
| 顺桨折叠 | 停机后桨叶在气动力下自动顺桨折叠；**装机前逐桨做"慢转→急停→折叠"台架模拟** |
| 线束 | 三相线互绞，长度一致；**绝不**让相位线绷紧（振动会拉脱焊点） |
| 走线 | 远离 IMU 与 GNSS 天线 ≥ 150 mm |

> ⚠ **桨心半径 0.245 m 是 v0.3 无干涉下限**（13" 桨半径 0.165 m + 1.05 D 净距反解），不是随便摆的。
> 装小了相邻盘面互穿，装大了尾部外廓超过 0.82 m、横向超 1 m 的毛病会回来。

### 🚪 Gate-5：动力段

| # | 检查 | 判据 |
|:--|:---|:---|
| 1 | 桨心半径 | 0.245 ± 2 mm；相邻桨心距 ≥ 0.347 m（逐对测量） |
| 2 | 轴向错位 | ≥ 30 mm |
| 3 | 桨静平衡 | ≤ 0.05 g·m |
| 4 | 电机座刚度 | 手推电机座端部，位移 ≤ 1 mm @ 50 N |
| 5 | **拉力试验**（整机固定，满油门 10 s） | 4 轴合计 ≥ 160 N @ 2750 m 等效 ⚠ |
| 6 | 变距两档切换 | 台架上逐桨：爬升档 → 巡航档单向锁存，**不可回爬升档**；电磁销到位指示正确 |
| 7 | 顺桨折叠 | 模拟关机后桨叶自动折叠到位，重启可甩开（逐桨 10 次） |
| 8 | 温升 | 电机 ≤ 80 ℃，电调 ≤ 75 ℃ |
| 9 | 振动 | 手摸无明显共振频率；用手机加速度 App 粗测峰值 ≤ 3 g |
| 10 | 螺栓力矩 | 全部复核 + 螺纹胶 |

## 阶段 6 · 尾翼（X 型，拉平操纵面）

**内容**

1. 4 × 尾翼：碳纤板 2 mm，**X 型 90° 环布、无 cant**（删去起旋/消旋职能）
2. **拉平操纵面**：倒拖/改平剖面需要俯仰与偏航控制，尾翼带舵面 + 舵机（4 ×）——俯冲阻尼、2.0 g 拉平都靠它
3. 舵机臂与拉杆：钢拉杆 + 球头，行程与 X 构型混控匹配

**工艺要点**

| 项 | 要求 |
|:---|:---|
| **X 型对称性** | 4 片夹角 90° ± 0.5°；同一对角线两片**共面**（否则拉平时产生不对称力矩） |
| 尾翼刚度 | 俯冲增速 ~23 m/s 时舵面载荷最大，**舵面要质量平衡到铰链轴前 ≥ 60 %**（防颤振） |
| 舵机 | ≥ 8 kg·cm 数字金属齿；拉杆**不留死区**，两端球头锁紧 |
| 铰链 | 环氧玻纤铰链 / 钢琴线铰链，间隙 ≤ 0.5 mm |
| 线束 | 舵机线沿尾杆内走，出口处留 U 形弯（防拉脱） |

### 🚪 Gate-6：尾段

| # | 检查 | 判据 |
|:--|:---|:---|
| 1 | X 型夹角 | 90° ± 0.5°，4 片无 cant |
| 2 | 尾翼安装刚度 | 翼尖施加 30 N，位移 ≤ 5 mm |
| 3 | 舵面质量平衡 | 铰链轴前 ≥ 60 % |
| 4 | 舵机行程/混控 | 4 片同步偏转 ±25°，左右/上下差 ≤ 1.5° |
| 5 | 拉杆无死区 | 全程顺滑，舵面在两端行程间无卡点 |
| 6 | 称重 | ≤ 0.32 kg |

## 阶段 7 · 主翼制造

**内容**

1. 主梁：碳纤管 ⌀16×1.5 × 2000 mm（贯穿）
2. 翼肋：3D 打印 PA-CF 或激光切割 2 mm 轻木，间距 90 mm
3. 蒙皮：0.4 mm 玻纤板（或热缩膜 + 翼肋，低速够用）
4. 升降副翼（elevon）：全展长，弦向 25 %，左右独立
5. 翼尖 EPP 滑块（可更换）
6. 上反角 3°

**工艺要点**

| 项 | 要求 |
|:---|:---|
| **左右对称性** | 半展差 ≤ 5 mm，**这是硬指标**；不对称 → 改平后立刻滚转 |
| 主梁不打断 | 折叠机构在主梁**根部抱夹**，不切断纤维 |
| 蒙皮胶接 | 玻纤板用环氧，加压固化（真空袋最好，最低限度用重物压） |
| 舵面间隙 | ≤ 1 mm；缝隙用柔性胶带封（减少阻力 + 防颤振） |
| 翼尖滑块 | 用**可撕式**固定（魔术贴 + 胶带），迫降磨损后现场可换 |

### 🚪 Gate-7：主翼

| # | 检查 | 判据 |
|:--|:---|:---|
| 1 | 左右半展差 | ≤ 5 mm |
| 2 | 扭转变差（左右翼同站位迎角差） | ≤ 0.5° |
| 3 | **静力试验**：翼尖加载至 **3 g × 半翼升力**（≈ 190 N） | 无永久变形；继续加载到 **2.5 倍（475 N）** 才破坏 |
| 4 | 舵面偏角 | ±25°，左右差 ≤ 1.5° |
| 5 | 舵面间隙 | ≤ 1 mm |
| 6 | 主梁与折叠座连接 | 无松动，纤维无损伤 |
| 7 | 称重 | 1.30 kg ± 8 % |

## 阶段 8 · 折叠机构与锁销

**内容**

1. 转轴：钢轴 ⌀10（SUS304）+ 铜衬套
2. 扭簧：展开驱动（**无动力也能展开**）
3. 锁销：钢销 ⌀5（SUS304），舵机驱动，**抗剪 ≥ 480 N**
4. 到位检测：**每侧 1 个微动开关**（共 2 个）
5. 折叠状态锁定：机械卡扣（运输中不自行展开）

**工艺要点**

| 项 | 要求 |
|:---|:---|
| 衬套 | 必须**可更换**（铜衬套磨损后更换，不换整个机构） |
| 锁销孔 | 铰制孔（H7），**不能是打出来的毛糙孔** |
| 锁销驱动 | 舵机 + **弹簧失效安全**：断电时弹簧把销推向"锁定"位 |
| 微动开关 | 用**常闭型**，断线 = 检测为"未锁定"（失效安全） |
| 线束 | 折叠处线束要**留 U 形余量**，反复折叠不能拉扯 |

> ⚠ v0.3 机翼在**俯冲段展开**（空速 ≥ 1.1 Vs），展开方向受气流影响，**扭簧力必须按俯冲动压标定**：太小展不开，太大解锁瞬间冲击折叠座。地面用吹风/滑车模拟验证（[12 章](./12-测试与验证流程.md) T-09）。

| # | 检查 | 判据 |
|:--|:---|:---|
| 1 | 展开/折叠 50 次循环 | 无卡滞、间隙增大 ≤ 0.1 mm |
| 2 | 锁销抗剪 | 加载 480 N 不变形；**1.5 倍（720 N）不剪断** |
| 3 | 展开时间 | ≤ 1.5 s |
| 4 | 双侧同步性 | 时间差 ≤ 0.3 s |
| 5 | 微动开关 | 展开/折叠两态均正确翻转，断线时为"未锁定" |
| 6 | **断电测试**：展开状态下切断舵机电源 | 弹簧把销推入锁定（失效安全） |
| 7 | 折叠运输状态 | 人工用力摇晃不自行展开 |
| 8 | **吹风展开模拟**（≥ 20 m/s 气流或滑车） | 展开到位、锁定指示正确、无卡滞 ⚠ |

## 阶段 9 · 互锁电路与安全逻辑 ★

> ### 这是**生死 Gate**。前面 8 个 Gate 出问题会摔飞机；这个 Gate 出问题会摔飞机 **+ 伤到人**。

**内容**

| 互锁 | 逻辑 | 失效后果 |
|:---|:---|:---|
| **IL-1 展翼门控** | **空速 ≥ 1.1 Vs（≈ 20.6 m/s）且高度 ≥ 90 m**，才允许**解锁**机翼展开 | 动压不足展开不到位/冲击折叠座；地面误展开 = 伤人 |
| **IL-2 双锁确认** | 2 个微动开关**同时**为"锁定"，才允许进入拉平（FLARE） | 单侧未锁 → 拉平时折翼 |
| **IL-3 吸能头到位** | 4 个卡扣微动开关全到位，才允许**解锁电机** | 无吸能 → 倒拖起飞触地即毁；地面试车脱扣飞出 |
| **IL-4 数据舱到位** | 快拆舱卡扣 + 防脱销检测 | 空中掉数据舱 |
| **IL-5 巡航档确认** | **棘轮已锁巡航小距档**，才允许**重启电机**进入平飞推进 | 爬升大距 + 巡航转速 → 电机过载/桨叶过应力 |
| **IL-6 电池检测** | 任一串 < 3.3 V 或温差 > 15 ℃ → 禁止起飞 | 空中掉电 |

**实现方式**

```
优先级 1（硬件层，不可被软件绕过）：
  IL-1 ~ IL-4 用**串联的继电器/固态开关**直接切断电机供电通路
  → 即使飞控死机、软件跑飞，电机也转不起来
  （IL-1 的"动压信号"用独立动压开关/空速计硬线，不用飞控软件值）

优先级 2（软件层）：
  飞控启动自检，任一互锁未满足 → 拒绝 ARM，地面站显示具体原因

优先级 3（人工层）：
  地面检查表逐条签字（见 12 章）
```

### 🚪 Gate-9：互锁与安全（**必须逐条实测，不接受"代码看起来对"**）

| # | 检查 | 判据 |
|:--|:---|:---|
| 1 | IL-1 | 地面/低速注入展开指令 → **被拒**；模拟空速 ≥ 1.1 Vs 且高度 ≥ 90 m → 放行 |
| 2 | IL-2 | 人为拔掉一侧微动开关 → 拒绝进入 FLARE |
| 3 | IL-2 失效安全 | 微动开关断线 → 判定"未锁定"（常闭型） |
| 4 | IL-3 | 拆掉一个吸能头卡扣 → **电机无法解锁**（实测转动） |
| 5 | IL-4 | 打开数据舱 → 拒绝 ARM |
| 6 | IL-5 | 棘轮未锁巡航档 → 拒绝电机重启（模拟平飞指令被拒） |
| 7 | IL-6 | 人为设一串低电压 → 拒绝 ARM |
| 8 | **飞控死机测试** | 运行中拔掉飞控 → 硬件互锁仍切断电机 |
| 9 | 所有互锁的失效方向 | 断线/断电 → **一律导向"禁止/锁定"**（失效安全） |

## 阶段 10 · 吸能机头（耗材）

**内容**

1. 用热丝/数控切割 EPP 三层：
   - 前段 130 mm：**EPP 20 kg/m³**
   - 中段 120 mm：**EPP 35 kg/m³**
   - 后段 150 mm：**EPP 60 kg/m³**
2. 中部埋 **铝止挡环 ⌀180**（位于 STA 250）
3. 三层之间用柔性胶粘接
4. 后部 4 × 快拆卡扣座（尼龙 + 钢销）
5. 外覆一层 0.1 mm 玻纤布 + 环氧（防紫外、防刮）

> ⚠ v0.3 吸能头**兼任倒拖起飞的触地缓冲端**：每次倒拖起飞它会先压一次触地环，再在末端迫降压一次。
> 因此**吸能头不是"飞一次换一个"，是"起飞 + 迫降 = 一次完整任务后必换"**；起飞后目视检查有压痕但未溃裂可续用，迫降后一律更换。

**工艺要点**

| 项 | 要求 |
|:---|:---|
| **密度必须实测** | 到货 EPP 称重 + 量体积核对；偏差 > 15 % 要重算吸能 |
| 止挡环位置 | STA 250 ± 5 mm（**装错等于没有**） |
| 空腔 | A 区**绝对不放任何设备**（见 [04 章](./04-结构设计与材料.md) 4.1） |
| 卡扣 | 尼龙件 + 钢销；**手拉不脱**，但要能 3 min 换 |
| 触地环接触面 | 前缘 130 mm 密度最低（20 kg/m³），起转时压触地环软垫不溃裂 |
| 备件 | 至少做 **3 件**，每件标注序号与制作日期 |

## 阶段 12 · 航电与线束

**内容**

1. 飞控安装：**减振安装**（30~50 Shore A 硅胶垫），方向对齐（箭头朝机头）
2. IMU 备份：安装在**不同方位**（避免共模振动）

4. 磁罗盘：**远离大电流线 ≥ 200 mm**

7. 配电板安装：绝缘垫 + 4 点固定

**工艺要点**

| 项 | 要求 |
|:---|:---|
| **减振** | 太软 → 控制延迟；太硬 → 振动噪声。30~50 Shore A，厚度 3~5 mm |
| 接插件 | 全部用**带锁扣**的（JST-XH / DF13 / Molex），振动场合不能用杜邦 |
| 线束固定 | 每 80~100 mm 一个扎带座；**不允许悬空甩线** |
| 应力释放 | 每个接插件处留 U 形弯 |
| 屏蔽 | GNSS、相机排线、IMU 线**屏蔽层单端接地** |
| 标识 | 每根线两端贴标签（**没有标识 = 无法排故**） |

## 阶段 13 · 总装、称重、配平

**内容**

1. 安装吸能机头（确认 4 卡扣，IL-3）
2. 安装电池（先用**配重块**配平，最后换真电池）
3. 机翼展开，确认锁定（地面维护态；任务中在俯冲段展开）
4. 称重
5. **重心测量**：横向 + 纵向 + 垂直

**重心测量方法**

```
纵向 CG：用两个支点（前支点在 STA 300，后支点在 STA 1300），
         分别读两个秤的读数 F1、F2
         CG = (F1 × 300 + F2 × 1300) / (F1 + F2)
         目标 = STA 885 ± 10 mm（电池 STA 600，SM ≈ +12 % MAC，初飞）

横向 CG：把飞机水平横放，左右翼下各放一秤（或整机悬吊），读差
         ⚠ 横向偏移必须 ≤ 3 mm —— 倒拖爬升"不斜着爬"的硬指标

垂直 CG：把飞机侧放（机腹朝下）与倒放各测一次，差值反映垂直 CG
         目标：落在主杆轴线上（± 10 mm），使倒拖摆轴通过 CG
```

**配平**

| 目标 | 值 |
|:---|:---|
| 纵向 CG | **STA 885 ± 10**（初飞，电池 STA 600，SM ≈ +12 % MAC） |
| 横向 CG | **≤ 3 mm** |
| 垂直 CG | 落在主杆轴线 ± 10 mm（倒拖摆式稳定需要 CG 贴推力线） |

**调整手段（按优先级）**

1. **移动电池**（STA 520~760 无级）——首选，不增加重量
2. 移动航电舱位置
3. 最后手段：加配重（**每加 1 g 都要记账**）

> ⚠ **倒拖姿态自检**：总装完成后把整机机头朝下放进触地环（阶段 0），
> 观察机身是否竖直（水平仪 ± 1°）——CG 偏一侧会直接在环里看出来，这是**最便宜的一次配平检查**。
