# 12 · 测试与验证流程

> **铁律：分级验证，禁止跳级。**
> 本设计的危险环节（倒拖爬升、关机-俯冲-改平、盘旋、迫降）**任何一个都可能在第一次尝试时毁掉整机**。
> 分级的目的不是"慢慢来"，而是**让每一次可能的失败都发生在损失最小的时候**。

---

## 12.1 验证等级

| 级 | 名称 | 场所 | 整机风险 | 前置条件 |
|:--|:---|:---|:---|:---|
| **T** | 台架试验 | 工作台 | 无 | 完成对应施工 Gate |
| **G** | 地面试验 | 场地 | 低 | T 级全过 |
| **A1** | 倒拖爬升 + 垂直回降（低空） | 试飞场 | 中 | G 级全过 |
| **A2** | 无动力改平（关机-俯冲-展翼-拉平） | 试飞场 | **高** | A1 × 20 架次无异常 |
| **A3** | 巡航 + 盘旋 | 试飞场 | 中 | A2 × 10 架次 |
| **A4** | 末端迫降（L0~L4） | 软地场地 | **高** | A3 + 落震 L1/L2 |
| **A5** | 全自主剖面 | 真实走廊 | **高** | A4 × 5 架次成功 |

> **批 1 先行**（[10 章](./10-物料清单BOM.md) 10.6）：先用**固定翼验证平台**（构型 T：无折叠、无倒拖，手抛/滑跑起飞）
> 把 A3 巡航-盘旋-迫降整条链跑稳——倒拖与改平是本设计最大的新东西，**不要让两个新东西第一次同时上天**（[03 章 Q2](./03-总体方案与气动布局.md)）。

## 12.2 T 级：台架试验

| # | 试验 | 方法 | 判据 |
|:--|:---|:---|:---|
| T-01 | 主杆弯曲 | 简支，FR-2~FR-3 间加载至 600 N·m | 无裂纹，残余变形 ≤ 1 mm |
| T-02 | 机翼静力 | 翼尖加载 190 N（3 g）→ 475 N（2.5×） | 前者无永久变形，后者才破坏 |
| T-03 | 锁销剪切 | 加载 480 N → 720 N | 前者不变形，后者不断 |
| T-04 | **拉力/功率实测** ⚠ | 整机倒拖姿态固定 + 拉力传感器 + 功率计；**在 2750 m 等效条件下**（低压舱或到高原实测） | 4 轴合计 ≥ 160 N；满载悬停电功率 ≤ 2.9 kW；峰值 ≤ 4.1 kW |
| T-05 | 电池放电 | 1 C 放 10 min；3 C 放 30 s | 最低串 ≥ 3.5 V；温升 ≤ 25 ℃ |
| T-06 | **尾翼静稳定复核** | Barrowman 手算 + 数值/风洞复核俯冲段安定性（[03 章](./03-总体方案与气动布局.md) 3.7） | 静稳定裕度与阻尼符合设计；发散时间 > 3 s |
| T-07 | EPP 压缩 | 万能试验机，100 mm/min | 平台应力与理论偏差 ≤ 25 % |
| T-08 | **整头压溃** | 压溃一个吸能头 | 吸能 ≥ 290 J，峰值力 ≤ 3.0 kN |
| T-09 | **折叠展开（吹风/滑车）** ⚠ | ≥ 20 m/s 气流或滑车模拟俯冲动压展开 | ≤ 1.5 s，双侧同步 ≤ 0.3 s，锁定指示正确 |
| T-10 | 互锁功能 | 见 Gate-9 全 9 条 | 全部通过 |
| T-11 | 配电满载 | 满油门 10 min | 纹波 ≤ 1 V p-p，无过热 |
| T-12 | 相机标定 | 棋盘格 | 重投影误差 ≤ 0.5 px |
| T-13 | 落震准备 | 吊挂释放装置标定 | 释放速度可控 ±0.2 m/s |
| T-14 | 变距棘轮循环 | 爬升↔巡航切换 100 次 + 单向锁存验证 | 无卡滞，巡航档后不可回爬升档 |

> **T-04 是最容易偷懒、也最容易致命的一项。**
> 厂家给的海平面推力曲线到 2750 m 要打 **76 %** 折扣。
> 没有实测，[05 章](./05-动力系统与配电.md) 的所有数字都是猜想。

## 12.3 G 级：地面试验

| # | 试验 | 判据 |
|:--|:---|:---|
| G-01 | 全机称重 + CG | ≤ 15 kg（目标 ≤ 12.55，BOM 12.19）；纵向 CG 885 ± 10（电池 STA 600）；横向 ≤ 3 mm |
| G-02 | 倒拖静置自检（触地环内） | 机身竖直 ± 1°，无侧倾（CG 偏侧会直接看出来） |
| G-03 | 舵面 / 电机转向 / 变距档位 | 全部正确；相邻反向对转；起飞前确认爬升大距档 |
| G-04 | 失控保护 | 关控 → 进入预案（不是直接掉） |
| G-05 | 滑跑/手抛发射试验（**仅批 1 构型 T**） | 直线跑 30 m，偏航 ≤ 2 m；或手抛离手姿态稳定 |
| G-06 | **系留倒拖**（绳系，机头朝下离地 ~0.5 m） | 4 轴差动推力可控，无持续漂移；关机后顺桨折叠到位 |
| G-07 | **变距棘轮地面切换** | 慢转下爬升档→巡航档单向锁存；电磁销指示正确 |
| G-08 | **顺桨折叠模拟** | 慢转 → 急停 → 桨叶自动折叠；重启可甩开（10 次） |
| G-09 | 机翼展开（低动压拒绝） | 地面/低速注入展开指令 → **被拒**（IL-1） |
| G-10 | 相机等距触发 | 地面推车，触发间距误差 ≤ 10 % |
| G-11 | LoRa 拉距 | 视距 ≥ 8 km，丢包 ≤ 10 % |
| G-12 | 全系统 30 min 待机 | 无异常；温升正常 |
| G-13 | **演练：数据舱取出** | ≤ 10 s，无工具，3 人各做一次 |

> **G-06 用绳系**：把飞机在倒拖姿态（机头朝下）用两根弹性绳吊在龙门架上，允许小幅运动但不落地。
> 这是验证"倒拖推力线过 CG、差动推力可控"**最便宜也最安全**的方法——首次垂直飞行不上真高度。

## 12.4 A1 级：倒拖爬升与垂直回降（低空）

| # | 试验 | 判据 |
|:--|:---|:---|
| A1-01 | 倒拖垂直起飞（机头在触地环内起转）到 3 m，保持 10 s | 竖直，漂移 ≤ 0.5 m |
| A1-02 | 上升到 30 m，保持 30 s | 高度保持 ±1 m |
| A1-03 | 抗 4 m/s 侧风 | 位置保持 ≤ 2 m |
| A1-04 | 垂直回降：从 30 m 缓慢下降，机头落回触地环 | 全程竖直，落点 ≤ 0.3 m，无侧翻 |
| A1-05 | **首次关机试验** ⚠：爬升 50 m → 关机 → 头朝下自然下坠 → 软垫/软土 V_NOSE 迫降 | 关机即俯冲无异常；桨顺桨折叠；低速下 IL-1 **拒绝展翼**；数据完整 |
| A1-06 | 全高爬升：倒拖到 **150 m**，垂直回降 | 全程竖直；爬升时间 ≤ 50 s |
| A1-07 | 重复 20 架次 | 无异常 |

> **A1-05 的用意**：真实任务里"关机后头朝下下坠"是从没验证过的动力学。第一次不做展翼、
> 不做拉平，只验证"关机 → 俯冲 → 触地"，失败也只是摔一次吸能头。**A1-05 每次消耗 1 个吸能头。**
> **A1-06 全高回降**验证 150 m 高度预算与倒拖时长（约 45 s），回降成功后才能进入 A2。

## 12.5 A2 级：无动力改平（**最高风险**）

| # | 试验 | 判据 | 备注 |
|:--|:---|:---|:---|
| A2-01 | **首次空中展翼** ⚠：150 m 关机 → 俯冲至 1.1 Vs 且高度 ≥ 90 m → 展开 + 双锁 → **只展开、不拉平**，维持俯冲 V_NOSE 迫降 | 展开 ≤ 1.5 s、双锁确认；无不对称 | 把"空中展翼"单拎出来验证 |
| A2-02 | **首次完整改平**：150 m 关机 → 俯冲 → 展翼 → 2.0 g 拉平 → 滑翔 | 总掉高 ≤ 84 m，改平后净高 ≥ 60 m，无失控 | **留足高度** |
| A2-03 | 改平 → 巡航 30 s → **腹滑橇滑跑迫降**（遥控） | 全程可控 | |
| A2-04 | 俯冲中人为使空速不足（< 1.1 Vs） | IL-1 拒绝展翼 → 走 V_NOSE 预案，不失控 | 验证互锁 |
| A2-05 | 拉平后重启推进：IL-5 巡航档确认 → 电机重启 → 平飞 | 棘轮未锁档时重启指令被拒 | |
| A2-06 | 平飞中人为断一轴 | 按预案处置 | ⚠ 高风险，**在无人区做** |
| A2-07 | 重复 10 架次 | 成功率 100 % 才进 A3 | |

**A2 的强制条件：**

- 试飞场**四周 300 m 无障碍物、无人**；
- 现场**两人**，一人操作一人观察；
- 备好灭火毯、防爆袋；
- **第一次改平务必在 ≥ 150 m 高度开始**（关机高度 = 150 m 是设计预算的前提，不许降格）；
- 风 ≤ 4 m/s。

> ⚠ **A2-01 与 A2-02 之间的差别**：A2-01 只证明"机翼能在俯冲中可靠展开并锁住"；
> A2-02 才第一次做 2.0 g 拉平。两者都从 150 m 关机开始——**展翼失败或拉平失败都只会摔在软垫上，不会撞山。**

## 12.7 A4 级：迫降（分 L0~L4）

> 见 [06 章](./06-末端迫降与泡沫机头吸能.md) 6.9。**禁止跳级。**

| 级 | 试验 | 判据 |
|:--|:---|:---|
| **L0** | EPP 试样压缩 | 平台应力偏差 ≤ 25 % |
| **L1** | **整机落震**（吊挂释放，水平 15 m/s + 垂直 3 m/s，软土靶） | **峰值过载 ≤ 25 g**；主杆不断；数据舱可读 |
| **L2** | 遥控滑橇滑跑迫降 | 3 次全成功停住 |
| **L3** | 无动力滑翔迫降（100 m 切动力，自动拉平） | 3 次，数据 3 次可读 |
| **L4** | 全自主迫降 | 5 次，成功率 ≥ 80 % |

**L1 落震试验布置**

```
        吊挂释放装置
              │
         ┌────┴────┐
         │  整机     │  ← 姿态：俯角 −8°，速度矢量 15 m/s 水平 + 3 m/s 下沉
         │ (配重到位)│
         └────┬────┘
              │ 释放
              ▼
   ══════════════════════════  软土靶（承载力 30~60 kPa，厚 ≥ 0.8 m）
   靶前 20 m 铺 EPP 缓冲？ ❌ 不要 —— 要测的就是真实土壤犁入

   测量：
   · 机载三轴加速度记录仪 ≥ 500 Hz（数据舱位置 + 机头各一个）
   · 高速摄影（≥ 240 fps）侧面 + 正面
   · 靶上画网格，测犁入深度与滑行距离
```

> **L1 一个样机可能报废。** 建议**先做一个等质量的"配重样机"**（无航电）做 L1，
> 真机只做 L2 以后。这能省下整套航电。

## 12.9 数据记录表（每次飞行必填）

| 字段 | 说明 |
|:---|:---|
| 日期/地点/海拔/气温/风速风向 | 环境 |

## 12.10 中止准则（**任何一条出现立即停飞**）

| # | 现象 |
|:--|:---|
| 1 | 任一承力件出现裂纹、分层、永久变形 |
| 2 | 迫降过载 > 40 g |
| 3 | 电池鼓包、漏液、异味、单串压差 > 0.1 V |
| 4 | 改平（A2）失败率 > 1/10 |
| 5 | 空中出现不明振动或异响 |
| 6 | 互锁任一失效 |
| 7 | 实测重量 > 设计点 +8 %（> 13.6 kg） |
| 8 | 实测 CG 超出允许范围 |
| 9 | 试飞人员不在状态（疲劳、赶时间、天气临界） |

> **第 9 条不是玩笑。这类项目绝大多数事故发生在"就飞最后一次"的时候。**
