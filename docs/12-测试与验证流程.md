# 12 · 测试与验证流程

> **铁律：分级验证，禁止跳级。**
> 本设计的危险环节（自旋过渡、盘旋、迫降）**任何一个都可能在第一次尝试时毁掉整机**。
> 分级的目的不是"慢慢来"，而是**让每一次可能的失败都发生在损失最小的时候**。

---

## 12.1 验证等级

| 级 | 名称 | 场所 | 整机风险 | 前置条件 |
|:--|:---|:---|:---|:---|
| **T** | 台架试验 | 工作台 | 无 | 完成对应施工 Gate |
| **G** | 地面试验 | 场地 | 低 | T 级全过 |
| **A1** | 低空悬停（尾坐） | 试飞场 | 中 | G 级全过 |
| **A2** | 过渡试验 | 试飞场 | **高** | A1 × 20 架次无异常 |
| **A3** | 巡航 + 盘旋 | 试飞场 | 中 | A2 × 10 架次 |
| **A4** | 无动力滑翔迫降 | 软地场地 | **高** | A3 + 落震 L1/L2 |
| **A5** | 全自主剖面 | 真实走廊 | **高** | A4 × 5 架次成功 |

## 12.2 T 级：台架试验

| # | 试验 | 方法 | 判据 |
|:--|:---|:---|:---|
| T-01 | 主杆弯曲 | 简支，FR-2~FR-3 间加载至 600 N·m | 无裂纹，残余变形 ≤ 1 mm |
| T-02 | 机翼静力 | 翼尖加载 190 N（3 g）→ 475 N（2.5×） | 前者无永久变形，后者才破坏 |
| T-03 | 锁销剪切 | 加载 480 N → 720 N | 前者不变形，后者不断 |
| T-04 | **拉力/功率实测** ⚠ | 整机固定 + 拉力传感器 + 功率计；**在 2750 m 等效条件下**（低压舱或到高原实测） | 4 轴合计 ≥ 160 N；峰值功率 ≤ 2.6 kW |
| T-05 | 电池放电 | 1 C 放 10 min；3 C 放 30 s | 最低串 ≥ 3.5 V；温升 ≤ 25 ℃ |
| T-06 | EPP 压缩 | 万能试验机，100 mm/min | 平台应力与理论偏差 ≤ 25 % |
| T-07 | **整头压溃** | 压溃一个吸能头 | 吸能 ≥ 290 J，峰值力 ≤ 3.0 kN |
| T-08 | 折叠循环 | 50 次 | 间隙增大 ≤ 0.1 mm |
| T-09 | 互锁功能 | 见 Gate-9 全 9 条 | 全部通过 |
| T-10 | 配电满载 | 满油门 10 min | 纹波 ≤ 1 V p-p，无过热 |
| T-11 | 相机标定 | 棋盘格 | 重投影误差 ≤ 0.5 px |
| T-12 | 落震准备 | 吊挂释放装置标定 | 释放速度可控 ±0.2 m/s |

> **T-04 是最容易偷懒、也最容易致命的一项。**
> 厂家给的海平面推力曲线到 2750 m 要打 **76 %** 折扣。
> 没有实测，[05 章](./05-动力系统与配电.md) 的所有数字都是猜想。

## 12.3 G 级：地面试验

| # | 试验 | 判据 |
|:--|:---|:---|
| G-01 | 全机称重 + CG | ≤ 15 kg；CG 870 ± 10；横向 ≤ 3 mm |
| G-02 | **尾坐倾覆角** | ≥ 22° |
| G-03 | 舵面/电机转向 | 全部正确 |
| G-04 | 失控保护 | 关控 → 进入预案（不是直接掉） |
| G-05 | 滑跑试验（不脱离地面） | 直线跑 30 m，偏航 ≤ 2 m |
| G-06 | 起旋试验（机轮离地 5 cm，绳系） | 自旋速率 2.0~2.8 Hz，无剧烈进动 |
| G-07 | **消旋试验**（绳系，模拟段 II） | 2.5 Hz → < 0.2 Hz，用时 ≤ 2 s |
| G-08 | 机翼展开试验 | ≤ 1.5 s，双侧同步，锁定指示正确 |
| G-09 | 相机等距触发 | 地面推车，触发间距误差 ≤ 10 % |
| G-10 | LoRa 拉距 | 视距 ≥ 8 km，丢包 ≤ 10 % |
| G-11 | 全系统 30 min 待机 | 无异常；温升正常 |
| G-12 | **演练：数据舱取出** | ≤ 10 s，无工具，3 人各做一次 |

> **G-06/G-07 用绳系**：把飞机用两根绳吊在门框上，允许小幅运动但不落地。
> 这是验证自旋/消旋**最便宜也最安全**的方法。

## 12.4 A1 级：尾坐悬停

| # | 试验 | 判据 |
|:--|:---|:---|
| A1-01 | 垂直起飞到 3 m，悬停 10 s | 无触地，漂移 ≤ 0.5 m |
| A1-02 | 上升到 30 m，悬停 30 s | 高度保持 ±1 m |
| A1-03 | 抗 4 m/s 侧风 | 位置保持 ≤ 2 m |
| A1-04 | **自旋起飞**（段 I）到 5 m | 无剧烈进动，可正常消旋 |
| A1-05 | 消旋后展开机翼（**空中第一次**） | ⚠ **先只展开，不过渡**，消旋后保持竖直降落 |
| A1-06 | 重复 20 架次 | 无异常 |

> **A1-05 的用意**：机翼在空中展开是全机**最不可预测的一步**。
> 单独验证它，失败了也只是摔一次，不会叠加过渡失败。

## 12.5 A2 级：过渡试验（**最高风险**）

| # | 试验 | 判据 | 备注 |
|:--|:---|:---|:---|
| A2-01 | 过渡（竖直 → 平飞），高度 ≥ 100 m | 掉高 ≤ 60 m，无失控 | **留足高度** |
| A2-02 | 过渡 → 平飞 30 s → 转回竖直 → 降落 | 全程可控 | |
| A2-03 | 平飞中人为降低空速到 Q_ASSIST 阈值以下 | 自动补推力，不失控 | |
| A2-04 | 平飞中人为断一轴 | 按预案处置 | ⚠ 高风险，**在无人区做** |
| A2-05 | 重复 10 架次 | 成功率 100 % 才进 A3 | |

**A2 的强制条件：**

- 试飞场**四周 300 m 无障碍物、无人**；
- 现场**两人**，一人操作一人观察；
- 备好灭火毯、防爆袋；
- **第一次过渡务必在 ≥ 120 m 高度开始**；
- 风 ≤ 4 m/s。

## 12.7 A4 级：迫降（分 L0~L4）

> 见 [06 章](./06-末端迫降与泡沫机头吸能.md) 6.9。**禁止跳级。**

| 级 | 试验 | 判据 |
|:--|:---|:---|
| **L0** | EPP 试样压缩 | 平台应力偏差 ≤ 25 % |
| **L1** | **整机落震**（吊挂释放，水平 15 m/s + 垂直 3 m/s，软土靶） | **峰值过载 ≤ 25 g**；主杆不断；数据舱可读 |
| **L2** | 遥控滑橇滑跑迫降 | 3 次全成功停住 |
| **L3** | 无动力滑翔迫降（100 m 切动力，自动拉平） | 3 次，数据 3 次可读 |
| **L4** | 全自主迫降 | 5 次，成功率 ≥ 80 % |

**L1 落震试验布置**

```
        吊挂释放装置
              │
         ┌────┴────┐
         │  整机     │  ← 姿态：俯角 −8°，速度矢量 15 m/s 水平 + 3 m/s 下沉
         │ (配重到位)│
         └────┬────┘
              │ 释放
              ▼
   ══════════════════════════  软土靶（承载力 30~60 kPa，厚 ≥ 0.8 m）
   靶前 20 m 铺 EPP 缓冲？ ❌ 不要 —— 要测的就是真实土壤犁入

   测量：
   · 机载三轴加速度记录仪 ≥ 500 Hz（数据舱位置 + 机头各一个）
   · 高速摄影（≥ 240 fps）侧面 + 正面
   · 靶上画网格，测犁入深度与滑行距离
```

> **L1 一个样机可能报废。** 建议**先做一个等质量的"配重样机"**（无航电）做 L1，
> 真机只做 L2 以后。这能省下整套航电。

## 12.9 数据记录表（每次飞行必填）

| 字段 | 说明 |
|:---|:---|
| 日期/地点/海拔/气温/风速风向 | 环境 |
| 起飞重量 / CG | 每次改装后必记 |
| 电池型号 / 起始电压 / 结束电压 / 消耗 Wh | 能量核对 |
| 各阶段时长与平均功率 | 与 [02 章](./02-需求规格与性能指标.md) 预算比对 |
| 最大过载（全程） | 结构载荷取证 |
| 迫降峰值过载 / 犁入深度 / 滑行距离 | 迫降专项 |
| 影像帧数 / 可读率 / 实测 GSD | 成像 |
| YOLO 检测数 / 人工复核命中数 | 算法 |
| 异常事件 | 任何"不对劲"都要记，**哪怕没造成后果** |
| 机头吸能段序号 / 是否更换 | 耗材追踪 |

## 12.10 中止准则（**任何一条出现立即停飞**）

| # | 现象 |
|:--|:---|
| 1 | 任一承力件出现裂纹、分层、永久变形 |
| 2 | 迫降过载 > 40 g |
| 3 | 电池鼓包、漏液、异味、单串压差 > 0.1 V |
| 4 | 过渡失败率 > 1/10 |
| 5 | 空中出现不明振动或异响 |
| 6 | 互锁任一失效 |
| 7 | 实测重量 > 设计点 +8 % |
| 8 | 实测 CG 超出允许范围 |
| 9 | 试飞人员不在状态（疲劳、赶时间、天气临界） |

> **第 9 条不是玩笑。这类项目绝大多数事故发生在"就飞最后一次"的时候。**
