## 2.4 任务剖面与能量预算（满载 12S4P）

> **v0.3 剖面**：倒拖爬升 → 关机 → 头朝下俯冲 → 展翼 2.0g 拉平 → 巡航 → 盘旋 → 返航 → 软地迫降。

| 段 | 时长 | 平均功率 | 能量 | 说明 |
|:---|---:|---:|---:|:---|
| P1 倒拖爬升（0→150 m） | 45 s | 3100 W | 39 Wh | 悬停 2.9 kW + 爬升增量；峰值 4.1 kW |
| P2 关机 · 俯冲 · 展翼 · 2.0g 拉平 | 25 s | 200 W | 1.4 Wh | 无动力；掉高 ≈ 84 m，剩 ≈ 64 m 净高 |
| P3 滑翔/爬升至巡航高度 | 70 s | 1030 W | 20 Wh | 拉平后低速爬升补能 |
| P4 去程巡航 25 km（下坡 950 m） | 893 s | 600 W | 149 Wh | 下坡回收 ≈ −10 Wh |
| P5 目标区盘旋拍摄 | **600 s** | 485 W | 81 Wh | 10 min |
| P6 返航巡航 25 km + **爬升 950 m** | 893 s | 600 W + 爬升 | 177 Wh | 爬升占 +28 Wh |
| P7 末端迫降剖面 | 60 s | 200 W | 3 Wh | |
| **合计** | **~41 min** | — | **470 Wh** | |
| 电池可用（778 Wh × 80 % DoD） | | | **622 Wh** | **余量 24 %** ✅ |

**标准电池（12S3P，583 Wh，可用 466 Wh）**：把 P5 缩到 **5 min**（−40 Wh）→ 需 430 Wh，余量 **8 %** ⚠。
→ 结论：**满载 12S4P 是"穿越 + 盘旋 + 返航"完整任务的标准配置**；标准电池仅用于短程/训练（倒拖爬升段本身 ~39 Wh，标准电池下余量更紧，优先满载）。

**"用高度换过载"的账**（v0.3 核心取舍，替代 v0.2 的 3~4 g 拉平）：

```
倒拖爬升 150 m 关机 → 无动力下坠（头朝下，尾翼安定）
→ 俯冲增速到 1.25 Vs = 23.4 m/s（掉高 ≈ 28 m）
→ 2.0 g 拉平 90°（掉高 ≈ 56 m）
→ 共需掉高 ≈ 84 m，剩 ≈ 64 m 净高（展翼 + 建滑翔 + 高原裕量）

代价：多爬 70 m（80→150 m）≈ +5 Wh（满载的 0.7 %）
收益：拉平过载从 3~4 g 降到 2.0 g，结构按 2.5 g 设计即可 → 机体显著减重
```

## 2.5 验收判据（Verify Gate）

> 每条都必须在 [12-测试与验证流程.md](./12-测试与验证流程.md) 中有对应试验。

| # | 判据 | 方法 |
|:--|:---|:---|
| V-01 | 全备重量 ≤ 15 kg | 地磅称量 |
| V-02 | 2750 m 等效密度下 T/W ≥ 1.30 | 拉力台实测（或低压舱；**禁止靠厂家曲线外推**） |
| V-03 | 起飞至迫降全程无人工干预 | 全 AUTO 剖面飞行 + 日志审计 |
| V-04 | GNSS 关断 120 s，位置误差 < 60 m | 地面站人为关断 + 差分/RTK 比对 |
| V-05 | 目标区盘旋 ≥ 5 min，影像 GSD ≤ 10 cm | 地面布设已知尺寸标定板 |
| V-06 | 盘旋影像可拼接为完整覆盖图 | 离线 SfM 处理，检查空洞率 < 5 % |
| V-07 | YOLO 对 1.7 m 人体目标的召回率 ≥ 70 % @ 250 m | 实地布靶，人工复核 |
| V-08 | 迫降后数据舱可无工具取出、microSD 可正常读取 | 3 次连续迫降试验 |
| V-09 | 迫降峰值过载 ≤ 25 g（软地） | 机载三轴加速度记录仪（≥ 500 Hz） |
| V-10 | 迫降后主承力杆不折断、电池无变形 | 目视 + 电池内阻/电压检查 |
| V-11 | 机头吸能段更换时间 ≤ 3 min（2 人） | 计时实测 |
| V-12 | LoRa 信标在迫降后 ≥ 2 km 可测向 | 手持测向机 |

## 2.6 不在需求内（Out of Scope）
