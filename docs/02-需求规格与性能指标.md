## 2.4 任务剖面与能量预算（满载 12S4P）

> **v0.3 剖面**：倒拖爬升 → 关机 → 头朝下俯冲 → 展翼 2.0g 拉平 → 巡航 → 盘旋 → 返航 → 软地迫降。

| 段 | 时长 | 平均功率 | 能量 | 说明 |
|:---|---:|---:|---:|:---|
| P1 倒拖爬升（0→150 m） | 45 s | 3050 W | 38 Wh | 收拢态悬停 3.02 kW + 爬升增量；峰值 4.2 kW |
| P2 关机 · 俯冲 · 撑开 · 2.0g 拉平 | 25 s | 200 W | 1.4 Wh | 无动力；掉高 ≈ 90 m，剩 ≈ 60 m 净高 |
| P3 滑翔/爬升至巡航高度 | 70 s | 1030 W | 20 Wh | 拉平后低速爬升补能 |
| P4 去程巡航 25 km（下坡 950 m） | 893 s | **750 W** | **186 Wh** | 双翼代价 +37 Wh（v0.3 为 149 Wh） |
| P5 目标区盘旋拍摄 | **300 s** | **640 W** | **53 Wh** | 5 min（10 min 为 107 Wh） |
| P6 返航巡航 25 km + **爬升 950 m** | 893 s | 750 W + 爬升 | **214 Wh** | 爬升占 +28 Wh |
| P7 末端迫降剖面 | 60 s | 200 W | 3 Wh | |
| **合计（盘旋 5 min）** | **~38 min** | — | **516 Wh** | |
| 电池可用（778 Wh × 80 % DoD） | | | **622 Wh** | **余量 17 %** ✅ |

⚠ **若盘旋拉满 10 min**：合计 **570 Wh**，余量仅 **8 %** —— 在双翼构型下**不再有 v0.3 的 24 % 安全垫**。
→ **v0.4 规定：标准任务盘旋 5 min（R-04 的 ≥ 5 min 硬需求仍满足）**；10 min 盘旋仅允许在航程缩短到 40 km 时使用。

**标准电池（12S3P，583 Wh，可用 466 Wh）**：仅够**短程/训练**（倒拖爬升段本身 ~38 Wh），
完整任务**必须满载 12S4P**，且**不再有 v0.3 的 8 % 底线余量**——标准电池 + 50 km 任务已不可行。

**"用高度换过载"的账**（v0.3 核心取舍，替代 v0.2 的 3~4 g 拉平）：

```
倒拖爬升 150 m 关机 → 无动力下坠（头朝下，十字尾翼安定）
→ 俯冲增速到 1.25 Vs = 23.8 m/s（掉高 ≈ 29 m）
→ 动压触发双翼雨伞撑开 + 棘爪自锁
→ 2.0 g 拉平 90°（掉高 ≈ 58 m，双翼阻力多耗 ≈ 3 m）
→ 共需掉高 ≈ 90 m，剩 ≈ 60 m 净高（撑开 + 建滑翔 + 高原裕量）

代价：多爬 70 m（80→150 m）≈ +5 Wh（满载的 0.7 %）
收益：拉平过载从 3~4 g 降到 2.0 g，结构按 2.5 g 设计即可 → 机体显著减重
```

## 2.5 验收判据（Verify Gate）

> 每条都必须在 [12-测试与验证流程.md](./12-测试与验证流程.md) 中有对应试验。

| # | 判据 | 方法 |
|:--|:---|:---|
| V-01 | 全备重量 ≤ 15 kg | 地磅称量 |
| V-02 | 2750 m 等效密度下 T/W ≥ 1.05（v0.4 因增重降至 1.06，裕度薄） | 拉力台实测（或低压舱；**禁止靠厂家曲线外推**）；< 1.05 必须减重或加大桨径 |
| V-03 | 起飞至迫降全程无人工干预 | 全 AUTO 剖面飞行 + 日志审计 |
| V-04 | GNSS 关断 120 s，位置误差 < 60 m | 地面站人为关断 + 差分/RTK 比对 |
| V-05 | 目标区盘旋 ≥ 5 min，影像 GSD ≤ 10 cm | 地面布设已知尺寸标定板；**10 min 盘旋需航程降至 40 km** |
| V-06 | 盘旋影像可拼接为完整覆盖图 | 离线 SfM 处理，检查空洞率 < 5 % |
| V-07 | YOLO 对 1.7 m 人体目标的召回率 ≥ 70 % @ 250 m | 实地布靶，人工复核 |
| V-08 | 迫降后数据舱可无工具取出、microSD 可正常读取 | 3 次连续迫降试验 |
| V-09 | 迫降峰值过载 ≤ 25 g（软地） | 机载三轴加速度记录仪（≥ 500 Hz） |
| V-10 | 迫降后主承力杆不折断、电池无变形 | 目视 + 电池内阻/电压检查 |
| V-11 | 机头吸能段更换时间 ≤ 3 min（2 人） | 计时实测 |
| V-12 | LoRa 信标在迫降后 ≥ 2 km 可测向 | 手持测向机 |
