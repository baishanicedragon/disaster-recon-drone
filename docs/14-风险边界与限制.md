# 14 · 风险边界与限制

> **这一章是给"想跟着做的人"看的。先读它，再读其他章。**

---

## 14.1 一句话风险声明

> **本设计的所有数字都是纸面推算。它从未飞过。**
> 按本文档制作的飞行器，**很可能第一次起飞就摔**；
> **即使飞起来了，末端迫降仍有很高概率损坏机体与数据。**
> 若你无法接受整机损失与可能的人身伤害风险，**不要制作**。

## 14.3 逐条说明与缓解

### R-01 末端迫降损毁 🔴

| 项 | 内容 |
|:---|:---|
| 为什么高风险 | 迫降是**主动撞击**。设计计算的 25 g 目标依赖软地承载力（30~60 kPa），**这个参数在现场很难准确判断** |
| 最坏情况 | 硬地 → 过载 40 g+ → 数据舱损坏 → **任务归零** |
| 缓解 | ① **先做配重样机做 L1 落震**；② 场地**人工先确认**（不是靠算法判断）；③ 数据舱双卡镜像；④ 每次任务带 3 个吸能头；⑤ **先做 5 次 L3 无动力迫降再上真任务** |
| **硬约束** | **禁止在未经人工确认的场地自主迫降** |

### R-02 无动力改平段失控 🔴

| 项 | 内容 |
|:---|:---|
| 为什么高风险 | 关机后整机无动力：先头朝下俯冲增速、再展翼、再 2.0 g 拉平，**每一步之间都是不可逆的时序**，任一环失败都要走机头迫降备用剖面 |
| 缓解 | ① 关机高度 **150 m**、改平预算掉高 ≤ 84 m、净高 ≥ 60 m；② **IL-1 动压 + 高度双门控**才允许展翼；③ IL-2 双锁确认才允许拉平；④ 改平限 2.0 g（超过 2.5 g 自动缓拉）；⑤ **A2 级必须在 ≥ 150 m 开始、四周 300 m 无人**；⑥ 先做构型 T（固定翼）验证平台，把巡航链先跑稳 |
| **硬约束** | 改平试验**必须两人到场 + 灭火毯** |

### R-03 机翼空中未锁定 🔴

| 项 | 内容 |
|:---|:---|
| 为什么高风险 | 折叠机构是单点失效；一旦空中脱锁，机翼瞬间不对称 |
| 缓解 | ① **硬件互锁 IL-2（双微动开关）**；② 弹簧失效安全（断电自动锁）；③ 锁销 1.5 倍静力试验；④ 空中第一次展开（A2-01）**单独验证，不过渡**（先展翼、不拉平，直接机头迫降软垫） |
| **硬约束** | 未确认双锁 → **禁止进入拉平** |

### R-04 倒拖爬升段失稳 🔴

| 项 | 内容 |
|:---|:---|
| 为什么高风险 | 倒拖段**无空速、无气动安定**，只靠"质量悬挂在推力线下"的摆式稳定 + 差动推力；起飞瞬间推力线偏心会直接表现为斜爬 |
| 缓解 | ① **横向 CG ≤ 3 mm 是硬指标**（Gate-13 实测）；② 4 电机相邻反向对转自消反扭矩；③ 差动推力阻尼摆振（固有频率 ~0.5 Hz，飞控带宽内）；④ 起飞风速 ≤ 6 m/s；⑤ **G-06 系留倒拖**先在绳上验证推力线，再上真高度 |
| **硬约束** | 系留试验若出现持续漂移/斜爬 → **停飞查 CG 与推力线**，不修好不升空 |

### R-05 峡谷内撞山 🔴

| 项 | 内容 |
|:---|:---|
| 为什么高风险 | 实时避障**反应时间不足**（4.3 s vs 需要 8+ s）；30 m DEM 在窄谷里误差可达 10~30 m |
| 缓解 | ① 净空从 100 m 提到 **150 m**；② 尽量申请高分辨率 DEM；③ 航路按走廊内最高地形算净空；④ 前向毫米波作最后一道 |
| **硬约束** | **禁止在未经 DEM 预规划与人工复核的峡谷飞行**；**禁止夜航** |

### R-06 锂电热失控 🔴

| 项 | 内容 |
|:---|:---|
| 为什么高风险 | 主动撞击 → 电池受挤压 → 内短路 → 热失控；高原救援条件差 |
| 缓解 | ① **强制使用钢壳 21700**（不用软包）；② 铝内衬 + EVA；③ 迫降后**先观察 30 min 再靠近**；④ **首次任务必带灭火毯 + 防爆袋**；⑤ 电池异常 → 隔离，勿移动 |
| **硬约束** | 现场**必须有灭火器材**；**禁止在室内/车内给受损电池充电** |

### R-14 法规风险 🔴

| 项 | 内容 |
|:---|:---|
| 为什么高风险 | 12.55 kg 属中型无人机；25 km 超视距、自主飞行、高原边境地区，**每一条都需要审批** |
| 缓解 | 本文档**不提供任何合规依据**。请自行：实名登记、空域申请、飞行计划报备、持证飞行 |
| **硬约束** | **边境地区飞行另有严格管制**——吉隆属边境管理区，实际作业必须取得全部许可 |

## 14.4 已知的设计局限（不打算在本版解决）

| # | 局限 | 影响 |
|:--|:---|:---|
| L-1 | **无防冰** | 云中飞行 < 2 min；雨季任务窗口受限 |
| L-2 | **无夜视** | 只能昼间作业 |
| L-3 | **无实时链路** | 无法中途改任务；无法实时回传疑似目标位置 |
| L-4 | 单次只能覆盖一个目标区 | 0.7 km² 需要 10 min 盘旋，若目标区更大需多架次 |
| L-5 | 迫降后需要人到现场取数 | 若回收场也不可达，数据仍拿不回 |
| L-6 | 机体复用依赖现场更换吸能头 | 需携带备件 |
| L-7 | YOLO 在小目标（26 px）上召回率有限 | 主要靠人工判读 |
| L-8 | 30 m DEM 精度不足 | 净空余量大 → 航程与成像高度受限 |

## 14.5 明确不要做的事

| ❌ 不要 | 原因 |
|:---|:---|
| 不要加战斗部 / 火工品 / 抛射物 | 红线；且改变法律性质 |
| 不要在人群上空飞行 | 12.55 kg 坠落的致命性 |
| 不要在未经确认的场地自主迫降 | R-01 |
| 不要在边境地区未经许可飞行 | R-14，后果严重 |
| 不要跳过验证等级 | 本设计的高危环节无法"边飞边调" |
| 不要用 EPS 替代 EPP | EPS 脆性，吸能能力差 |
| 不要用软包锂电 | R-06 |
| 不要一个人试飞 | 出事无人施救 |
| 不要在"就飞最后一次"的心态下飞行 | 统计上事故高发于此 |
| 不要相信本文档的任何未经你实测的数字 | 全部是纸面推算 |

## 14.6 与真实救援的关系（**重要的边界**）

| 必须说清楚 | 说明 |
|:---|:---|
| **这不是救援装备** | 真实救援由专业队伍执行 |
| **它不会救人** | 它只能提供影像，而且大概率提供得不够好 |
| **不要用它挡住专业力量** | 个人或业余装备进入灾区，可能反而占用救援资源、制造新的事故 |
| **影像涉及遇难者** | 默认**不公开**；如需提交给救援方，按对方要求处理 |
| **本仓库不发布任何灾区影像** | 这是有意的自我约束 |

## 14.7 如果你仍然要做

**最低安全清单（缺一不可）：**

- [ ] 至少有 **2 人**，且都了解锂电风险
- [ ] 有**合法场地**（远离人群、远离建筑、远离边境敏感区）
- [ ] 有**灭火毯 + 防爆袋 + 护目镜 + 手套**
- [ ] 已完成 **T 级全部台架试验**
- [ ] 已完成 **G 级地面试验**
- [ ] 第一次改平（A2）在 **≥ 150 m 高度开始 + 四周 300 m 无人**
- [ ] 迫降场地**已人工确认**（承载力、坡度、无障碍）
- [ ] 每次飞行前走完 [11 章](./11-施工顺序与装配工艺.md) 的 10 项检查
- [ ] 已知晓**中止准则**（[12 章](./12-测试与验证流程.md) 12.10）
- [ ] 心理上接受**整机损失**
