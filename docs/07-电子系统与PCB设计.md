## 7.2 主控与飞控

### 7.2.1 飞控选型

| 选项 | 优点 | 缺点 | 结论 |
|:---|:---|:---|:---|
| **ArduPilot（STM32H7 飞控板）** | **原生支持固定翼巡航 + 地形跟随 + 航点 + 失速保护**，平飞段零开发；生态成熟 | 倒拖段与"关机-俯冲-改平"剖面需自定义状态机 | **选它** |
| PX4 | 学术与开源生态好 | 同需自定义倒拖/改平剖面，且周边工具链不如 ArduPilot | 备选 |

> **为什么 ArduPilot 是本项目的关键使能**：
> 平飞段的常规控制、地形跟随（`terrain.ardupilot.org` 地形文件）、RTL/自动降落
> 全部是**已经存在且经过大量实飞验证的功能**；倒拖段和改平段作为**自定义状态机**挂接在 AUTO 之外。
> 自己从零写全套飞控 = 项目失败率翻倍。

**必需参数（初值，需 AutoTune）**：

| 参数 | 值 | 说明 |
|:---|:---|:---|
| `Q_FRAME_CLASS` | 不启用 Q-hover（倒拖段自定义状态机） | 倒拖段与改平段由自定义逻辑接管 |
| `RESTART_CRUISE_ASP` | 22 m/s | 拉平后重启推进的空速门槛（高于 1.15 Vs） |
| `TERRAIN_ENABLE` | 1 | 地形跟随（DEM 文件放 SD 卡） |
| `TERRAIN_FOLLOW` | 1 | |
| `TERRAIN_MARGIN` | 视净空设定 | |
| `EK3_SRC1_POSXY` | GPS | 主定位源 |
| `EK3_SRC1_VELXY` | GPS | |
| `EK3_SRC1_POSZ` | BARO | 高度以气压为主（峡谷内 GPS 高误差大） |
| `AHRS_EKF_TYPE` | 3 | EKF3 |
| `FS_GCS_ENABLE` | 0 | **禁止链路失效触发 RTL**（本设计无链路） |
| `BATT_FS_LOW_ACT` | 2 | 低电进入返航/迫降 |
| `AIRSPEED_MIN` | 20 m/s | 失速保护：低于 1.1 Vs 禁止展翼/拉平（见 7.2.2） |

> ⚠ **参数名以实际固件版本为准**，ArduPilot 参数会重命名。请以官方最新文档为准。

### 7.2.2 倒拖段 + 无动力改平控制器（自定义）

ArduPilot **不支持**"机头朝下倒拖爬升 + 关机俯冲 + 展翼改平"这套剖面。需要自定义一个任务状态机（挂 AUTO 外）：

```
段 1 倒拖爬升（0 → 150 m，~45 s）
  姿态：机头朝下（俯仰 -90°），4 桨对转、推力竖直向上
  稳定：被动摆式为主；差动推力仅做阻尼（横向 CG < 3 mm 保证）
  输出：4 电机油门 = f(爬升率误差)，差动微调 = f(陀螺速率)

段 2 关机（T+45 s）
  4 电机停转 → 桨叶气动顺桨折叠
  （若爬升速率 > 1 m/s，先减速再关机，减少上飘过冲）

段 3 头朝下俯冲（惯性上飘 → 反向 → 增速至 1.25 Vs ≈ 23.4 m/s）
  控制：只做阻尼（角速率阻尼 + 小量配平），不急于改出
  门控：空速 ≥ 1.1 Vs（20.6 m/s）且高度 ≥ 90 m → 解锁机翼展开（硬件互锁）
       任一不满足 → 放弃改平，进入"机头朝下迫降"备用剖面

段 4 2.0 g 拉平（~5 s，掉高 ≈ 54 m）
  尾翼拉起，俯冲 -90° → 水平；限制最大 2.5 g（超过自动缓拉）
  拉平完成判定：俯仰 |θ| < 15° 且空速 > 1.15 Vs

段 5 棘轮切巡航档 + 重启推进
  电磁销/棘轮把桨距从爬升大距切到巡航小距（一次性，锁存）
  重启电机 → 离心甩开折叠桨叶 → ArduPilot 常规控制接管
```

> **⚠ 这是全项目技术风险最高的一项（B 级：工程极难但合理可实现）。**
> **降低风险的做法（强烈建议）**：
> 1. **分步验证**（[03 章 Q2](./03-总体方案与气动布局.md)）：先系留测倒拖爬升 → 再用滑翔机投放测无动力改平 → 最后合全剖面；
> 2. 倒拖段本身**只做推力 + 阻尼**，不追求全姿态闭环（垂直上升 + 摆式稳定下，开环即可大概率成立）；
> 3. 展翼门控与棘轮切换都用**独立硬件信号**（动压开关 / 微动开关）而非纯软件判定，降低单点失效。

## 7.3 感知器件

| 器件 | 选型等级 | 关键指标 | 用途 |
|:---|:---|:---|:---|
| **IMU 主** | BMI088 / ICM-42688-P 级 | 陀螺量程 **≥ ±2000 °/s**，噪声 ≤ 0.05 °/s/√Hz，带宽 ≥ 200 Hz | 姿态 + 倒拖爬升阻尼 |
| **IMU 备** | 与主 IMU **不同型号**（避免共模失效） | 同上 | EKF 冗余 |
| **气压计 ×2** | DPS310 / BMP390 级 | 噪声 ≤ 0.06 Pa，**相对精度 ±0.03 m** | **主高度源**（峡谷内） |
| **空速计** | MS4525DO 级差压 | ±1 % FS | 失速保护、过渡判定 |
| **GNSS** | u-blox **M10** 级（L1 单频四星座） | 更新率 10 Hz，水平精度 ~1.5 m CEP | 主定位 |
| GNSS 增强（可选） | u-blox **F9P** 双频 | 抗多路径显著更好 | 预算允许时强烈建议 |
| **磁罗盘** | IST8310 / RM3100 级 | — | ⚠ **峡谷内磁异常严重**，权重调低或禁用 |
| **测高（末端）** | 激光 ToF（≥ 40 m）或 24 GHz 雷达 | ±5 cm @ 10 m | P7-3/P7-4 拉平与触地 |

> **磁罗盘警告**：吉隆沟是深切构造带（南北向正断层 + 节理），
> 岩体磁性不均匀 → **磁罗盘误差可达数十度**。
> **对策**：起飞前在已知航向完成校准；飞行中**用 GPS 航向（COG）作为主航向源**，磁罗盘仅作静态初始化。

## 7.4 视觉与成像

### 7.4.1 两条独立的视觉通道

```
通道 A：实时识别（低延迟、低功耗、可跑全程）
  STM32N6（Arm Cortex-M55 @800 MHz + Neural-ART NPU）
  + 全局快门 CMOS（如 OV9282 / AR0234 级，1~2 MP）
  → YOLOv8n 量化到 INT8，256×256 输入，目标 ≥ 15 fps
  → 输出：目标类别 + 像素坐标 + 置信度 → 通过 UART/MAVLink 给飞控
  → 用途：① 回收场十字标检测；② 疑似人体/车辆打点；③ 地平线检测（姿态备份）

通道 B：高清成像（高分辨率、事后处理）
  IMX477 级 1/2.3" 12 MP（4056 × 3040，1.55 µm）+ 6 mm 定焦
  + 小型 Linux 板（如 Raspberry Pi Zero 2W / CM4 级）
  → 定时触发（1~2 fps）或按航迹等距触发
  → 写入 microSD（≥ 256 GB U3/V30），带 EXIF 中的 GPS/姿态标签
  → 用途：事后 SfM 拼接 + 人工判读
```

### 7.4.2 GSD 计算

```
GSD = (h × p) / f
  h = 250 m AGL
  p = 1.55 µm（像元）
  f = 6 mm
GSD = 250 × 1.55e-6 / 6e-3 = 0.0646 m = 6.5 cm  ✅
```

| 高度 AGL | GSD | 判读能力 |
|---:|---:|:---|
| 150 m | 3.9 cm | 可辨人体姿态、车辆型号 |
| **250 m** | **6.5 cm** | **可辨人体轮廓、车辆、建筑结构** |
| 400 m | 10.4 cm | 仅大型目标 |

### 7.4.3 运动模糊校核（盘旋段）

```
盘旋 V = 23 m/s，高度 250 m
地物在像面的角速度 = V / h = 23 / 250 = 0.092 rad/s
像面线速度 = 0.092 × f = 0.092 × 6e-3 = 5.5e-4 m/s = 0.55 mm/s

快门 1/2000 s = 0.5 ms → 像移 = 0.55 × 0.0005 = 0.28 µm
像元 1.55 µm → 像移 = 0.18 像元   ✅ 完全可忽略
```

> **对比 v0.1/v0.2**：自旋/倒拖段都不成像（成像只在盘旋平飞段进行），
> 平飞段像移 0.18 像元，可忽略——这是本次收敛最大的隐性收益。

### 7.4.4 曝光与光照

| 条件 | 设置 |
|:---|:---|
| 高原晴天（照度可达 10 万 lx） | 1/2000 s，f/4，ISO 100 |
| 云雾/阴天 | 1/1000 s，f/2.8，ISO 200~400 |
| 建议 | **固定快门优先（S 模式）**，ISO 自动上限 800 |
| 强烈建议 | 加 **ND4~ND8 滤镜** 保证白天也能用大光圈短快门 |

### 7.5.1 板卡清单

| 板 | 层 | 尺寸 | 说明 |
|:---|:---|:---|:---|
| **主配电板** | 2 层，2 oz 铜 | 100 × 60 mm | 200 A 主回路、预充、分流器、4 路 ESC 输出、BEC 输入 |

### 7.5.2 主配电板框图

```
         ┌──────────────────────────────────────────────┐
  XT90   │  12S+ ──┬── 预充电阻(10Ω/50W) ──┐            │
  ───────┤         │                       │            │
  输入   │         └── 接触器/理想二极管 ───┤            │
         │                                 │            │
         │   200 A 主保险 │ 分流器(100A/75mV)│           │
         │                                 │            │
         │   4700 µF/63 V 母线电容 ×2（低 ESR）           │
         │                                 │            │
         │  ┌──────┬──────┬──────┬──────┐  │            │
         │  │ESC1  │ESC2  │ESC3  │ESC4  │  │            │
         │  │+ 470µF each         │      │  │            │
         │  └──────┴──────┴──────┴──────┘  │            │
         │                                 │            │
         │  BEC 12V/15A（伺服）  BEC 5V/8A（飞控）        │
         │  BEC 5V/3A（视觉）    BEC 19V/2A（相机）       │
         │                                 │            │
         │  INA226 ×2（母线电流/电压遥测 → I2C）          │
         │  反接保护：理想二极管（非肖特基，压降小）        │
         └──────────────────────────────────────────────┘
```

**布线要点：**

| 项 | 要求 |
|:---|:---|
| 主回路铜厚 | **2 oz 起**，大电流路径开窗镀锡或加铜条（载流 60 A 峰值 90 A） |
| 载流宽度 | 2 oz 外层 60 A 需 ≥ 25 mm（或双面并联 + 过孔阵列） |
| 过孔 | 主回路过孔 ⌀0.5 mm × 阵列（≥ 12 个） |
| 电容布置 | ESC 输入电容**紧贴**接插件，回路面积最小 |
| 地平面 | 4 层板保留完整地层；2 层板（配电）功率地与信号地**单点连接** |
| 爬电距离 | 50.4 V（满充）属 SELV，但**高原低气压**下需加大爬电：≥ 1.5 mm，开槽 |

> ⚠ **高原低气压爬电**：2750 m 气压约 72 kPa，空气绝缘强度下降约 25 %。
> 高压端子间距按**海拔 5000 m 修正**（间距 ×1.4），并**全部涂三防漆**。

### 7.5.3 数据舱主板

```
  ┌────────────────────────────────────────────────┐
  │  STM32N6（M55 800 MHz + Neural-ART NPU）        │
  │   ├── 8/16 MB OctoSPI Flash（模型 + 固件）       │
  │   ├── 32 MB HyperRAM（推理工作区）              │
  │   ├── CSI-2 → 全局快门 CMOS（识别用）            │
  │   ├── microSD ×1（主）U3/V30                    │
  │   ├── IMU（BMI270 级）用于帧间去抖              │
  │   ├── 2S 200 mAh 后备锂电 + 充电管理            │
  │   │     ↑ 关键：撞击后主电断开仍能完成写入      │
  │   ├── UART → 飞控（MAVLink 隧道）               │
  │   └── USB-C（地面取数 / 调试）                  │
  │                                                 │
  │  12 MP 相机模组（独立，MIPI → Linux 小板）      │
  │   ├── 6 mm 定焦（或等效 35 mm 视角）            │
  │   ├── 相机触发信号 ← 飞控 GPIO（等距触发）      │
  │   └── microSD ×2（镜像备份）                    │
  └────────────────────────────────────────────────┘
```

**写入可靠性三保险：**

1. **循环落盘**：每 5 s 强制 `fsync`，不允许长时间缓存；
2. **后备电池**：主电断开后仍可完成当前帧写入 + 关闭文件系统；
3. **双卡镜像**：两张 microSD 同时写，任一可读即可。

## 7.6 通信

| 链路 | 频段 | 用途 | 要求 |
|:---|:---|:---|:---|
| **LoRa 遥测** | 868 / 915 MHz | 单向下行：位置、姿态、电量、状态字 | 5~10 kbps，≥ 8 km 视距 ⚠；**不接受上行指令** |
| **LoRa 信标** | 433 MHz 或同频分时 | 迫降后求救定位 | 每 10 s 一帧，续航 ≥ 6 h |
| 2.4 GHz 遥控 | 2.4 GHz | **仅用于测试与人工接管** | 任务模式（AUTO）下**不依赖**它 |
| 蜂鸣 + LED | — | 近距离寻的 | ≥ 95 dB @ 1 m |

> **为什么不接受上行链路？**
> 1. 峡谷内链路不可靠，收到一半指令比收不到更危险；
> 2. "尽可能不依赖操纵员"是硬需求（R-02）；
> 3. 单向链路不会被劫持 → 安全边界更清晰。
> **保留一人一机的物理急停**：地面站有一个"降落伞模式/立即迫降"的独立开关，
> 但它触发的是**机上预案**，不是遥控飞行。

## 7.8 环境适应性

| 项 | 要求 | 措施 |
|:---|:---|:---|
| 温度 | −20 ~ +45 ℃（高原昼夜） | 电池舱保温（EVA 内衬）；相机/电池预热可选 |
| 低气压 | 2750 m（72 kPa），爬升余量按 4000 m | **加大爬电距离、三防漆、密封舱 + 透气阀** |

| 电磁 | 峡谷内无干扰源，但机内干扰强 | 见 [05 章](./05-动力系统与配电.md) 5.5.2 |
| 冷凝 | 昼夜温差大 | 舱内放干燥剂；**起飞前开舱晾 10 min** |

## 7.9 器件风险

| 器件 | 风险 | 缓解 |
|:---|:---|:---|
| STM32N6 | 较新，工具链/例程在演进 | 备选：K210（MaixPy/NNCASE 生态成熟）、i.MX RT1170 + TinyMaix |

| 21700 电池 | 高倍率型号供货波动 | 设计兼容多种 21700；**必须实测内阻一致性（≤ 5 mΩ 偏差）** |
