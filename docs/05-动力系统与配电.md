## 5.2 垂直起飞推力预算（动量理论）

### 5.2.1 桨盘载荷

> **v0.3 口径（2026-09-08 修正）**：桨径从 24" 收敛到 **13"**。
> 24" × 4 在 ⌀140 机尾需要横向 ~1.3 m 的十字支架，在 1.55 m 机体上不合理（已被否决）；
> 上一轮曾给出"桨心半径 0.15 m / 外廓 0.63 m"，**几何上不成立**——13" 桨半径 0.165 m，
> 桨心距轴 0.15 m 会导致相邻桨盘互穿、桨叶扫过机身轴线。**无干涉下限是桨心半径 0.245 m**。

```
需求总推力 T = 1.26 × 126.8 = 160 N（峰值，仅极端风修正；正常爬升 < 1.15）

选 13" 桨（D = 0.3302 m），单盘面积 A₁ = π × 0.1651² = 0.0856 m²
4 桨总面积 = 0.3424 m²

几何约束（4 桨 X 型 90° 环布，桨盘不得互穿）：
   相邻桨心距 ≥ 1.05 D = 0.347 m
   → 桨心半径 R ≥ 0.347 / √2 = 0.245 m
   → 尾部外廓半径 = R + D/2 = 0.410 m，横向全宽 ≈ 0.82 m
   （对比：24" 方案的 1.3 m，收敛 37 %；仍是 1.55 m 机体上的"尾环"，但不再是十字架）

桨盘载荷 DL(悬停) = 126.8 / 0.3424 = 370 N/m²
桨盘载荷 DL(峰值) = 160 / 0.3424 = 467 N/m²
（中等盘载；代价见 5.2.2——比 24" 低盘载方案多耗 ~0.4 kW，换取合理的安装几何）
```

### 5.2.2 悬停功率

```
标准 11.77 kg：T_hov = 115.5 N
诱导速度 v_i = √(T / (2ρA)) = √(115.5 / (2 × 0.933 × 0.3424)) = √180.6 = 13.4 m/s
理想功率 P_ideal = T × v_i = 115.5 × 13.4 = 1549 W

取 FoM = 0.70（折叠桨 + 变距棘轮毂的附加损耗）
P_轴 = 1549 / 0.70 = 2213 W

电机效率 0.88 × 电调效率 0.96 = 0.845
P_电 = 2213 / 0.845 = 2619 W   →  I = 2619 / 44.4 = 59.0 A（电池端）

满载 12.93 kg：T_hov = 126.8 N → v_i = 14.09 m/s
  P_ideal = 1787 W → P_轴 = 2553 W → P_电 ≈ 3.02 kW → 68 A
峰值（1.26 T/W，极端风修正）：P_电 ≈ 4.2 kW → ~95 A（< 2 s，罕见）
```

> **关于"1.7 kW"这个数**：v0.4 评审阶段常说的"倒拖悬停 1.7 kW"是**理想功率 P_ideal**（1.79 kW），
> 尚未乘 FoM 与电气效率。文档统一口径为 **电功率 3.02 kW**（= 1.79 / 0.70 / 0.845）。
> 真正被避免掉的不是这 1.79 kW，而是**机翼展开时挡住桨下洗流**所需的 4.3~4.9 kW——
> 双翼**收拢贴体**让下洗流问题消失，所以**不需要为倒拖段增容电机**。

**单轴需求**（满载悬停）：推力 31.7 N（3.2 kgf），轴功率 ~638 W
**爬升（150 m）能量成本**：ΔPE = 126.8 × 150 = 19.0 kJ ≈ **5.3 Wh**（约满载 778 Wh 的 0.7 %）——
**这就是"用高度换过载"的代价，几乎为零。**

> ⚠ **变距棘轮毂的 FoM 惩罚需要实测**：折叠 + 变距 + 单向棘轮三者叠加，
> 若 FoM 实测 < 0.65，悬停功率升至 ~3.25 kW（73 A），仍在 12S4P 能力内，但爬升时间需加长。
> ⚠ **v0.4 新增风险**：MTOW 由 12.55 增至 12.93 kg，2750 m 实推 T/W 由 **1.09 降到 1.06**。
> 这是全机裕度最薄的一环——12 章 T-04 必须实测；若 < 1.05，优先减重（相机/结构），
> 其次考虑 13" → 14" 桨（需重算桨心半径与尾段外廓）。

### 5.2.3 高原折减的量化

| 海拔 | ρ | 同样桨/转速下的推力 | 同样推力所需功率 |
|---:|---:|---:|---:|
| 0 m | 1.225 | 100 % | 100 % |
| 1800 m | 1.024 | 84 % | **+10 %** |
| **2750 m** | **0.933** | **76 %** | **+15 %** |
| 4200 m | 0.804 | 66 % | +23 % |

> **教训**：若按海平面数据选"4 × 4.5 kgf = 18 kgf 推力"的电机，
> 到 2750 m 只有 **13.7 kgf**，对 12.93 kg 的飞机 **T/W = 1.06** —— **能离地，但 controllability 极差，一阵风就摔。**
> **必须按高原口径（而非海平面曲线）选件，并给 v0.4 的增重留 0.03 的 T/W 余量。**

## 5.3 电机 / 电调 / 桨选型目标

> ⚠ **以下为"目标规格"，候选型号需实测确认。不要照抄型号。**

| 项目 | 目标规格 |
|:---|:---|
| 电机 | 4 × 无刷，**KV 300~400**（配 12S、13" 桨），单轴**静态推力 ≥ 4.5 kgf @ 2750 m 等效**，连续功率 ≥ 700 W |
| 单电机质量 | ≤ 320 g |
| 电调 | 4 × **80 A**，12S 兼容，BLHeli_32 / AM32，支持 DShot1200 + 双向遥测（转速/电流/温度） |
| 桨 | 4 × **13" × 6.5"** 碳纤**折叠桨**；**相邻两桨反向（CCW/CW 成对）**，反扭矩自消 |
| 变距 | **棘轮单向两档**（爬升大距 → 巡航小距），升空后一次性切换、不回爬升档；停机时桨叶**气动顺桨折叠**（见 5.3.1） |
| 桨安装 | 桨心半径 **0.245 m**（X 型 90° 环布，相邻桨心距 ≥ 0.347 m，无盘面互穿），轴向错位 ≥ 30 mm |

**候选（需实测，非背书）**：T-Motor MN4014 / MN5008 / AT4120 系列、Hobbywing XRotor 60 A 级、国产 4014/4120 同级件。
**验证方法**：见 [12 章](./12-测试与验证流程.md) T-04（拉力台 / 低压舱实测）。

### 5.3.1 变距与顺桨（v0.3 新增）

- **为什么变距**：倒拖爬升时桨向机头排气（推力向上），平飞巡航时向机尾排气（推力向前），
  同一副**定距**桨的排气方向由旋转方向锁定 → 两阶段方向相反 → 要么电机倒转（双向 ESC），要么**桨距反装**。
  v0.3 选**变距**：电机保持同向，靠桨距切换两种模式（顺滑、不依赖 ESC 双向能力）。
- **为什么棘轮单向两档**：整段飞行只需切换**一次**（升空后爬升档→巡航档），不需要双向连续变距；
  用电磁销/棘轮锁两个桨距位，比全伺服变距轻 ~1.2 kg（省 4 套伺服 + 电滑环）。
- **停机顺桨折叠**：下坠/滑翔段桨停转，桨叶在气动力下**自动顺桨折叠**（与储备时同一折叠机构），
  消除风车阻力和盘面阻力；巡航重启时离心力甩开桨叶 + 棘轮已锁巡航档。
- **重量账**：4 ×（变距棘轮毂 60~90 g + 电磁销 15 g）≈ 0.3~0.4 kg，加折叠机构共约 0.5 kg；
  相比 24" 时代的尾部十字支架（约 0.9 kg 结构 + 更大桨）**净减重**。

### 5.4.2 为什么不用 LiPo 软包

| 项 | 21700 锂电 | LiPo 软包 |
|:---|:---|:---|
| 能量密度（pack 级） | 200~230 Wh/kg | 160~190 Wh/kg |
| 低温（高原夜间 −10 ℃） | 较好 | **明显衰减** |
| 抗挤压/抗穿刺（迫降！） | **钢壳，好很多** | 差，鼓包/起火风险高 |
| 循环寿命 | 300~500 | 150~300 |
| 成本 | 高 | 低 |

> **迫降工况是选型的第一驱动**：本设计主动撞地，电池**必须**是钢壳 21700。

### 5.4.3 BMS 与保护

| 功能 | 要求 |
|:---|:---|
| 均衡 | 主动/被动均衡，**起飞前必须完成** |
| 过放 | 单体 ≤ 2.8 V 切断（但飞控侧按电压 + 电量双重判断） |
| 过流 | 持续 ≤ 120 A，峰值 ≤ 200 A |
| 温度 | 每 12 串至少 2 个 NTC，**> 60 ℃ 降额**、> 70 ℃ 告警 |
| 遥测 | 通过 CAN/I2C 上报最高/最低单体电压、温度、剩余电量给飞控 |
| 结构 | 铝内衬壳体 + 3 mm EVA + 防挤压梁（见 [04 章](./04-结构设计与材料.md) 4.8） |

## 5.6 巡航与盘旋功率（复核）

| 段 | V | 推力需求 | 推进效率 | 电功率 |
|:---|---:|---:|---:|---:|
| 巡航（2200 m） | 28 m/s | 10.6 N | 0.62 | **563 W** |
| 盘旋（2050 m，20° 坡） | 23 m/s | 10.6 N | 0.65 | **442 W** |
| 爬升（返航 +950 m） | — | +126.8 N × sinγ | — | 额外 **+117 W**（按 1.5 m/s 爬升率，γ=3°） |

```
爬升额外功率校核：
爬升率 RC = 1.5 m/s → ΔPE/dt = 126.8 N × 1.5 m/s = 190 W
考虑爬升时升阻比下降与推进效率 → 额外电功率 ≈ 185 / (0.62 × 0.85) = 351 W?? 
```
⚠ **此处需要修正**：前面 2.4 表按 "+28 Wh" 估算爬升，对应约 **+113 W × 893 s = 28 Wh**。
两种算法不一致（113 W vs 351 W）。**保守取大值 351 W**：

```
返航段电功率 = 563 + 351 = 914 W × 893 s = 227 Wh（原估 177 Wh）
任务总能量重算 = 20 + 5 + 20 + 149 + 81 + 227 + 3 = 505 Wh
可用 622 Wh → 余量 23 %   ✅ 仍然足够
```

> **⚠ 待验证项（高优先级）**：爬升功率的两种算法差异必须在实飞中厘清。
> 若按 351 W，标准电池（466 Wh）**跑不完**完整剖面 → **满载 12S4P 为强制配置**。

## 5.7 冗余与失效

| 故障 | 检测 | 处置 |
|:---|:---|:---|
| 单电机/电调失效 | 电调遥测电流骤降 + 转速不一致 | **倒拖爬升段（低高度）**：立即收油中止——桨叶自动顺桨折叠，整机**头朝下**坠落，泡沫机头吸收（该姿态恰好头先着地）；**倒拖爬升段（高高度 > 60 m）**：尽快切巡航档，转入"下坠-展翼-改平"应急剖面；**平飞段**：对轴电机停机、差动配平，进入最近回收场剖面 |
| 电池单体过放 | BMS 遥测 | 立即进入"能量最优返航"（降速到最佳航程速度）；低于阈值**就近迫降** |
| 母线过流 | 分流器 | 限功率，降爬升率 |
| BEC 失效 | 电压监测 | 飞控有独立 5 V 备份（2S Li-Ion 200 mAh），保证失控后仍能记录与信标 |
| 电调过热 | 遥测温度 | 降功率告警；> 90 ℃ 进入迫降 |
