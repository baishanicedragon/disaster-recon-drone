# 08 · 自主导航与山区穿越

> 状态：**待验证**。本章是"尽可能不依赖操作员"这条硬需求的技术主体。
> 核心判断：**在吉隆沟这种深切峡谷里，实时避障做不到；真正的防线是"飞之前就想清楚"。**

---

## 8.1 问题的本质

操作员不可用的原因不是"懒得操作"，而是**物理上做不到**：

| 障碍 | 事实 |
|:---|:---|
| 链路 | 峡谷遮挡 + 基站损毁 → 无上行无下行 |
| 目视 | 出谷 1 km 即失去目视 |
| 距离 | 25 km 远超常规图传 |
| 地形 | 谷底狭窄，无法"绕一圈看看" |

所以导航必须**在起飞前就把 90 % 的决策做完**。

---

## 8.2 三层防御体系

```
        ┌─────────────────────────────────────────────────┐
        │  第 1 层：预规划（地面，起飞前）                    │
        │  DEM 地形跟随航路 + 谷底线提取 + 净空检查           │
        │  → 覆盖 ≈ 90 % 的地形风险                          │
        └─────────────────────────────────────────────────┘
                              ↓
        ┌─────────────────────────────────────────────────┐
        │  第 2 层：飞行中地形跟随 + 航位推算                 │
        │  气压高度 + DEM 比对 + EKF + GNSS（可用时）        │
        │  → 覆盖 DEM 精度内的误差、风、密度变化              │
        └─────────────────────────────────────────────────┘
                              ↓
        ┌─────────────────────────────────────────────────┐
        │  第 3 层：前向毫米波（最后一道）                    │
        │  只管 DEM 里没有的东西：新滑坡堆积体、电缆、漂浮物  │
        │  → 覆盖 ≈ 5 %，但可能是致命的 5 %                  │
        └─────────────────────────────────────────────────┘
```

> **重要认知**：**不要用第 3 层去扛第 1 层的活。**
> 28 m/s 巡航 + 120 m 探测距离 = **4.3 s 反应时间**；
> 一台 12 kg 的飞机在峡谷里从 28 m/s 转向需要 **80~120 m 半径**（3 g 限制）。
> **来不及。** 实时避障只是"运气好能救一次"，不是方案。

## 8.3 第 1 层：DEM 航路预规划

### 8.3.1 数据源

| 数据 | 分辨率 | 覆盖 | 获取 | 说明 |
|:---|---:|:---|:---|:---|
| **Copernicus DEM GLO-30** | 30 m | 全球 | 开放数据 | 基线选择，垂直精度 ~4 m ⚠ |
| **ALOS World 3D (AW3D30)** | 30 m | 全球 | 开放数据 | 与 GLO-30 交叉验证 |
| SRTM 30 m | 30 m | 全球 | 开放数据 | 山区空洞较多 |
| 国产高分/资源三号 DEM | 2~10 m | 中国 | 需申请 | **强烈建议申请**，30 m 在窄谷里不够 |

> ⚠ **30 m 分辨率的致命问题**：吉隆沟谷底宽度可能只有 100~300 m，
> 30 m 网格意味着**谷底只有 3~10 个格点**，谷底线的真实高程可能被平滑掉 **10~30 m**。
> **对策**：① 净空余量从 100 m 提到 **150 m**；② 尽量申请更高分辨率 DEM。

### 8.3.2 谷底线提取与航路生成

```
输入：DEM（GeoTIFF）+ 起飞点 P0 + 目标点 P1
输出：一串航路点（含经纬度、高程、AGL 净空、最大坡度）

算法（简化 4 步，脚本见 mission/）：
 1. 填洼（priority-flood）→ 得到水文正确的 DEM
 2. D8 流向 + 汇流累积 → 提取河谷网络
 3. 在河谷网络上找 P0 → P1 的最短路（Dijkstra，代价 = 距离 + 坡度惩罚）
 4. 沿最短路重采样（每 3~4 km 一个航路点），
    每个点的高程 = max( DEM高程 , 两侧 500 m 走廊内 DEM 最大值 ) + 净空 150 m
```

**航路点属性：**

| 字段 | 说明 |
|:---|:---|
| `lat/lon` | 经纬度 |
| `alt_amsl` | 海拔（绝对） |
| `alt_agl` | 相对地面（用于地形跟随） |
| `clearance` | 相对**走廊内最高地形**的净空（**关键**，不是相对正下方） |
| `max_turn` | 该点允许的最大转弯率（按谷宽收紧） |
| `abort` | 备降点标记（每隔 2~3 个点标一个） |

### 8.3.3 净空定义（容易搞错的地方）

```
        ⛰                                    ⛰
       ╱ ╲           clearance              ╱ ╲
      ╱   ╲          ←─────→               ╱   ╲
     ╱     ╲___________✈__________________╱     ╲
    ╱       |                             |       ╲
   ⚠ 错误：只算正下方  AGL          ✅ 正确：算走廊内最高地形

净空 = 航路点高程 − max( 走廊（左右各 500 m）内 DEM 高程 ) ≥ 150 m
```

> 因为在转弯/侧风/航位误差下，飞机**不会精确走在谷底线上**。
> 按走廊最大值算，是唯一保守的做法。

### 8.3.4 预规划检查清单

| # | 检查 | 判据 |
|:--|:---|:---|
| M-01 | 全程最小净空 | ≥ 150 m |
| M-02 | 航路点间坡度 | ≤ 8°（爬升段另行核算能量） |
| M-03 | 转弯半径 vs 谷宽 | 每点的 3 g 转弯半径 ≤ 谷宽的 1/3 |
| M-04 | 备降点密度 | 每 8~10 km 一个可迫降场地 |
| M-05 | 与 G216 走廊的一致性 | 航路尽量贴合已知可通行走廊（便于地面取回） |
| M-06 | 人口/建筑上空飞越 | **最小化**（虽然是无人区，仍应避开） |
| M-07 | DEM 空洞 | 无；有空洞的区域净空加倍 |

## 8.4 第 2 层：飞行中导航

### 8.4.1 传感器组合

| 量 | 主源 | 备源 | 备注 |
|:---|:---|:---|:---|
| 水平位置 | GNSS（可用时） | **DEM 地形匹配 + 航位推算** | |
| 高度 | **双气压计** | GNSS 高度（峡谷内差，权重低） | 气压为主 |
| 航向 | **GNSS COG** | 磁罗盘（**峡谷内不可信**） | |
| 姿态 | 双 IMU（不同型号） | — | EKF3 |
| 空速 | 差压空速计 | 地速 − 风速估计 | 失速保护 |
| 地面高度 | DEM 推算 AGL | 激光/雷达测高（末端） | |

### 8.4.2 GNSS 失效后的航位推算

**目标：GNSS 中断 120 s，位置误差 < 60 m。**

```
误差来源分析（120 s）：

① IMU 加速度计零偏 b_a：
   Δp = ½ · b_a · t² = ½ × 0.002 m/s² × 14400 = 14.4 m   （消费级 MEMS，b_a ≈ 2 mg）

② 陀螺零偏 b_g（引起姿态漂移 → 加速度投影误差）：
   Δθ = b_g × t = 0.01 °/s × 120 = 1.2°  → 重力投影误差 = g × sin(1.2°) = 0.21 m/s²
   Δp = ½ × 0.21 × 14400 = 1488 m   ← ❌ 这是灾难性的

   ⚠ 但：陀螺零偏在使用中会被 EKF 在线估计并补偿。
     补偿后残差按 10 % 计：Δp ≈ 15 m

③ 风/风速变化（无空速修正时）：
   假设 5 m/s 未知风 → Δp = 5 × 120 = 600 m  ← ❌ 最大误差源
   → **必须用空速计 + 地速做风估计**，残差按 1 m/s → Δp = 120 m  ⚠ 仍超

④ DEM 地形匹配（关键补救）：
   用气压高度 − DEM 高程 = AGL，与航路走廊比对
   在峡谷中，横向偏离 100 m 通常会导致 AGL 变化 30~100 m（坡陡）
   → 横向定位精度可达 **±30 m** ⚠
```

**结论**：

| 情形 | 120 s 后误差 | 是否满足 < 60 m |
|:---|---:|:---|
| 纯 IMU | > 1000 m | ❌ |
| IMU + 空速风估计 | ~120 m | ❌ |
| IMU + 空速 + **DEM 地形匹配** | **~40 m** ⚠ | ✅（勉强） |
| 上述 + **视觉里程计（VIO）** | ~20 m | ✅ 有余量 |

> **强烈建议增加一路视觉里程计（VIO）**：用视觉 MCU 的全局快门相机做光流/特征跟踪。
> 峡谷内纹理丰富（岩石、植被），VIO 条件其实很好。
> 这是"GNSS 中断 < 60 m"指标能否稳定达成的**关键使能**。
> 开源方案：`openMVG` / `VINS-Fusion` / `ORB-SLAM3`（需算力，可用 Linux 小板跑）。

### 8.4.3 地形跟随实现

```
ArduPilot 原生支持：
  TERRAIN_ENABLE = 1
  地形文件（.terrain）从 terrain.ardupilot.org 下载，
  或从本地 DEM 用 MAVProxy / Mission Planner 生成，放到飞控 SD 卡

  航路点使用 "Relative to Terrain" 高度框架
  → 飞控在飞行中按当前位置的 DEM 高程实时调整目标海拔
```

> ⚠ **注意**：ArduPilot 的地形跟随是**逐点插值**的，
> 在 30 m DEM 上，谷底的细微起伏会被平滑 → **净空必须留足 150 m**。

## 8.5 第 3 层：前向避障

| 选项 | 量程 | 质量 | 适用性 |
|:---|---:|---:|:---|
| 77 GHz 毫米波（AWR1843 级） | 150~200 m | ~150 g | ✅ 优选（穿透雨雾、不受光照影响） |
| Livox Mid-360 | 40~70 m | 265 g | 用于低速/起降段 |
| LD19/LD06 类 360° 激光 | 12 m | 50 g | ❌ 量程不足（0.43 s 反应） |
| 双目视觉 | 30~60 m | 100 g | 依赖纹理与光照，峡谷阴影区失效 |
| 单目 + 深度学习 | 有限 | 已有 | 只能做粗分类 |

**结论**：前向 **77 GHz 毫米波**，量程 ≥ 120 m，FOV ±30°。

**处置逻辑（保守）：**

| 探测 | 处置 |
|:---|:---|
| 120~60 m 有回波 | 记录，不动作（可能是谷壁） |
| 60~30 m 有回波且**不在 DEM 预测的谷壁位置** | 爬升 30 m + 减速到 22 m/s |
| < 30 m 有回波且非预测地形 | **立即执行"沿谷退出"**：减速 + 最大爬升率 + 触发返航 |
| 反应时间不足（< 4 s） | **宣告失败**——这说明第 1 层没做好 |

> **再次强调**：这一层成功率不高。**不要让它成为方案的支柱。**

## 8.6 任务状态机（自主决策）

```
    ┌────────┐
    │  PRE   │  地面自检（传感器、舵面、电池、吸能段、数据舱）+ 倒拖竖立
    └───┬────┘
        │ 全部通过？── 否 ──→ ABORT
        ▼
    ┌────────┐
    │ VTOLUP │  倒拖垂直起飞：机头朝下、4 桨对转、爬升至 150 m
    └───┬────┘
        │ 高度 150 m 且爬升率 < 0.5 m/s？── 否 ──→（爬升超时）V_NOSE
        ▼
    ┌────────┐
    │ CUTOFF │  关机 → 桨叶顺桨折叠 → 减速至 0 → 头朝下俯冲
    └───┬────┘
        │ 空速 ≥ 1.1 Vs 且高度 ≥ 90 m？── 否 ──→ V_NOSE（机头迫降）
        ▼
    ┌────────┐
    │  DEPLY │  展开机翼 + 双锁确认（硬件互锁 + 微动开关）
    └───┬────┘
        │ 锁定确认？── 否 ──→ V_NOSE
        ▼
    ┌────────┐
    │  FLARE │  2.0 g 拉平（限 2.5 g）→ 棘轮切巡航档 → 重启推进
    └───┬────┘
        │ 俯仰 < 15° 且空速 > 1.15 Vs？── 否 ──→ V_NOSE
        ▼
    ┌────────┐
    │ TRANS  │  转入常规平飞（ArduPilot 接管）
    └───┬────┘
        │ 空速 ≥ 22 m/s 且姿态稳定？── 否 ──→ V_NOSE
        ▼
    ┌────────┐
    │ CRUISE │  地形跟随巡航（第 1+2 层）
    └───┬────┘
        │ ├ 净空 < 100 m ──→ 爬升 + 告警
        │ ├ GNSS 丢失 > 180 s ──→ 返航
        │ ├ 剩余能量 < 返航所需 × 1.2 ──→ **立即返航**（不可协商）
        │ ├ 雷达告警 ──→ 爬升 + 减速 + 评估
        │ └ 到达目标区 ──→ LOITER
        ▼
    ┌────────┐
    │ LOITER │  盘旋拍摄（相机触发 + YOLO 打点）
    └───┬────┘
        │ ├ 完成预设圈数/时长 ──→ RETURN
        │ ├ 剩余能量阈值 ──→ 提前 RETURN
        │ └ 气象恶化（空速突变 > 8 m/s）──→ RETURN
        ▼
    ┌────────┐
    │ RETURN │  原路返航 + 爬升
    └───┬────┘
        │ ├ 到达回收场上空 ──→ APPROACH
        │ └ 能量不足 ──→ 就近备降点
        ▼
    ┌────────┐
    │APPROACH│  进近 + 十字标视觉检测
    └───┬────┘
        │ ├ 检测到 + 场地合格 ──→ LAND
        │ └ 未检测到 / 复飞 ≥ 3 次 ──→ V_NOSE
        ▼
    ┌────────┐
    │  LAND  │  拉平 → 泡沫机头触地 → 断电 → 信标
    └────────┘

    ┌────────┐
    │ V_NOSE │  备用机头迫降：放弃撑开/改平，直接机头朝下触地（EPP + 软地）
    └────────┘
    ┌────────┐
    │ ABORT  │  地面中止 / 起飞后 5 s 内中止
    └────────┘
```

### 8.6.1 能量管理（**最重要的一条自主决策**）

```
每 10 s 计算一次：

  E_return = 从当前位置返航到回收场所需能量（按 DEM 剖面 + 逆风余量 × 1.15）

  if E_remaining < E_return × 1.2 :
       立即转入 RETURN，取消剩余盘旋任务
       （不可协商——宁可少拍 3 分钟，不能掉在峡谷里）

  if E_remaining < E_return × 1.05 :
       转入 RETURN 且**就近备降**（不再回主回收场）
```

> **这条规则高于一切任务目标。** 一台掉在峡谷里的无人机，数据也拿不回来。

## 8.7 峡谷内的特殊风险

| 风险 | 说明 | 对策 |
|:---|:---|:---|
| **谷风（日变化）** | 印度洋暖湿气流沿沟北上，午后谷风可 > 10 m/s，且**上谷风/下谷风在一天内换向** | 任务尽量安排在**上午**（风小）；返航按**逆风**预算能量 |
| **下坡风/涡旋** | 谷底起伏、支沟汇入处产生涡旋 | 航路点避开支沟汇入口；空速突变 > 8 m/s 触发爬升 |
| **云雾/低云** | 暖湿气流遇冷成雾，能见度骤降 | 视觉失效 → 依赖气压 + IMU；**云中禁止进近** |
| **GNSS 多路径** | 谷壁反射 | 加装**地平面（ground plane）**；天线朝天且远离碳纤（碳纤遮挡） |
| **磁异常** | 构造带岩性不均 | **磁罗盘降级**，用 GNSS COG |
| **低温 + 高湿结冰** | 2000~2800 m + 云雾 | **无防冰能力 → 云中飞行时间 < 2 min**；任务规划避开云层高度 |
| **落石/新滑坡** | DEM 里没有 | 第 3 层雷达；且**飞行高度不贴谷底**（净空 150 m 已提供余量） |
| **鸟类** | 峡谷猛禽 | 无有效对策，接受风险 |

## 8.8 不做什么（明确排除）

| 不做 | 理由 |
|:---|:---|
| 实时图传 + 地面站操纵 | 链路不存在 |
| 依赖 4G/5G | 基站损毁 |
| 依赖磁罗盘做主航向 | 峡谷磁异常 |
| 依赖实时避障穿越未知峡谷 | 反应时间不足（4.3 s vs 需要 8+ s） |
| 夜间/云中飞行 | 无防冰、无夜视 |
| 集群/编队 | 复杂度超出本项目 |
