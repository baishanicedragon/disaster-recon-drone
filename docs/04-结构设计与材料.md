# 04 · 结构设计与材料

> 状态：**待验证**。强度计算为简化梁/柱模型，未做有限元，未做静力破坏试验。

---

## 4.1 设计哲学：**让耗材变形，让贵重件躲开**

v0.1 的思路是"把机头和前部加固，硬扛撞击"。
**v0.2 反过来**：

> **加固去硬扛 = 把撞击能量原封不动传给内部的芯片。**
> 正确做法是 **① 把贵重件挪到不变形的地方，② 让便宜的东西替它变形，③ 再找一段免费的行程。**

落实到本设计：

| 原则 | 具体做法 |
|:---|:---|
| **分区** | 全长分 A~G 七区，**撞击端（A 区）是空的**（只有泡沫） |
| **挪开** | 数据舱（相机 + 存储 + 视觉 MCU）在 **STA 860~1080（中后段）**，距撞击端 ≥ 860 mm |
| **耗材** | A 区机头为**可更换 EPP 吸能段**，1 次飞行 1 件 |
| **免费行程** | 靠**软地犁入 0.5 m** 提供约 900 J 吸收——这是"软地"真正的价值（详见 [06 章](./06-末端迫降与泡沫机头吸能.md)） |
| **牺牲结构** | 主杆 STA 400~520 设**可控屈曲诱导槽**，极端撞击时前段先屈曲，保护后段与数据舱 |
| **保护镜头** | 下视相机两侧各一条 **EPP 腹滑橇**，比镜头突出 **25 mm** |

## 4.2 主承力结构

### 4.2.1 主承力杆

| 项目 | 参数 |
|:---|:---|
| 规格 | 碳纤缠绕管 **⌀55 × 2.5 mm**，T700 级，0°/±45° 铺层 |
| 长度 | STA 400 ~ 1400（1000 mm） |
| 估算质量 | 0.62 kg |
| 破坏弯矩（估） | ≥ 900 N·m ⚠ |
| 设计载荷 | **40 g 横向 + 25 g 轴向**（迫降工况），**+6/−3 g**（飞行工况） |

**迫降工况校核（简化：悬臂梁，撞击力作用于 STA 200 机头）**

```
迫降峰值力 F ≈ 3.0 kN（见 06 章，软地 + 泡沫共同限定的峰值）
力臂（STA 400 隔框到 STA 200）= 0.20 m
M = 3000 × 0.20 = 600 N·m < 900 N·m  ✅ 余量 1.5×
```

> ⚠ 这个余量**偏薄**。原因是机头吸能段把力往后传了 200 mm 才到主杆。
> **改进**：A 区与 B 区之间加一段**铝蜂窝/碳纤锥形过渡筒**（STA 380~520），
> 既是承力过渡，又是**二级吸能**（屈曲吸能 ≈ 300 J）。**强烈建议实施**。

### 4.2.2 承力隔框（4 道）

| 隔框 | 位置 | 材料 | 作用 |
|:---|---:|:---|:---|
| FR-1 | STA 400 | 3 mm 玻纤板 + 铝嵌件 | 吸能段接口（4 × M4 卡扣座） |
| FR-2 | STA 520 | 3 mm 碳纤板 | 主杆前接头、前设备舱后壁、二级吸能筒起点 |
| FR-3 | STA 900 | 4 mm 碳纤板 + 铝件 | **主翼接头（主承力）**、数据舱后壁 |
| FR-4 | STA 1250 | 4 mm 碳纤板 + 铝件 | 主杆后接头、4 × 电机座、尾翼座 |

> **FR-3 是全机最关键的一个件**：盘旋时 1.06 g、机动时可能到 3 g，
> 机翼升力全部通过它传进机身。**必须用金属接头 + 碳纤板复合，不能纯 3D 打印。**

### 4.2.3 蒙皮

| 段 | 材料 | 厚度 | 说明 |
|:---|:---|:---|:---|
| A 区 | EPP（三层变密度） | — | 吸能，无蒙皮 |
| B/C 段 | 3K 碳纤管（直接作为承力外壳） | 1.0 mm | 或直接外购 ⌀140 碳纤管 |
| D/E 段 | 3D 打印 PETG/PA-CF 舱盖 | 2.0 mm | 非承力，只做整流与防雨 |
| F/G 段 | 3D 打印 PA-CF | 2.5 mm | 电机座受振动，用 PA-CF |

## 4.3 主翼与折叠机构

### 4.3.1 机翼结构

| 项目 | 做法 |
|:---|:---|
| 主梁 | 碳纤管 ⌀16 × 1.5 mm（贯穿全展），或碳纤 D-box |
| 翼肋 | 3D 打印 PA-CF / 激光切割 2 mm 轻木，间距 90 mm |
| 蒙皮 | 0.4 mm 玻纤板 或 热缩膜 + 翼肋（低速够用） |
| 舵面 | **全展长升降副翼（elevon）**，弦向 25 %，左右独立 |
| 翼尖 | **EPP 滑块**（长 300 mm，厚 25 mm），迫降磨损件，可更换 |
| 展开驱动 | **扭簧被动展开 + 舵机机械锁**（无动力也能展开，失效安全） |
| 折叠状态 | 两片翼沿机身轴向后折，锁定于机身两侧，展向包络 ≤ 0.35 m |
| 质量（含机构） | 1.30 kg ⚠ |

### 4.3.2 折叠机构要点

```
        展开状态（俯视）              折叠状态（俯视）
      ╔═══════╗                     ╔═══╗
   ═══╣  FUSE ╠═══               ╔══╣FUSE╠══╗
      ╚═══════╝                  ║  ╚═══╝  ║
    ←─ 2.00 m ─→                 ║ ════╗   ║
                                 ╚═════╝   ║
                                  ← 0.35 m →
   转轴：位于 STA 900 上表面，轴向与机身轴平行
   折叠角：0°（展开） → 92°（向后收拢，贴机身）
   锁定：展开到位后，舵机驱动的锥形销插入 FR-3 锁孔 + 扭簧保持
```

**关键要求：**

1. **硬件互锁**：`自旋速率 < 0.2 Hz` 信号为高时，才允许解锁展开（[11 章](./11-施工顺序与装配工艺.md) Gate-9）；
2. **双微动开关**确认两侧均锁定 → 任一未确认，飞控**中止过渡**，进入垂直迫降备用剖面；
3. **锁销抗剪**：按 3 g × 半翼升力（≈ 190 N）+ 2.5 倍安全系数 → **≥ 480 N 剪切**，材料用钢销 ⌀5 mm；
4. 折叠机构**不得削弱主梁**：转轴座直接抱夹在主梁根部，不打断纤维。

## 4.4 A 区：吸能机头（耗材）

详见 [06 章](./06-末端迫降与泡沫机头吸能.md)。结构要点：

| 项目 | 参数 |
|:---|:---|
| 外形 | 尖拱（tangent ogive），长径比 3:1，根部 ⌀240 mm，长 400 mm |
| 材料 | **三层变密度 EPP**：25 / 45 / 70 kg/m³，各约 130 mm，从前到后密度递增 |
| 内部 | **空腔**（不装任何设备）——这是与 v0.1 的关键区别 |
| 接口 | 4 × 快拆卡扣（尼龙 + 钢销），2 人 **3 min** 更换 |
| 质量 | 0.45 kg |
| 单次成本 | ≈ 30~60 元（EPP 数控切割/热丝切割） |
| 库存建议 | 每次任务带 **3 件** |

## 4.5 D 区：快拆数据舱

| 项目 | 参数 |
|:---|:---|
| 位置 | STA 860 ~ 1080 |
| 内含 | 12 MP 相机（下视）+ 6 mm 镜头、视觉 MCU（STM32N6）、microSD ×1（镜像备份可选 ×2）、IMU、小容量后备锂电（保证断电后完成写入） |
| 舱体 | 3D 打印 PA-CF，壁厚 2.5 mm，内部 3 mm EVA 缓冲 |
| 固定 | 2 × 快拆卡扣 + 1 × 防脱销，**无工具 10 s 取出** |
| 密封 | 硅胶条 + 防水透气阀（高原昼夜温差 + 雨雾） |
| 相机窗 | 光学玻璃 / PC 平板，**凹入 6 mm**，两侧由腹滑橇保护 |
| 质量 | 0.62 kg |

**为什么必须放中后段而不是机头？**

```
机头（STA 200）：迫降时承受全部撞击，过载 25~50 g + 直接挤压 → 芯片/镜头/接插件必损
中后段（STA 970）：距撞击端 970 mm，中间隔着 400 mm 泡沫 + 520 mm 电池 + 主杆
                   → 载荷经泡沫压溃与结构变形后大幅衰减，实测目标 ≤ 25 g
```

## 4.6 腹滑橇与翼尖保护

| 部件 | 参数 | 作用 |
|:---|:---|:---|
| 腹滑橇 ×2 | EPP 45 kg/m³，长 500 mm，截面 60 × 120 mm，位于 STA 700~1200 机身腹部两侧 | 迫降时机腹着地，承担滑行与二级吸能；**比相机镜头突出 25 mm** |

| 尾坐起落架 | 4 条可折叠碳纤支腿，展开半径 0.55 m，末端 EPP 脚垫 | 起飞支撑；**迫降时保持收起** |

## 4.7 材料清单（结构部分）

| 材料 | 用途 | 关键特性 | 注意 |
|:---|:---|:---|:---|
| 碳纤缠绕管 ⌀55×2.5 | 主承力杆 | 高比强度、抗弯 | **导电**，远离天线；切割戴口罩 |
| 碳纤板 3~4 mm | 隔框 | 高刚度 | 开孔处需封边防分层 |
| 玻纤板 0.4~3 mm | 蒙皮、过渡筒 | 透波（天线罩区）、绝缘 | 刚度低于碳纤 |
| EPP 25/45/70 kg/m³ | 吸能机头、滑橇、翼尖 | **可回复形变**（多次小冲击）、压溃吸能 | 不可用 EPS 替代（EPS 脆性、吸能差） |
| 铝蜂窝（⌀6 mm，5052） | 二级吸能筒 | 高比吸能、稳定压溃 | 需防潮密封 |
| PA-CF 3D 打印 | 舱盖、电机座、接头 | 高强耐热、可打印复杂件 | 吸湿，打印后烘干 |
| EVA 3 mm | 舱内缓冲 | 廉价、减振 | — |
| 钢销 ⌀5（SUS304） | 锁销 | 抗剪 ≥ 480 N | 涂防松胶 |

## 4.8 防断裂专项（本设计最怕的失效）

| 失效点 | 原因 | 对策 |
|:---|:---|:---|
| **机翼锁销剪断** | 盘旋载荷 + 迫降擦地 | 钢销 ⌀5、双锁点、2.5 倍安全系数、翼尖 EPP 滑块先接触 |
| **主杆在 FR-2 处折断** | 迫降弯矩集中 | 二级吸能筒分担；STA 400~520 设**屈曲诱导槽**（牺牲前段） |
| **电池受挤压起火** | 电池在 STA 520~900，撞击传递路径上 | 电池舱用**铝内衬 + 3 mm EVA**；撞后**必须先测电压/内阻再充电** |
| **数据舱卡扣脱开** | 迫降过载 | 卡扣 + **防脱销**双保险；舱外再加 1 条 3M 应力带 |
| **相机镜头碎** | 机腹触地 | 腹滑橇高出镜头 25 mm；窗口凹入 6 mm；加一次性透明保护膜 |
| **折叠机构疲劳** | 反复展开 | 转轴用**钢套 + 铜衬套**；每 10 次展开检查间隙 |
| **蒙皮分层** | 高原紫外 + 温差 | 外表面喷聚氨酯清漆防紫外；切边全封 |
| **电机座共振断裂** | 振动 + 悬臂 | PA-CF + 4 mm 铝背板；电机座与 FR-4 一体成型 |
