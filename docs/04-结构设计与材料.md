# 04 · 结构设计与材料

> 状态：**待验证**。强度计算为简化梁/柱模型，未做有限元，未做静力破坏试验。

## 4.1 设计哲学：**让耗材变形，让贵重件躲开**

v0.1 的思路是"把机头和前部加固，硬扛撞击"。
**v0.2 反过来**：

> **加固去硬扛 = 把撞击能量原封不动传给内部的芯片。**
> 正确做法是 **① 把贵重件挪到不变形的地方，② 让便宜的东西替它变形，③ 再找一段免费的行程。**

落实到本设计：

| 原则 | 具体做法 |
|:---|:---|
| **分区** | 全长分 A~G 七区，**撞击端（A 区）是空的**（只有泡沫） |
| **挪开** | 数据舱（相机 + 存储 + 视觉 MCU）在 **STA 860~1080（中后段）**，距撞击端 ≥ 860 mm |
| **耗材** | A 区机头为**可更换 EPP 吸能段**，1 次飞行 1 件 |
| **免费行程** | 靠**软地犁入 0.5 m** 提供约 900 J 吸收——这是"软地"真正的价值（详见 [06 章](./06-末端迫降与泡沫机头吸能.md)） |
| **牺牲结构** | 主杆 STA 400~520 设**可控屈曲诱导槽**，极端撞击时前段先屈曲，保护后段与数据舱 |
| **保护镜头** | v0.4：相机窗凹入 6 mm + **可更换 PC 保护片**（腹滑橇已删） |

## 4.2 主承力结构

### 4.2.1 主承力杆

| 项目 | 参数 |
|:---|:---|
| 规格 | 碳纤缠绕管 **⌀55 × 2.5 mm**，T700 级，0°/±45° 铺层 |
| 长度 | STA 400 ~ 1400（1000 mm） |
| 估算质量 | 0.62 kg |
| 破坏弯矩（估） | ≥ 900 N·m ⚠ |
| 设计载荷 | **40 g 横向 + 25 g 轴向**（迫降工况），**+6/−3 g**（飞行工况） |

**迫降工况校核（简化：悬臂梁，撞击力作用于 STA 200 机头）**

```
迫降峰值力 F ≈ 3.0 kN（见 06 章，软地 + 泡沫共同限定的峰值）
力臂（STA 400 隔框到 STA 200）= 0.20 m
M = 3000 × 0.20 = 600 N·m < 900 N·m  ✅ 余量 1.5×
```

> ⚠ 这个余量**偏薄**。原因是机头吸能段把力往后传了 200 mm 才到主杆。
> **改进**：A 区与 B 区之间加一段**铝蜂窝/碳纤锥形过渡筒**（STA 380~520），
> 既是承力过渡，又是**二级吸能**（屈曲吸能 ≈ 300 J）。**强烈建议实施**。

### 4.2.2 承力隔框（4 道）

| 隔框 | 位置 | 材料 | 作用 |
|:---|---:|:---|:---|
| FR-1 | STA 400 | 3 mm 玻纤板 + 铝嵌件 | 吸能段接口（4 × M4 卡扣座） |
| FR-2 | STA 520 | 3 mm 碳纤板 | 主杆前接头、前设备舱后壁、二级吸能筒起点 |
| FR-3 | STA 895 | 4 mm 碳纤板 + 铝件 | **双翼合接头（主承力，上下翼盒塔共用）**、数据舱后壁 |
| FR-4 | STA 1250 | 4 mm 碳纤板 + 铝件 | 主杆后接头、4 × 电机座、尾翼座 |

> **FR-3 是全机最关键的一个件**：盘旋时 1.06 g、机动时可能到 3 g，
> 机翼升力全部通过它传进机身。**必须用金属接头 + 碳纤板复合，不能纯 3D 打印。**

### 4.2.3 蒙皮

| 段 | 材料 | 厚度 | 说明 |
|:---|:---|:---|:---|
| A 区 | EPP（三层变密度） | — | 吸能，无蒙皮 |
| B/C 段 | 3K 碳纤管（直接作为承力外壳） | 1.0 mm | 或直接外购 ⌀140 碳纤管 |
| D/E 段 | 3D 打印 PETG/PA-CF 舱盖 | 2.0 mm | 非承力，只做整流与防雨 |
| F/G 段 | 3D 打印 PA-CF | 2.5 mm | 电机座受振动，用 PA-CF |

## 4.3 双翼与钻石背收拢机构（v0.4 重写）

### 4.3.1 机翼结构（上下各 2 片，共 4 片半翼）

| 项目 | 上翼 | 下翼 |
|:---|:---|:---|
| 半展 | 750 mm | 700 mm |
| 根弦 / 梢弦 | 230 / 190 mm | 240 / 200 mm |
| 站位（LE~TE） | STA **818 ~ 1048** | STA **860 ~ 1100** |
| 安装 | 背脊塔 y **+175 mm**（塔 X 818~1030，z ±40） | 机腹塔 y **−175 mm**（塔 X 860~1100，z ±40） |
| 主梁 | 碳纤管 ⌀14 × 1.5 mm（贯穿半展） | 同 |
| 翼肋 | 3D 打印 PA-CF / 2 mm 轻木，间距 90 mm | 同 |
| 蒙皮 | 0.4 mm 玻纤板 或 热缩膜 | 同 |
| 舵面 | **无**（v0.4 取消 elevon；偏航/横滚全靠 4 桨差动） | 无 |
| 翼尖 | EPP 滑块（长 250 mm，厚 20 mm），迫降磨损件 | 同 |
| 质量（含收拢铰） | 0.75 kg | 0.75 kg |

> **为什么取消副翼/升降副翼**：机翼要能"收拢挂体、随主体整桶运输"，
> 翼身接口必须**纯承力、不过任何信号线**；姿态控制交给 4 桨差动 + 平尾升降舵。
> 代价是横滚靠差动推力（响应慢），换来的是**装配 3~5 min、无工具、无插接线缆**。

### 4.3.2 钻石背两段折 + 雨伞式被动撑开

```
   展开（俯视，上翼）                     收拢（俯视，挂体随主体装箱）
 ╔═══════╗                              ╔═══════╗
 ║  FUSE ║                              ║  FUSE ║
 ╚═══╤═══╝                              ╚═══╤═══╝
 ────┴────  内段(375) ─ 外段(375)        ═══╗   ║   ← 内段后折 ~160°
   ← b 1.50 m →                            ╚═══╝   ← 外段折回（Y 向分层 +18/+36）
                                          ← 横向包络 ⌀480 mm →

 内段铰点 = 翼根【前缘】角点   外段铰点 = 内段外端【后缘】角点
 展开驱动 = 弹簧预载 + 俯冲动压触发（无舵机、无线缆）
 锁止     = 棘爪自锁，一次性不回收
```

**三段硬要求（建模实测教训，见 `_check_fold.py`）：**

1. **铰点必须在翼根前缘角点**，不能取弦中点——否则收拢后左右翼在 Z 向**完全穿透**；
2. **外段必须 Y 向分层**（右外 +18 mm、左外 +36 mm，下翼对称 −18 / −36），否则折回后跨中线相撞；
3. 收拢包络必须与桨臂保持间隙：现方案 **纵向 STA 786~1210**，距桨臂起点 1425 **留 215 mm** ✅。

**关键要求：**

1. **硬件互锁 IL-1**：`空速 ≥ 1.1 Vs（≈20.9 m/s）且高度 ≥ 90 m` 同时为高才允许解锁撑开
   （[11 章](./11-施工顺序与装配工艺.md) Gate-9）；撑开失败则放弃、机头朝下迫降；
2. **双微动开关**确认 4 片半翼均锁定 → 任一未确认，飞控**中止改平**，进入机头朝下迫降备用剖面；
3. **棘爪抗剪**：按 2.5 g × 单片半翼升力（≈ 80 N）+ 2.5 倍安全系数 → **≥ 200 N 剪切**，钢销 ⌀4 mm；
4. **收拢态锁销**：倒拖爬升（1.7 kW 级）与俯冲段必须保证不抖开——锁销 + 过中心弹簧双保险；
5. 收拢机构**不得削弱主梁**：铰座直接抱夹主梁根部，不打断纤维。

## 4.5 D 区：快拆数据舱

| 项目 | 参数 |
|:---|:---|
| 位置 | **STA 380 ~ 540**（v0.4 前移，见下） |
| 内含 | 12 MP 相机（下视）+ 6 mm 镜头、视觉 MCU（STM32N6）、microSD ×1（镜像备份可选 ×2）、IMU、小容量后备锂电（保证断电后完成写入） |
| 舱体 | 3D 打印 PA-CF，壁厚 2.5 mm，内部 3 mm EVA 缓冲 |
| 固定 | 2 × 快拆卡扣 + 1 × 防脱销，**无工具 10 s 取出** |
| 密封 | 硅胶条 + 防水透气阀（高原昼夜温差 + 雨雾） |
| 相机窗 | 光学玻璃 / PC 平板，**凹入 6 mm**；v0.4 因**删除腹滑橇**改为**可更换 PC 保护片 + 一次性透明膜** |
| 质量 | 0.62 kg |

**v0.4 为什么前移到 STA 460？**

```
下翼占据机腹 STA 860~1100 —— 相机窗口若留在 STA 860~1080 会被下翼完全遮挡。
前移到 STA 460（下翼前方、上翼 818 之前）后视场完全无障碍，
且远离桨盘（STA 1460）不受洗流与振动影响。

代价：距撞击端由 970 mm 缩到 460 mm，中间只有 300 mm 泡沫
      → 迫降过载会上升，必须靠「一次性 PC 保护片 + 3 mm EVA + 后备锂电完成写入」兜底。
      → 12 章 A4 迫降试验必须实测数据舱过载，若 > 25 g 则把 microSD 改为
        「双卡镜像 + 其中一卡后置到 STA 1000 航电舱」。
```

## 4.8 防断裂专项（本设计最怕的失效）

| 失效点 | 原因 | 对策 |
|:---|:---|:---|
| **机翼锁销剪断** | 盘旋载荷 + 迫降擦地 | 钢销 ⌀5、双锁点、2.5 倍安全系数、翼尖 EPP 滑块先接触 |
| **主杆在 FR-2 处折断** | 迫降弯矩集中 | 二级吸能筒分担；STA 400~520 设**屈曲诱导槽**（牺牲前段） |
| **电池受挤压起火** | 电池在 STA 520~900，撞击传递路径上 | 电池舱用**铝内衬 + 3 mm EVA**；撞后**必须先测电压/内阻再充电** |
| **数据舱卡扣脱开** | 迫降过载 | 卡扣 + **防脱销**双保险；舱外再加 1 条 3M 应力带 |
| **相机镜头碎** | 机腹触地（v0.4 已无腹滑橇） | 窗口凹入 6 mm；**可更换 PC 保护片**；一次性透明膜；数据舱 3 mm EVA |
| **收拢/撑开机构疲劳** | 反复收放 | 铰点用**钢套 + 铜衬套**；地面收放 10 次检查间隙；棘爪每 5 次任务更换 |
| **蒙皮分层** | 高原紫外 + 温差 | 外表面喷聚氨酯清漆防紫外；切边全封 |
| **电机座共振断裂** | 振动 + 悬臂 | PA-CF + 4 mm 铝背板；电机座与 FR-4 一体成型 |
