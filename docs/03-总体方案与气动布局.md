# 03 · 总体方案与气动布局（v0.3 倒拖构型）

> 状态：**待验证**。气动数字为简化估算（动量理论 + Barrowman + 平板摩擦），**非 CFD / 风洞结果**。
> 本章是 v0.3 收敛的**核心**：解释为什么 v0.2 的"折叠翼 + 自旋垂起段"被推翻，
> 以及"倒拖起飞 + 无动力改平"这套全新剖面怎么把"垂直起飞"和"盘旋成像"装进一台 1.55 m 长杆。

---

## 3.1 为什么 v0.2 的"自旋垂起段"被推翻

v0.2 为解决"无空速时的起飞稳定"，让长杆**折叠机翼、绕纵轴自旋**爬升到 80 m，再消旋展开。评审后发现四条硬伤：

| # | 问题 | 说明 |
|:--|:---|:---|
| **D1** | 4 桨几何不成立 | v0.2 尾部 **4 × 24" 桨 X 型环布**：24" 桨盘 0.61 m，桨间距要 ≥ 0.64 m → 尾部十字支架横向 **~1.3 m**，装在 1.55 m / 11.7 kg 长杆上荒谬（用户否决）；缩小桨径又会推高悬停功率与盘载 |
| **D2** | 电机挂载位置无解 | 若把 4 电机挂到**机翼**上（Wingtra 式尾坐四轴的真实做法），则垂起时机翼必须展开 → **"折叠 + 自旋"失去前提**；若留在机尾，又回到 D1 的支架问题 |
| **D3** | 自旋与同轴/对转冲突 | 自旋是 v0.1"单桨长杆"的遗产（用来抵消反扭矩 + 陀螺安定）。v0.2 用 4 桨相邻对转后反扭矩已自消，**自旋不再有存在的理由**，只剩"被动安定"一条用途 |
| **D4** | 用高度换过载的账反了 | 为压掉高，v0.2 设 3~4 g 拉平 → 结构被迫加重。**高度是廉价的**：150 m 爬升只多耗 ~5 Wh，却能把拉平过载降到 2.0 g |

**结论（A 级）**：**删除自旋体系。** 垂直起飞改为 **"倒拖"**：机头朝下、尾桨朝上，
桨向下排气 → 反作用力把整机**竖直拉起**（机头仍朝下）。质量悬挂在推力线下方，姿态**被动摆式稳定**，
无空速也不需要自旋或舵面。

## 3.2 v0.3 方案：倒拖起飞 + 无动力改平

```
        ┌──────────────┬──────────────┬──────────────────┬──────────┐
        │ 段 I：倒拖爬升 │ 段 II：无动力 │ 段 III：机翼巡航   │ 段 IV：   │
        │ 机翼【折叠】  │ 改平          │ 机翼【展开】      │ 迫降      │
        │ 机头朝下      │ 头朝下俯冲    │ 正常三轴稳定      │ 泡沫机头  │
        └──────────────┴──────────────┴──────────────────┴──────────┘
          0 → 150 m AGL    掉高 ≈ 84 m     全程其余           末端
          桨：爬升大距     桨停转·顺桨折叠  桨：巡航小距推进    桨停转
          姿态：被动摆式    尾翼拉平 2.0g    常规 PID          拉平 + 触地
```

**为何机头朝下、桨朝上（"倒拖"）？**

1. **起飞瞬间桨离地最远**：尾桨盘面在机体顶端（离地 ~1.6 m），避免地面效应、扬尘、杂草打桨；
2. **被动稳定**：整机像"挂在推力线下的摆"——任何倾斜，重力分量产生恢复力矩，无空速也能保持竖直；
3. **关机即俯冲**：倒拖关机后自然**头朝下**下坠（细长体 + 尾翼安定），正好进入改平剖面，无需翻转动作；
4. **机头本来就是耗材**：A 区 EPP 吸能机头同时充当倒拖起飞的**触地缓冲端**（复用，不增重）。

### 3.2.1 时序（一次完整任务）

| 时刻 | 动作 | 姿态 | 控制模式 |
|:---|:---|:---|:---|
| T+0 | 4 电机起旋（**爬升大距**，向机头排气） | 机头朝下、尾桨朝上（倒拖） | 被动摆式 + 差动推力修正 |
| T+2 s | 离地，竖直爬升 | 倒拖竖直 | 被动稳定 + 推力（对转反扭矩自消） |
| T+45 s | 到达 **150 m AGL** | 倒拖竖直 | — |
| T+45 s | **关机**，桨叶自动**顺桨折叠** | 倒拖竖直 → 减速至 0 → 反向 | 无动力 |
| T+50~55 s | **头朝下俯冲**增速至 1.25 Vs ≈ 23.4 m/s | 机头朝下 | 尾翼安定 + 阻尼 |
| T+55 s | 动压足够 → **展开机翼并锁定**（弹簧 + 机械锁） | 俯冲中 | 硬件互锁（动压 > 阈值） |
| T+55~60 s | **2.0 g 拉平 90°** | 俯冲 → 水平 | 尾翼拉平，掉高 ≈ 56 m |
| T+60 s | 进入滑翔（净高 ≈ 64 m），棘轮切**巡航小距** | 水平 | 常规固定翼 |
| T+60~130 s | 爬升至巡航高度 | 水平 | 常规固定翼 |
| T+130 s | 进入地形跟随巡航 | 水平 | 常规固定翼 |
| … | 盘旋拍摄 / 返航 | 水平 | 常规固定翼 |
| 末端 | **末端迫降剖面**（见 [06 章](./06-末端迫降与泡沫机头吸能.md)） | 水平，低姿态 | 拉平 + 减速 + 机头触地 |

> **为什么 150 m 才关机？** 这不是"飞得高"，是给无动力改平买高度：
> 增速掉高 ~28 m + 2.0 g 拉平掉高 ~56 m ≈ **84 m 总掉高**，150 m 关机后仍剩 ~64 m 净高
> 用于展翼、建滑翔、对抗高原谷风。**过载因此只需 2.0 g**（v0.2 需 3~4 g）。
> 代价：多爬 70 m ≈ **+5 Wh**（满载 778 Wh 的 0.7 %）。

## 3.3 构型选择（横向对比，v0.3 口径）

| 构型 | 垂起 | 尾桨 | 可盘旋 | 无跑道 | 复杂度 | 结论 |
|:---|:---|:---|:---|:---|:---|:---|
| **A. 长杆倒拖 + 无动力改平（v0.3）** | ✅（被动稳定） | ✅ | ✅ | ✅ | 中 | **选它** |
| B. 尾坐 + 自旋垂起（v0.2） | ✅ | ✅ | ✅ | ✅ | 中高 | **排除（D1~D4）** |
| C. 翼挂 4 桨尾坐（Wingtra 式） | ✅ | ❌（挂翼） | ✅ | ✅ | 高（机翼需展开悬停） | 排除（D2：与折叠翼/被动稳定目标冲突） |
| D. 倾转旋翼 | ✅ | ⚠️ | ✅ | ✅ | 很高 | 排除 |
| E. 纯自旋长杆（v0.1） | ✅ | ✅ | **❌** | ✅ | 低 | 排除 |
| F. 多旋翼 + 高速巡航 | ✅ | ❌ | ✅ | ✅ | 中 | 速度/航程不足 |
| G. 伞降/火箭助推 | — | — | — | — | — | 火工品，红线排除 |

**结论：A。**

## 3.4 主翼设计

### 3.4.1 参数

| 参数 | 符号 | 数值 |
|:---|:---|:---:|
| 展长 | b | 2.00 m |
| 面积 | S | 0.63 m² |
| 展弦比 | AR | **6.35** |
| 平均气动弦 | MAC | 0.315 m |
| 根梢比 | λ | 0.6（根弦 0.39 m / 梢弦 0.23 m） |
| 安装位置 | — | **上单翼**（安装线高于机身轴 60 mm） |
| 前缘位置 | — | STA 821（AC 在 STA 900） |
| 上反角 | Γ | 3° |
| 翼型 | — | 半对称，t/c = 9~10 % |
| 翼载 | W/S | **199 N/m²（20.3 kg/m²）** ⚠ |

> **为什么上单翼？** 迫降时翼尖离地高度 = 机身半径 + 上单翼抬升 60 mm + 腹滑橇 120 mm ≈ **180 mm**。
> 下单翼会让翼尖先触地、造成机体翻滚。见 [06 章](./06-末端迫降与泡沫机头吸能.md)。
> **折叠**：运输/储备时沿机身收折（展向 ~0.35 m + 尾桨环后包络 ⌀0.63 m）；
> 任务中于**下坠段**展开（动压足够才解锁，见 [08 章](./08-自主导航与山区穿越.md)）。

### 3.4.2 失速速度

```
V_s = √( 2W / (ρ · S · Cl_max) )

@ 2750 m, ρ = 0.933 kg/m³, W = 123 N, Cl_max = 1.15
V_s = √( 246 / (0.933 × 0.63 × 1.15) ) = √(246 / 0.676) = 18.7 m/s  (67 km/h)

@ 1800 m, ρ = 1.024
V_s = 17.8 m/s  (64 km/h)
```

⚠ **18.7 m/s 的失速速度偏高**，这是"高速长杆"必然的代价。
它直接决定了**改平触发速度（1.25 Vs = 23.4 m/s）**与末端迫降的能量水平——见 06 章（本设计最危险的一环）。

### 3.4.3 阻力与巡航功率

```
CD0  = 0.028      （机身摩擦 + 机翼型阻 + 尾翼 + 干扰，基于 S = 0.63 m²）
e    = 0.85
k    = 1/(π·AR·e) = 1/(π × 6.35 × 0.85) = 0.0589

巡航 V = 28 m/s，ρ ≈ 0.98（平均 2200 m）：
Cl = 2W/(ρ V² S) = 246 / (0.98 × 784 × 0.63) = 0.488
CD = 0.028 + 0.0589 × 0.488² = 0.028 + 0.0140 = 0.0420
L/D = 0.488 / 0.0420 = 11.6
D   = 123 / 11.6 = 10.6 N
P_推力 = 10.6 × 28 = 297 W
```

**v0.3 的推进效率改进**：4 × 13" 桨在巡航段**切到巡航小距**（棘轮单向两档的第二档），
前进比不再像 v0.2（24" 大桨低前进比）那样严重偏离设计点。取 η_p = 0.66（仍保守）：

```
P_轴   = 297 / 0.66 = 450 W
P_电   = 450 / 0.85（电机×电调）= 529 W
P_总   = 529 + 60（航电/载荷）≈ 590 W
```

> **已知代价**：13" 桨对 28 m/s 巡航仍偏大，效率 penalty 约 10~20 %。
> **缓解手段**（按优先级）：
> 1. 巡航时**对角 2 桨停转并顺桨折叠**，只用 2 桨推进 → 省 8~12 %（仍需实测对称性）；
> 2. 巡航小距档进一步减小桨距角（已内置）；
> 3. 接受，把多出的功率算进电池（本设计先采用，实测航程不足再上 1）。

### 3.4.4 盘旋（侦察）状态

```
V = 23 m/s（1.23 Vs，留足裕度）
坡度 φ：R = V² / (g · tanφ) = 150 m
→ tanφ = 529 / (9.81 × 150) = 0.359 → φ = 19.7°
→ 载荷因数 n = 1/cosφ = 1.064

ρ = 1.024（目标区 2050 m AMSL）
Cl = n·2W / (ρ V² S) = 1.064 × 246 / (1.024 × 529 × 0.63) = 0.736
CD = 0.028 + 0.0589 × 0.736² = 0.028 + 0.0319 = 0.0599
L/D_turn = 0.736 / 0.0599 = 12.3
D = n·W / (L/D) = 131 / 12.3 = 10.6 N
P_推力 = 10.6 × 23 = 244 W
P_电   = 244/0.65/0.85 + 60 = 502 W  →  取 485 W（下坡/风场补偿后）
```

**盘旋一圈 = 2πR/V = 41 s。** 盘旋 10 min ≈ **14.6 圈**，足够做多次重叠覆盖。

> **盘旋比巡航更省电**（速度更低），代价主要在爬升与垂起——v0.3 同 v0.2。

### 3.5.2 配平（平飞状态）

```
中性点 X_np = X_AC_wing + V_h × (a_t/a_w) × (1 − dε/dα) × MAC

尾容量 V_h = (S_t × l_t) / (S × MAC)
           = (0.057 × 0.54) / (0.63 × 0.315) = 0.0308 / 0.198 = 0.155

X_np ≈ 900 + 0.155 × 0.7 × 0.7 × 315 = 900 + 24 = 924 mm
```

| 电池位置 | CG | 静稳定裕度 SM = (X_np − X_CG)/MAC | 判定 |
|---:|---:|---:|:---|
| STA 760 | 918 mm | +1.9 % | ⚠ 偏中性，仅适合放宽静稳定 + 高增益增稳 |
| **STA 600** | **885 mm** | **+12.4 %** | ✅ 推荐（初飞保守） |
| STA 520 | 862 mm | +19.1 % | ⚠ 过稳，配平阻力上升、操纵迟钝 |

> **设计决策**：电池舱做成 **STA 520~760 无级可调**（滑轨 + 压紧块），
> **初飞用 STA 600（SM +12 %）**，完成 AutoTune 与包线扩展后逐步后移到 STA 700~730 减阻。
> 注意：倒拖爬升段要求 **CG 尽量接近推力线**，避免侧向偏移 > 3 mm 引起斜爬（见 3.5.3）。

### 3.5.3 倒拖（竖直）状态的稳定

竖直爬升时**被动摆式稳定**（不需要自旋），但仍有三条硬要求：

- **横向 CG 偏移 < 3 mm**：偏移会造成倒拖爬升中的侧向漂移（摆长 1.5 m、无阻尼时对初始偏航敏感）；
- **4 电机合推力线过 CG 纵轴**：相邻反向对转已抵消反扭矩，剩姿态由差动推力微调；
- **起飞阵风限制 6 m/s**：倒拖段无空速，侧风会吹斜摆线 → 靠"摆的恢复 + 差动推力"对抗，超限不起飞。

**倒拖摆的固有频率**：摆长 ≈ CG 到桨盘距离 ≈ 1.0 m → f ≈ (1/2π)√(g/l) ≈ **0.5 Hz**，
属于飞控带宽可覆盖的慢摆；起飞瞬间（桨刚出力）由差动推力阻尼。

## 3.6 无动力改平段设计（段 II，v0.3 核心新段）

### 3.6.1 物理预算

```
关机高度 150 m → 速度归零（惯性上飘 ~2 m）→ 头朝下俯冲

增速到 1.25 Vs = 23.4 m/s：掉高 ≈ V²/2g = 28 m
2.0 g 拉平 90°：半径 R = V²/(g·(n−1)) = 529/(9.81×1.0) = 54 m → 掉高 ≈ 54 m
总掉高 ≈ 84 m → 改平完成净高 ≈ 64 m ✅
```

| 拉平过载 | 增速 + 拉平总掉高 | 150 m 关机后净高 | 结论 |
|---:|---:|---:|:---|
| 1.5 g | ~139 m | ~11 m ⚠ | 高度成本反而更高，排除 |
| **2.0 g** | **~84 m** | **~64 m** | ✅ **采用**（结构按 2.5 g 裕量） |
| 3.0 g | ~56 m | ~94 m | 可行但结构代价大 |

### 3.6.2 时序与安全

1. **关机**：电机停转 → 桨叶在气动阻力下**顺桨折叠**（消除风车阻力与盘面阻力）；
2. **俯冲**：头朝下、尾翼安定（箭式），飞控只做阻尼，不急于改出；
3. **展翼门控**：空速 ≥ **1.1 Vs ≈ 20.6 m/s** 且高度 ≥ 90 m 才允许解锁展开
   （动压不足展开会不到位；高度不足则放弃展翼，直接机头迫降）——硬件互锁信号，见 [11 章](./11-施工顺序与装配工艺.md) Gate-9；
4. **2.0 g 拉平**：尾翼拉起，俯冲 → 水平，掉高约 54 m；
5. **棘轮切巡航档**：拉平后、重启电机前，单向棘轮把桨距从爬升大距切到巡航小距
   （一次性，不回爬升档）；
6. **重启推进**：离心力甩开折叠桨叶 → 平飞巡航。

> **失效分支**：
> - 展翼失败（动压不足 / 机构卡死）→ 放弃改平，**机头朝下迫降**（EPP 吸能 + 软地，见 06 章）；
> - 拉平后净高不足 → 直接进入滑翔并就近选场，不强行爬升。

## 3.7 过渡段风险（倒拖 → 巡航）

| 风险 | 表现 | 对策 |
|:---|:---|:---|
| 关机后姿态发散 | 俯冲中偏航/横滚 | ① 尾翼安定 + 阻尼；② 细长体尾翼面积按 Barrowman 复核（12 章 T-06）；③ 俯冲段禁止大侧滑 |
| 展翼过早/过晚 | 展开不到位 / 动压不足 | **动压 + 高度双门控**硬件互锁 |
| 拉平过载超限 | 结构损伤 | 2.0 g 目标，飞控限制最大 2.5 g（超过自动缓拉） |
| 侧风吹偏 | 下坠段漂移出走廊 | 顺风/逆风均可改平，**忌大侧风起飞**（> 6 m/s 不起飞） |
| 棘轮未切巡航档就重启 | 大桨距在巡航转速 → 电机过载 | 重启电机由"棘轮已锁巡航档"信号门控 |

