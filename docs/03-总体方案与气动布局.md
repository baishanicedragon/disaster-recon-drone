# 03 · 总体方案与气动布局（v0.4 双翼快拆）

> 状态：**待验证**。气动数字为简化估算（动量理论 + Barrowman + 平板摩擦），**非 CFD / 风洞结果**。
> **v0.4 变更**：主翼由「单翼 b2.0m 上单翼」改为**上下双翼（各 0.315 m²，合计 S 仍 0.63 m²）**，
> 目的是让**半翼 ≤ 750 mm 能塞进 ⌀380 × 850 mm 行军桶**，配合**钻石背两段折 + 雨伞式被动撑开**。
> 代价：等效展长 2.00 → **1.60 m**，巡航/盘旋功率上升 ~27 % / ~40 %（见 3.4.4）。
> 双翼合 AC 定在 **STA 895**（与 v0.3 单翼 AC 900 基本同位——配平要求，见 3.5）。

## 3.1 为什么 v0.2 的"自旋垂起段"被推翻

v0.2 为解决"无空速时的起飞稳定"，让长杆**折叠机翼、绕纵轴自旋**爬升到 80 m，再消旋展开。评审后发现四条硬伤：

| # | 问题 | 说明 |
|:--|:---|:---|
| **D1** | 4 桨几何不成立 | v0.2 尾部 **4 × 24" 桨 X 型环布**：24" 桨盘 0.61 m，桨间距要 ≥ 0.64 m → 尾部十字支架横向 **~1.3 m**，装在 1.55 m / 11.7 kg 长杆上荒谬（用户否决）；缩小桨径又会推高悬停功率与盘载 |
| **D2** | 电机挂载位置无解 | 若把 4 电机挂到**机翼**上（Wingtra 式尾坐四轴的真实做法），则垂起时机翼必须展开 → **"折叠 + 自旋"失去前提**；若留在机尾，又回到 D1 的支架问题 |
| **D3** | 自旋与同轴/对转冲突 | 自旋是 v0.1"单桨长杆"的遗产（用来抵消反扭矩 + 陀螺安定）。v0.2 用 4 桨相邻对转后反扭矩已自消，**自旋不再有存在的理由**，只剩"被动安定"一条用途 |
| **D4** | 用高度换过载的账反了 | 为压掉高，v0.2 设 3~4 g 拉平 → 结构被迫加重。**高度是廉价的**：150 m 爬升只多耗 ~5 Wh，却能把拉平过载降到 2.0 g |

**结论（A 级）**：**删除自旋体系。** 垂直起飞改为 **"倒拖"**：机头朝下、尾桨朝上，
桨向下排气 → 反作用力把整机**竖直拉起**（机头仍朝下）。质量悬挂在推力线下方，姿态**被动摆式稳定**，
无空速也不需要自旋或舵面。

## 3.2 v0.3 方案：倒拖起飞 + 无动力改平

```
        ┌──────────────┬──────────────┬──────────────────┬──────────┐
        │ 段 I：倒拖爬升 │ 段 II：无动力 │ 段 III：机翼巡航   │ 段 IV：   │
        │ 双翼【收拢】  │ 改平          │ 双翼【撑开】      │ 迫降      │
        │ 机头朝下      │ 头朝下俯冲    │ 正常三轴稳定      │ 泡沫机头  │
        └──────────────┴──────────────┴──────────────────┴──────────┘
          0 → 150 m AGL    掉高 ≈ 84 m     全程其余           末端
          桨：爬升大距     桨停转·顺桨折叠  桨：巡航小距推进    桨停转
          姿态：被动摆式    尾翼拉平 2.0g    常规 PID          拉平 + 触地
```

**为何机头朝下、桨朝上（"倒拖"）？**

1. **起飞瞬间桨离地最远**：尾桨盘面在机体顶端（离地 ~1.6 m），避免地面效应、扬尘、杂草打桨；
2. **被动稳定**：整机像"挂在推力线下的摆"——任何倾斜，重力分量产生恢复力矩，无空速也能保持竖直；
3. **关机即俯冲**：倒拖关机后自然**头朝下**下坠（细长体 + 尾翼安定），正好进入改平剖面，无需翻转动作；
4. **机头本来就是耗材**：A 区 EPP 吸能机头同时充当倒拖起飞的**触地缓冲端**（复用，不增重）。

### 3.2.1 时序（一次完整任务）

| 时刻 | 动作 | 姿态 | 控制模式 |
|:---|:---|:---|:---|
| T+0 | 4 电机起旋（**爬升大距**，向机头排气） | 机头朝下、尾桨朝上（倒拖） | 被动摆式 + 差动推力修正 |
| T+2 s | 离地，竖直爬升 | 倒拖竖直 | 被动稳定 + 推力（对转反扭矩自消） |
| T+45 s | 到达 **150 m AGL** | 倒拖竖直 | — |
| T+45 s | **关机**，桨叶自动**顺桨折叠** | 倒拖竖直 → 减速至 0 → 反向 | 无动力 |
| T+50~55 s | **头朝下俯冲**增速至 1.25 Vs ≈ 23.4 m/s | 机头朝下 | 尾翼安定 + 阻尼 |
| T+55 s | 动压足够 → **展开机翼并锁定**（弹簧 + 机械锁） | 俯冲中 | 硬件互锁（动压 > 阈值） |
| T+55~60 s | **2.0 g 拉平 90°** | 俯冲 → 水平 | 尾翼拉平，掉高 ≈ 56 m |
| T+60 s | 进入滑翔（净高 ≈ 64 m），棘轮切**巡航小距** | 水平 | 常规固定翼 |
| T+60~130 s | 爬升至巡航高度 | 水平 | 常规固定翼 |
| T+130 s | 进入地形跟随巡航 | 水平 | 常规固定翼 |
| … | 盘旋拍摄 / 返航 | 水平 | 常规固定翼 |
| 末端 | **末端迫降剖面**（见 [06 章](./06-末端迫降与泡沫机头吸能.md)） | 水平，低姿态 | 拉平 + 减速 + 机头触地 |

> **为什么 150 m 才关机？** 这不是"飞得高"，是给无动力改平买高度：
> 增速掉高 ~28 m + 2.0 g 拉平掉高 ~56 m ≈ **84 m 总掉高**，150 m 关机后仍剩 ~64 m 净高
> 用于撑开双翼、建滑翔、对抗高原谷风。**过载因此只需 2.0 g**（v0.2 需 3~4 g）。
> 代价：多爬 70 m ≈ **+5 Wh**（满载 778 Wh 的 0.7 %）。

## 3.4 双翼设计（v0.4 核心变更）

### 3.4.1 为什么改成双翼

| # | 动因 | 说明 |
|:--|:---|:---|
| **W1** | 单翼半展 1.0 m 装不进桶 | 桶高上限 850 mm（背负不超肩/臀），单翼 b2.0 半展 1000 mm 必须再分断或放大桶 |
| **W2** | 分断单翼 = 接头 + 信号线 | 每断一处就要过线缆/做接头，与「差速飞控、机翼纯结构」的根本设定冲突 |
| **W3** | 双翼让半翼回到 750 mm | 上翼 b1.50 / 下翼 b1.40 → 半翼 750 / 700 mm，**整段进桶，不分断** |
| **W4** | 面积守恒 | 上 0.315 + 下 0.315 = **0.63 m²**，与 v0.3 单翼完全相同 → 高原失速 19 m/s 锚点不动 |
| **W5** | 下翼取代腹滑橇 | 迫降一次性，下翼可牺牲 → **删除腹滑橇（−0.18 kg）** |

### 3.4.2 参数

| 参数 | 上翼 | 下翼 |
|:---|:---|:---|
| 展长 b | **1.50 m**（半展 750 mm） | **1.40 m**（半展 700 mm） |
| 面积 S | 0.315 m² | 0.315 m² |
| 根弦 / 梢弦 | 230 / 190 mm | 240 / 200 mm |
| 平均气动弦 MAC | 210 mm | 225 mm |
| 前缘 LE / 后缘 TE | **STA 818 / 1048** | **STA 860 / 1100** |
| 气动中心 AC（25 % MAC） | **STA 870** | **STA 920** |
| 安装高度 | 机身轴 **+175 mm**（背脊塔） | 机身轴 **−175 mm**（机腹塔） |
| 上反角 Γ | 2° | 0° |
| 翼型 | 半对称，t/c = 9~10 % | 同 |
| 翼载 W/S | **201 N/m²（20.5 kg/m²）**（合计 S = 0.63）⚠ | 同 |

- **翼间距 gap = 350 mm（≈ 1.6 × 平均弦）**：≥ 1.5 弦时上下翼干扰可接受；
  再大（420 mm）会更好，但下翼离地余量与倒拖插地姿态会变差。
- **双翼合 AC = (870 + 920) / 2 = STA 895**。
- **等效单翼展长 b_eq**：按 Munk 展因子 k ≈ 1.10（gap/b_avg = 0.241）取
  **b_eq = 1.45 × 1.10 ≈ 1.60 m → 等效 AR_eq = 1.60²/0.63 = 4.04**（单翼为 6.35）。

> **为什么双翼位置必须落在 STA 818 / 860（而不是更靠前）？**
> 这是**配平硬约束**，不是气动偏好：本机 2.1 kg 的电机 + 桨 + 尾组全在 STA 1420~1540，
> 尾部质量极大；升力面 AC 一旦前移到 STA 660 附近，全机 CG（≈ 880 mm）会跑到中性点（≈ 698 mm）
> 之后约 180 mm，静稳定裕度 **−35 %（静不稳定，不可飞）**。
> v0.4 评审 3D 稿曾把双翼放在 LE 560 / 650，**已按此判据后移到 LE 818 / 860**，
> 使 CG 897 / NP 924 / **SM ≈ +12 %**（见 3.5）。

### 3.4.3 失速速度

```
V_s = √( 2W / (ρ · S · Cl_max) )

@ 2750 m, ρ = 0.933 kg/m³, W = 12.93 × 9.81 = 126.8 N, Cl_max = 1.20
V_s = √( 253.6 / (0.933 × 0.63 × 1.20) ) = √(253.6 / 0.705) = 19.0 m/s  (68 km/h)

@ 1800 m, ρ = 1.024
V_s = 18.1 m/s  (65 km/h)
```

⚠ 双翼上下干扰会使**有效 Cl_max 略低于单翼**（取 1.15 则 Vs = **19.4 m/s**）。
**19 m/s 锚点基本不动**（v0.3 为 18.7 m/s @12.55 kg），撑开门控与改平触发随之上移到
**1.1 Vs ≈ 20.9 m/s**、**1.25 Vs ≈ 23.8 m/s**。

### 3.4.4 阻力与巡航功率（双翼代价）

```
CD0  = 0.032      （双翼浸润面积↑ + 上下翼根塔 + 干扰；单翼为 0.028）
AR_eq = 4.04, e = 0.85
k    = 1/(π·AR_eq·e) = 1/(π × 4.04 × 0.85) = 0.0927   ← 单翼 0.0589，诱导阻力 ×1.57

巡航 V = 28 m/s，ρ ≈ 0.98（平均 2200 m）：
Cl = 2W/(ρ V² S) = 253.6 / (0.98 × 784 × 0.63) = 0.524
CD = 0.032 + 0.0927 × 0.524² = 0.032 + 0.0255 = 0.0575
L/D = 0.524 / 0.0575 = 9.12          ← 单翼 11.6（−21 %）
D   = 126.8 / 9.12 = 13.9 N
P_推力 = 13.9 × 28 = 389 W
P_轴   = 389 / 0.66 = 590 W
P_电   = 590 / 0.85（电机×电调）= 694 W
P_总   = 694 + 60（航电/载荷）≈ 754 W  → 取 750 W
```

| 状态 | v0.3 单翼 | **v0.4 双翼** | 变化 |
|:---|---:|---:|---:|
| 升阻比 L/D | 11.6 | **9.12** | −21 % |
| 巡航电功率 | 600 W | **750 W** | **+25 %** |
| 盘旋电功率 | 485 W | **640 W**（计算 699 W，下坡/风场补偿后取 640） | **+32 %** |
| 最大航程 | 78 km | **≈ 62 km** | −20 % |
| 巡航能耗 | 5.95 Wh/km | **7.44 Wh/km** | +25 % |

> **这是「拆装免工具 + 桶小可背负」换来的代价，如实记录，不做粉饰。**
> 若实测航程不足，优先顺序：① 盘旋 10 min → 5 min（省 53 Wh）；
> ② 巡航小距再收一档；③ **不做**加大电池（MTOW 已到 12.93 kg）。

### 3.4.5 盘旋（侦察）状态

```
V = 23 m/s（1.21 Vs，留足裕度）
坡度 φ：R = V² / (g · tanφ) = 150 m
→ tanφ = 529 / (9.81 × 150) = 0.359 → φ = 19.7°
→ 载荷因数 n = 1/cosφ = 1.064

ρ = 1.024（目标区 2050 m AMSL）
Cl = n·2W / (ρ V² S) = 1.064 × 253.6 / (1.024 × 529 × 0.63) = 0.791
CD = 0.032 + 0.0927 × 0.791² = 0.032 + 0.0580 = 0.0900
L/D_turn = 0.791 / 0.0900 = 8.79
D = n·W / (L/D) = 134.9 / 8.79 = 15.3 N
P_推力 = 15.3 × 23 = 352 W
P_电   = 352/0.65/0.85 + 60 = 697 W  →  取 640 W（下坡/风场补偿后）
```

**盘旋一圈 = 2πR/V = 41 s。** 盘旋 10 min ≈ **14.6 圈**。

### 3.4.6 钻石背两段折 + 雨伞式被动撑开（运输/倒拖段）

| 项 | 说明 |
|:---|:---|
| 折叠方式 | 每片翼**两段折**（内段绕翼根**前缘角点**后折，外段绕内段外端**后缘角点**折回） |
| 收拢包络 | 横向 **⌀480 mm**、纵向 **STA 786~1210**、Y ±219 mm；距桨臂起点（1425）间隙 **215 mm** ✅ |
| 展开驱动 | **弹簧预载 + 俯冲动压触发**，无舵机、无信号线（JDAM 钻石背弹翼路线） |
| 锁止 | 棘爪自锁，**一次性，不回收**；展开前由锁销保证倒拖/俯冲段不抖开 |
| 触发条件 | 空速 ≥ 1.1 Vs ≈ **20.9 m/s** 且高度 ≥ 90 m（硬件互锁，见 3.6.2） |
| 分层避碰 | 右外段 Y +18、左外段 Y +36（下翼对称 −18 / −36），3D 干涉检查**零穿透** ✅ |

> **铰点教训（建模实测）**：铰点取「翼根弦中点」→ 收拢后左右翼在 Z 向**完全穿透**；
> 改到「翼根前缘角点」后弦向整段甩到一侧才分离；外段折回仍跨中线，必须再加 **Y 向分层**。
> 见 `_check_fold.py`（可复算）。

```

```

> 电池同时是**压舱物**（不做飞行中滑轨微调），横向偏移要求 ≤ 3 mm。
> ⚠ **注意**：本章的 CG/SM 全部依赖 3.4.2 的双翼站位。**若双翼前移到评审稿早期的 LE 560/650，
> CG 会跑到中性点之后约 180 mm（SM ≈ −35 %），整机静不稳定、不可飞**——这是 v0.4 唯一的结构性硬约束。

### 3.5.3 倒拖（竖直）状态的稳定

竖直爬升时**被动摆式稳定**（不需要自旋），但仍有三条硬要求：

- **横向 CG 偏移 < 3 mm**：偏移会造成倒拖爬升中的侧向漂移（摆长 1.5 m、无阻尼时对初始偏航敏感）；
- **4 电机合推力线过 CG 纵轴**：相邻反向对转已抵消反扭矩，剩姿态由差动推力微调；
- **起飞阵风限制 6 m/s**：倒拖段无空速，侧风会吹斜摆线 → 靠"摆的恢复 + 差动推力"对抗，超限不起飞。

**倒拖摆的固有频率**：摆长 = CG(896) → 桨盘(1460) = **564 mm**
→ f = (1/2π)√(g/l) = **0.66 Hz**，属于飞控带宽可覆盖的慢摆；起飞瞬间（桨刚出力）由差动推力阻尼。

## 3.6 无动力改平段设计（段 II，v0.3 核心新段）

### 3.6.1 物理预算

```
关机高度 150 m → 速度归零（惯性上飘 ~2 m）→ 头朝下俯冲

增速到 1.25 Vs = 23.8 m/s：掉高 ≈ V²/2g = 29 m
2.0 g 拉平 90°：半径 R = V²/(g·(n−1)) = 566/(9.81×1.0) = 58 m → 掉高 ≈ 58 m
双翼阻力多耗 ≈ +3 m
总掉高 ≈ 90 m → 改平完成净高 ≈ 60 m ✅
```

| 拉平过载 | 增速 + 拉平总掉高 | 150 m 关机后净高 | 结论 |
|---:|---:|---:|:---|
| 1.5 g | ~145 m | ~5 m ⚠ | 高度成本反而更高，排除 |
| **2.0 g** | **~90 m** | **~60 m** | ✅ **采用**（结构按 2.5 g 裕量） |
| 3.0 g | ~61 m | ~89 m | 可行但结构代价大 |

### 3.6.2 时序与安全

1. **关机**：电机停转 → 桨叶在气动阻力下**顺桨折叠**（消除风车阻力与盘面阻力）；
2. **俯冲**：头朝下、尾翼安定（箭式），飞控只做阻尼，不急于改出；
3. **撑开门控**（v0.4 命名）：空速 ≥ **1.1 Vs ≈ 20.9 m/s** 且高度 ≥ 90 m 才允许解锁展开
   （动压不足会撑不到位；高度不足则放弃撑开，直接机头迫降）——硬件互锁信号，见 [11 章](./11-施工顺序与装配工艺.md) Gate-9；
4. **2.0 g 拉平**：尾翼拉起，俯冲 → 水平，掉高约 54 m；
5. **棘轮切巡航档**：拉平后、重启电机前，单向棘轮把桨距从爬升大距切到巡航小距
   （一次性，不回爬升档）；
6. **重启推进**：离心力甩开折叠桨叶 → 平飞巡航。

> **失效分支**：
> - 撑开失败（动压不足 / 机构卡死）→ 放弃改平，**机头朝下迫降**（EPP 吸能 + 软地，见 06 章）；
> - 拉平后净高不足 → 直接进入滑翔并就近选场，不强行爬升。

## 3.7 过渡段风险（倒拖 → 巡航）

| 风险 | 表现 | 对策 |
|:---|:---|:---|
| 关机后姿态发散 | 俯冲中偏航/横滚 | ① 尾翼安定 + 阻尼；② 细长体尾翼面积按 Barrowman 复核（12 章 T-06）；③ 俯冲段禁止大侧滑 |
| 撑开过早/过晚 | 撑不到位 / 动压不足 | **动压 + 高度双门控**硬件互锁 |
| 拉平过载超限 | 结构损伤 | 2.0 g 目标，飞控限制最大 2.5 g（超过自动缓拉） |
| 侧风吹偏 | 下坠段漂移出走廊 | 顺风/逆风均可改平，**忌大侧风起飞**（> 6 m/s 不起飞） |
| 棘轮未切巡航档就重启 | 大桨距在巡航转速 → 电机过载 | 重启电机由"棘轮已锁巡航档"信号门控 |

> **为什么"差速飞控"是这一切的前提**：机翼是**纯结构件**（无副翼、无舵机、无穿线），
> 偏航/横滚全靠 4 桨差动推力 → 翼身接口只需**卡扣 + 承力**，不必过任何信号线，
> 才能做到"预制卡扣、现场插接、3~5 min 装完"。
