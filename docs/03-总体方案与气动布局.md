# 03 · 总体方案与气动布局（构型收敛）

> 状态：**待验证**。气动数字为简化估算（动量理论 + Barrowman + 平板摩擦），**非 CFD / 风洞结果**。
> 本章是本次收敛的**核心**：解释为什么 v0.1 的"纯自旋长杆"必须被推翻，以及新构型怎么把"自旋"和"盘旋"这两件互斥的事同时塞进一台飞机。

---

## 3.1 根本冲突：自旋 与 盘旋

v0.1 的构型是"纯自旋长杆 + 尾翼"。它能垂直起飞、能高速巡航、能用单侧相机做圆锥扫描。
但它**无法盘旋**，原因有三条，且都是硬性的：

| # | 冲突 | 物理解释 |
|:--|:---|:---|
| **C1** | 自旋体没有持续盘旋所需的向心力来源 | 盘旋 = 持续的水平向心力。自旋长杆靠弹体倾斜产生法向力，但**弹体每转半圈，倾斜方向就反向一次**，向心力被平均掉 → 只能走直线 |
| **C2** | 自旋 + 大展向面 = 桨叶效应 | 若给自旋体加机翼以获得向心力，机翼会变成一副**大阻力桨叶**：展长 2 m、自旋 2.5 Hz 时**翼尖线速度 15.7 m/s**，产生巨大反自旋力矩与阻力，同时左右机翼升力周期性反号 |
| **C3** | 自旋体成像质量差 | v0.1 已承认：2 ms 曝光下像移 58 像元，必须压到 0.5 ms 曝光 + 降速到 1.5 Hz。这与"高清晰度"要求直接对抗 |

**结论（A 级 · 物理层面）**：**自旋稳定与机翼盘旋不能同时存在。** 只能**分时复用**。

---

## 3.2 收敛方案：**分时三段式**

```
        ┌─────────────────┬──────────────────┬──────────────────┐
        │  段 I：自旋段    │  段 II：过渡段    │  段 III：机翼段   │
        │  机翼【折叠】    │  消旋 + 展开      │  机翼【展开】     │
        │  纯长杆自旋      │                  │  常规三轴稳定     │
        └─────────────────┴──────────────────┴──────────────────┘
          垂直起飞 + 爬升       ~20 s            巡航 / 盘旋 / 返航
          80 m AGL 以下        60~120 m          全程其余
          自旋 2.0~2.8 Hz     自旋 → 0          自旋 < 0.2 Hz
          控制：滚转速率      控制：反舵消旋     控制：常规 PID
```

**关键洞察：机翼折叠状态恰好同时满足两个需求。**

- 折叠运输（R-09：1 人可背负、2 人 10 min 展开）→ 本来就要折叠机构；
- 自旋段需要"小展向面" → 折叠状态下展向只有 ~0.35 m，桨叶效应消失（C2 解除）。

因此**不需要额外代价**，只需把"折叠"和"自旋"绑进同一套时序。

### 3.2.1 时序（一次完整任务）

| 时刻 | 动作 | 姿态 | 控制模式 |
|:---|:---|:---|:---|
| T+0 | 4 电机起旋 → 尾翼 cant 在桨滑流中起旋 | 尾坐竖直 | **自旋保持**（滚转速率闭环） |
| T+2 s | 离地，垂直爬升 | 竖直 | 自旋保持 + 推力 |
| T+25 s | 到达 **80 m AGL** | 竖直 | — |
| T+25~27 s | **尾翼反舵消旋** 2.5 Hz → < 0.2 Hz | 竖直 | 反舵闭环 |
| T+27~29 s | **机翼展开并锁定**（舵机/弹簧 + 机械锁） | 竖直 | 姿态保持 |
| T+29~45 s | **过渡转平飞**（重力转弯 + 差动推力 + Q_ASSIST） | 竖直 → 水平 | tailsitter 过渡 |
| T+45 s | 进入地形跟随巡航 | 水平 | 常规固定翼 |
| … | 盘旋拍摄 / 返航 | 水平 | 常规固定翼 |
| 末端 | **末端迫降剖面**（见 [06 章](./06-末端迫降与泡沫机头吸能.md)） | 水平，低姿态 | 拉平 + 减速 |

> **为什么 80 m 才展开？** 自旋段的价值是"起飞瞬间无空速、舵面无效时的被动稳定"。
> 到 80 m 已积累约 15 m/s 轴向速度 + 桨滑流，舵面有效，主动控制接管，自旋可以退役。

## 3.3 构型选择（横向对比）

| 构型 | 垂起 | 4 尾电机 | 自旋兼容 | 可盘旋 | 无跑道 | 复杂度 | 结论 |
|:---|:---|:---|:---|:---|:---|:---|:---|
| **A. 尾坐 + 折叠弹翼 + 自旋垂起段** | ✅ | ✅ | ✅（折叠时） | ✅ | ✅ | 中高 | **选它** |
| B. 复合翼（4 垂起 + 1 平推） | ✅ | ❌ 需求限"尾部电机" | ❌ | ✅ | ✅ | 高 | 不满足约束 |
| C. 倾转旋翼 | ✅ | ⚠️ 倾转机构与自旋冲突 | ❌ | ✅ | ✅ | 很高 | 排除 |
| D. 纯自旋长杆（v0.1） | ✅ | ✅ | ✅ | **❌** | ✅ | 低 | **排除（C1）** |
| E. 多旋翼 + 高速巡航 | ✅ | ✅ | ❌ | ✅ | ✅ | 中 | 速度/航程不足 |
| F. 伞降/火箭助推 | — | — | — | — | — | — | 火工品，红线排除 |

**结论：A。**

## 3.4 主翼设计

### 3.4.1 参数

| 参数 | 符号 | 数值 |
|:---|:---|:---:|
| 展长 | b | 2.00 m |
| 面积 | S | 0.63 m² |
| 展弦比 | AR | **6.35** |
| 平均气动弦 | MAC | 0.315 m |
| 根梢比 | λ | 0.6（根弦 0.39 m / 梢弦 0.23 m） |
| 安装位置 | — | **上单翼**（安装线高于机身轴 60 mm） |
| 前缘位置 | — | STA 821（AC 在 STA 900） |
| 上反角 | Γ | 3° |
| 翼型 | — | 半对称，t/c = 9~10 % |
| 翼载 | W/S | **199 N/m²（20.3 kg/m²）** ⚠ |

> **为什么上单翼？** 迫降时翼尖离地高度 = 机身半径 + 上单翼抬升 60 mm + 腹滑橇 120 mm ≈ **180 mm**。
> 下单翼会让翼尖先触地、造成机体翻滚。见 [06 章](./06-末端迫降与泡沫机头吸能.md)。

### 3.4.2 失速速度

```
V_s = √( 2W / (ρ · S · Cl_max) )

@ 2750 m, ρ = 0.933 kg/m³, W = 123 N, Cl_max = 1.15
V_s = √( 246 / (0.933 × 0.63 × 1.15) ) = √(246 / 0.676) = 18.7 m/s  (67 km/h)

@ 1800 m, ρ = 1.024
V_s = 17.8 m/s  (64 km/h)
```

⚠ **18.7 m/s 的失速速度偏高**，这是"高速长杆"必然的代价。
它直接决定了末端迫降的能量水平——见 06 章（这是本设计最危险的一环）。

### 3.4.3 阻力与巡航功率

```
CD0  = 0.028      （机身摩擦 + 机翼型阻 + 尾翼 + 干扰，基于 S = 0.63 m²）
e    = 0.85
k    = 1/(π·AR·e) = 1/(π × 6.35 × 0.85) = 0.0589

巡航 V = 28 m/s，ρ ≈ 0.98（平均 2200 m）：
Cl = 2W/(ρ V² S) = 246 / (0.98 × 784 × 0.63) = 0.488
CD = 0.028 + 0.0589 × 0.488² = 0.028 + 0.0140 = 0.0420
L/D = 0.488 / 0.0420 = 11.6
D   = 123 / 11.6 = 10.6 N
P_推力 = 10.6 × 28 = 297 W
```

**螺旋桨效率是这里的隐忧**：4 副 24" 桨是为垂起悬停优化的（大盘面、低桨盘载荷），
在 28 m/s 巡航时**严重偏离设计点**（前进比过低）。取 η_p = 0.62（乐观）：

```
P_轴   = 297 / 0.62 = 479 W
P_电   = 479 / 0.85（电机×电调）= 563 W
P_总   = 563 + 60（航电/载荷）≈ 620 W
```

> **已知代价**：4 桨在巡航段是"过大"的，效率 penalty 约 15~25 %。
> **缓解手段**（按优先级）：
> 1. 巡航时**对角 2 桨停转并顺桨**，只用 2 桨推进 → 需处理不对称，但可省 8~12 %；
> 2. 用**变距桨/折叠桨**在巡航时减小等效盘面；
> 3. 干脆接受，把多出的功率算进电池（本设计采用）。

### 3.4.4 盘旋（侦察）状态

```
V = 23 m/s（1.23 Vs，留足裕度）
坡度 φ：R = V² / (g · tanφ) = 150 m
→ tanφ = 529 / (9.81 × 150) = 0.359 → φ = 19.7°
→ 载荷因数 n = 1/cosφ = 1.064

ρ = 1.024（目标区 2050 m AMSL）
Cl = n·2W / (ρ V² S) = 1.064 × 246 / (1.024 × 529 × 0.63) = 0.736
CD = 0.028 + 0.0589 × 0.736² = 0.028 + 0.0319 = 0.0599
L/D_turn = 0.736 / 0.0599 = 12.3
D = n·W / (L/D) = 131 / 12.3 = 10.6 N
P_推力 = 10.6 × 23 = 244 W
P_电   = 244/0.65/0.85 + 60 = 502 W  →  取 485 W（下坡/风场补偿后）
```

**盘旋一圈 = 2πR/V = 41 s。** 盘旋 10 min ≈ **14.6 圈**，足够做多次重叠覆盖。

> 有意思的是：**盘旋比巡航更省电**（速度更低）。这与"盘旋很贵"的直觉相反——
> 因为代价主要在**爬升**和**垂起**，不在盘旋本身。

### 3.5.3 尾坐（竖直）状态的稳定

竖直悬停时**无被动稳定性**，全靠飞控。竖直段的配平要求只有一条：
**4 个电机合推力矢量过 CG，且 CG 在机体轴线上。**

- 4 电机 X 型对称 → 合力沿轴；
- 横向 CG 偏移必须 **< 3 mm**（超出会导致起飞即倒）；
- 尾坐起落架展开半径 **≥ 0.55 m**，抗 6 m/s 侧风不倒 ⚠。

## 3.6 自旋段设计（段 I）

### 3.6.1 自旋从哪来

**尾翼 cant 角**：4 片尾翼相对子午面统一偏转 δ_cant = 4.5°，
在桨滑流 / 轴向来流下产生绕纵轴净力矩，加速自旋，直到
**滚转阻尼 = cant 驱动力矩**。

```
驱动：Cl_δ · δ_cant ≈ 0.010 /deg × 4.5 = 0.045
阻尼：Cl_p · (p·b_f)/(2V)，Cl_p ≈ −0.45，b_f = 0.48 m
平衡（V ≈ 桨滑流速度 25 m/s）：
p = 0.045 × 2 × 25 / (0.45 × 0.48) = 10.4 rad/s = 1.66 Hz
平衡（V = 爬升速度 15 m/s 分量叠加）：p ≈ 2.0~2.5 Hz
```

**设计自旋速率：2.0 ~ 2.8 Hz**（cant 4.5°，可用舵面微调 ±0.8 Hz）

### 3.6.2 自旋段的三个好处

1. **起飞瞬间无空速、舵面无效** → 自旋提供陀螺刚度，抵抗地面阵风、地面效应不对称、单桨推力偏差；
2. **角动量平均掉固定偏置**：4 电机推力差、加工不对称、cant 误差，转一圈被平均；
3. **折叠状态展向仅 0.35 m**，桨叶效应可忽略（这是本方案能成立的前提）。

### 3.6.3 消旋（段 II）

```
折叠状态转动惯量（机翼收拢）：I_xx ≈ 0.05 kg·m²
ω = 2π × 2.5 = 15.7 rad/s → H = 0.79 kg·m²/s

尾翼在桨滑流中：q = ½ × 0.933 × 25² = 291 Pa
单片尾翼 S = 0.0143 m²，偏 20° → Cl ≈ 0.8
单翼升力 = 291 × 0.0143 × 0.8 = 3.33 N
力臂 ≈ 0.09 m → 4 片合计滚转力矩 = 4 × 3.33 × 0.09 = 1.20 N·m

消旋时间 t = H / L = 0.79 / 1.20 = 0.66 s  ✅
```

> 消旋非常轻松（**0.7 s**），因为折叠状态惯量极小。
> 唯一风险是**消旋与展开机翼的时序**：**必须先消旋、后展开**。
> 若在自旋中展开，一侧先开 → 巨大不对称力矩 → 立刻失控。
> → **硬件互锁**：机翼展开机构的作动器由"自旋速率 < 0.2 Hz"信号门控（[11 章](./11-施工顺序与装配工艺.md) Gate-9）。

## 3.7 过渡段（尾坐 → 平飞）

| 风险 | 表现 | 对策 |
|:---|:---|:---|
| 空速不足，舵面无效 | 竖立→平飞中段失控 | ① 高度余量 ≥ 80 m；② 过渡以**差动推力**为主；③ ArduPilot `Q_ASSIST_SPEED` 空速不足自动补推力 |
| 侧风吹倒 | 长杆侧面积大 | ① 风速 > 6 m/s 不起飞；② 过渡段**禁止大侧滑**；③ 尾翼在滑流中保持权限 |
| 过渡后掉高 | 势能换动能 | 预留 ≥ 60 m 掉高量 |
| 机翼未锁定 | 展开不到位 → 空中折翼 | **硬件互锁 + 微动开关**双确认；任一未确认 → 中止并进入"垂直迫降"备用剖面 |
