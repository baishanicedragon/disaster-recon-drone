## 13.8 本仓库的许可兼容提示

| 你打算做什么 | 需要注意 |
|:---|:---|
| 只阅读/学习 | 无限制 |
| 修改文档并提交 PR | 遵循 MIT（文档部分） |
| 制作硬件并**销售** | 硬件许可 **CERN-OHL-S v2** 要求衍生设计**同样开源** |
| 使用 YOLOv8 权重 | **AGPL-3.0**，商用需向 Ultralytics 取得商用授权 |
| 使用 ODM 做商业服务 | AGPL-3.0，网络服务也触发传染 |
| 飞机本身 | **本仓库不提供任何适航/合规依据** |

## 13.9 维护约定

1. 所有外链**只在本文件登记**，便于批量校验（建议每季度跑一次死链检查）；
2. 新增依赖时，**同时更新本表 + 在 PR 中说明许可**；
3. 发现链接失效或版本大改 → 提 Issue 标签 `dependencies`；
4. **不在此表登记的外部资源，视为未被本项目采纳。**
